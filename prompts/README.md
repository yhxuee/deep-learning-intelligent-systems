# Mentor prompt packs

Plain-text, model-agnostic prompts. These files are the source of truth: the website renders them verbatim with a copy button.

Use: paste `base-policy.md` + one mode file (or one unit file) into any capable LLM, then attach or paste the relevant unit page (or point an MCP-capable agent at the Atlas server in `mcp/`).

Prompts are pedagogical suggestions, not enforcement. They cannot proctor an exam. Each change must pass a human review and the regression checklist in `docs/` (Phase 3) against at least two different model families.

Version: 1.1.0 (edition 2026-11)
