## 精简版——一学期，14 周

适合只开一门深度学习课的系所。涵盖毕业生验证 AI 写的深度学习代码所需的最低限度。

| 周次 | 单元 | 产出 |
|---|---|---|
| 1–2 | [01](/zh-cn/core/unit-01/) 学习 | 主干项目阶段 01；保留集评估 |
| 3–5 | [03](/zh-cn/core/unit-03/) 优化（加上 [02](/zh-cn/core/unit-02/) 的要点） | 通过所有不变量的手写自动微分；阶段 03 |
| 6–8 | [04](/zh-cn/core/unit-04/) 交互 | 不看数据写出注意力；调试挑战；阶段 04 |
| 9 | 统整 | 不使用 AI 的期中考＋口试检查 |
| 10–11 | [07](/zh-cn/core/unit-07/) 自监督 | 预训练主干模型；数据污染检查 |
| 12–13 | [10](/zh-cn/core/unit-10/) 失效 | 评估框架；数据泄漏诊断 |
| 14 | 答辩 | 小型专题＋答辩 |

## 完整版——两学期，28 周

| 周次 | 重点 | 产出 |
|---|---|---|
| 1–6 | 单元 01–03：学习、表示、优化 | 附独立梯度验证的最小网络 |
| 7–12 | 单元 04–06：交互、记忆、计算 | 信息处理机制的比较实验 |
| 13–14 | 统整 | 独立评估与口试 |
| 15–20 | 单元 07–09：自监督、生成、决策 | 含后训练的小型端到端流程 |
| 21–24 | 单元 10–11：失效、诠释 | 诊断式与对抗式评估报告；归纳头 |
| 25–28 | 单元 12：总结专题 | 复现 → 挑战 → 延伸 → 答辩 |
