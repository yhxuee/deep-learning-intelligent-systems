## D.1 熵

离散分布 $p$ 的**熵（entropy）**为
$$
H(p) = -\sum_xp(x)\ln p(x) = \mathbb{E}_{x\sim p}[-\ln p(x)],
$$
即期望的**惊讶度（surprisal）** $-\ln p(x)$，约定 $0\ln0 = 0$。

**命题 D.1。** 对 $K$ 个结果上的分布，$0\le H(p)\le\ln K$；$H = 0$ 恰为点质量，$H = \ln K$ 恰为均匀分布。

*证明。* 对 $p\in[0, 1]$，每一项 $-p\ln p\ge0$，而且只有某个 $p(x) = 1$ 时才全部为零。上界：以 $u$ 表均匀分布，$\ln K - H(p) = \mathrm{KL}(p\,\Vert\,u)\ge0$（D.2）。$\blacksquare$

**例题 D.1。** $p = (0.5, 0.3, 0.15, 0.05)$ 的 $H = 1.142$ nats $= 1.648$ 比特，低于 $\ln 4 = 1.386$ nats。它是单元 08 温度例子的基础分布：降低温度使熵趋向 0，提高温度使熵趋向 $\ln 4$（单元 08，例题 8.2）。

**联合熵与条件熵。** 对一对 $(X, Y)$，$H(X, Y) = -\mathbb{E}\ln p(X, Y)$，$H(Y\mid X) = -\mathbb{E}\ln p(Y\mid X) = \sum_xp(x)H(Y\mid X = x)$。对乘法规则取 $-\mathbb{E}\ln$ 就得到**链式法则**
$$
H(X, Y) = H(X) + H(Y\mid X),\qquad H(X_1,\dots,X_T) = \sum_tH(X_t\mid X_{<t}).
$$
第二种形式说明了为什么下一词元模型的每词元损失可以和熵*率*比较：在平稳来源上可达到的最优平均损失是 $\lim_T\frac1TH(X_1,\dots,X_T)$。**条件化平均而言会降低熵**，$H(Y\mid X)\le H(Y)$（证明见 D.3）：更多上下文在期望上永远不会让最优预测器变差，虽然它可能让一个*学出来的*预测器变差。

## D.2 交叉熵与 Kullback–Leibler 散度

模型 $q$ 相对于数据 $p$ 的**交叉熵**为 $H(p, q) = -\mathbb{E}_{x\sim p}\ln q(x)$——数据服从 $p$、预测服从 $q$ 时的期望对数损失。**Kullback–Leibler 散度**是其超出的部分：
$$
\mathrm{KL}(p\,\Vert\,q) = \sum_xp(x)\ln\frac{p(x)}{q(x)} = H(p, q) - H(p).
$$
若对某个 $p(x) > 0$ 的 $x$ 有 $q(x) = 0$，它就是 $+\infty$：一个把零概率指派给会发生之事的模型，要付出无穷大的对数损失——这就是平滑（单元 01，§1.3.4）与 logits 有限的 softmax 输出之所以重要的原因。

**定理 D.2（吉布斯不等式，Gibbs' inequality）。** $\mathrm{KL}(p\,\Vert\,q)\ge0$，等号成立当且仅当 $p = q$。

*证明。* 在 $p$ 的支撑集上使用 $\ln t\le t - 1$（只在 $t = 1$ 时等号成立）：
$$
-\mathrm{KL}(p\,\Vert\,q) = \sum_xp(x)\ln\frac{q(x)}{p(x)}\le\sum_xp(x)\Big(\frac{q(x)}{p(x)} - 1\Big) = \sum_{x: p(x)>0}q(x) - 1\le0. \qquad\blacksquare
$$

所以在所有 $q$ 中，交叉熵恰在 $q = p$ 时最小，其值为 $H(p)$：**最小化对数损失就是最大似然，而它的下限是数据的熵**（单元 01，§1.3.2）。书中每个回报的训练或留出损失，都是从样本估计的 $H(p) + \mathrm{KL}(p\,\Vert\,q)$；只有第二项能被更好的模型降低。

**KL 不是距离。** 它不对称，也不满足三角不等式。

**例题 D.2。** 对 $p = (0.5, 0.5)$ 与 $q = (0.9, 0.1)$：$\mathrm{KL}(p\,\Vert\,q) = 0.5\ln\frac{0.5}{0.9} + 0.5\ln\frac{0.5}{0.1} = 0.511$，但 $\mathrm{KL}(q\,\Vert\,p) = 0.9\ln1.8 + 0.1\ln0.2 = 0.368$。低估一个一半时间都会发生的结果（给它 0.1），代价比高估它还大。

**凸性。** $\mathrm{KL}(p\,\Vert\,q)$ 对 $(p, q)$ 联合凸，$H(p, q)$ 对 $q$ 凸。对 softmax 模型 $q = \mathrm{softmax}(z)$，交叉熵对 logits $z$ 是凸的（附录 B，命题 B.3），但对产生 logits 的深层网络参数则不是。

## D.3 互信息

$X$ 与 $Y$ 之间的**互信息（mutual information）**为
$$
I(X; Y) = \mathrm{KL}\big(p(x, y)\,\Vert\,p(x)p(y)\big) = H(X) - H(X\mid Y) = H(Y) - H(Y\mid X).
$$
由吉布斯不等式 $I\ge0$，等号恰在 $X$ 与 $Y$ 独立时成立——这证明了 $H(X\mid Y)\le H(X)$。

**例题 D.3。** 令 $X$ 为公平的比特，$Y$ 是它以概率 0.2 翻转后的副本，所以 $p(x, y) = \begin{pmatrix}0.4 & 0.1\\0.1 & 0.4\end{pmatrix}$。则 $H(X) = \ln2 = 0.693$，$H(X\mid Y) = h(0.2) = -0.2\ln0.2 - 0.8\ln0.8 = 0.500$，$I(X; Y) = 0.193$ nats：观测 $Y$ 消除了关于 $X$ 的 28% 不确定性。

**定理 D.3（数据处理不等式）。** 若 $X\to Y\to Z$ 是马尔可夫链（$Z$ 只通过 $Y$ 依赖 $X$），则 $I(X; Z)\le I(X; Y)$。

*证明。* 由互信息的链式法则，$I(X; Y, Z) = I(X; Z) + I(X; Y\mid Z) = I(X; Y) + I(X; Z\mid Y)$。马尔可夫性质给出 $I(X; Z\mid Y) = 0$，而 $I(X; Y\mid Z)\ge0$。$\blacksquare$

对一个表示的任何处理，都无法创造出该表示本来没有的、关于输入的信息。这是单元 02“表示只能舍弃”这一观察（§2.2）的信息论形式，也是为什么探针的准确率从下方界定了一层*包含*什么，却从不界定模型*使用*什么（单元 11，§11.3.6）。

**对比界。** 互信息在高维中难以估计。以 $K$ 个候选的 InfoNCE 目标给出下界 $I(X; Y)\ge\ln K - \mathcal L_{\text{InfoNCE}}$（单元 07，命题 7.1），它永远不会超过 $\ln K$——所以要以对比方法估计很大的互信息，需要非常大的批量。

## D.4 微分熵与高斯

对密度，**微分熵**为 $h(p) = -\int p(x)\ln p(x)\,dx$。与离散熵不同，它可以是负的，而且在变量替换下不是不变的：$h(aX) = h(X) + \ln|a|$。相对地，KL 散度与互信息对密度仍保有意义，并在可逆的重参数化下不变。

**高斯熵。** 对 $N(\mu, \sigma^2)$，$h = \tfrac12\ln(2\pi e\sigma^2)$，$\sigma = 1$ 时为 $1.419$ nats；对 $\mathbb{R}^n$ 中的 $N(\mu, \Sigma)$，$h = \tfrac12\ln\big((2\pi e)^n\det\Sigma\big)$。

**命题 D.4（最大熵）。** 在 $\mathbb{R}$ 上方差为 $\sigma^2$ 的所有密度中，高斯的微分熵最大。

*证明。* 对任何这样的 $p$ 与平均、方差相同的高斯 $\phi$，$0\le\mathrm{KL}(p\,\Vert\,\phi) = -h(p) - \int p\ln\phi$。因为 $\ln\phi(x)$ 是 $x$ 的二次式，$\int p\ln\phi$ 只通过平均与方差依赖 $p$，所以等于 $\int\phi\ln\phi = -h(\phi)$。因此 $h(p)\le h(\phi)$。$\blacksquare$

以其他限制做同样的论证，会得到其他最大熵族；以期望特征 $\mathbb{E}[f(x)]$ 为限制时得到 $p(x)\propto e^{\lambda^{\top}f(x)}$——指数族，也是 softmax 输出之所以自然的原因（附录 F.6）。

## D.5 高斯之间的 KL 散度

对一维高斯，
$$
\mathrm{KL}\big(N(\mu_1, \sigma_1^2)\,\Vert\,N(\mu_2, \sigma_2^2)\big) = \ln\frac{\sigma_2}{\sigma_1} + \frac{\sigma_1^2 + (\mu_1 - \mu_2)^2}{2\sigma_2^2} - \frac12 ,
$$
对 $n$ 维高斯
$$
\mathrm{KL}\big(N(\mu_1, \Sigma_1)\,\Vert\,N(\mu_2, \Sigma_2)\big) = \tfrac12\Big[\mathrm{tr}(\Sigma_2^{-1}\Sigma_1) + (\mu_2 - \mu_1)^{\top}\Sigma_2^{-1}(\mu_2 - \mu_1) - n + \ln\frac{\det\Sigma_2}{\det\Sigma_1}\Big].
$$
*推导（一维）。* $\ln\frac{p_1}{p_2} = \ln\frac{\sigma_2}{\sigma_1} - \frac{(x - \mu_1)^2}{2\sigma_1^2} + \frac{(x - \mu_2)^2}{2\sigma_2^2}$；在 $p_1$ 下取期望值，使用 $\mathbb{E}(x - \mu_1)^2 = \sigma_1^2$ 与 $\mathbb{E}(x - \mu_2)^2 = \sigma_1^2 + (\mu_1 - \mu_2)^2$。$\blacksquare$

**例题 D.4。** $\mathrm{KL}(N(0, 1)\,\Vert\,N(1, 4)) = \ln2 + \frac{1 + 1}{8} - \frac12 = 0.443$，而 $\mathrm{KL}(N(1, 4)\,\Vert\,N(0, 1)) = -\ln2 + \frac{4 + 1}{2} - \frac12 = 1.307$。用一个宽的分布描述位于其中的窄分布很便宜；反过来则很昂贵。

变分自编码器 ELBO 中的 KL 项 $\mathrm{KL}(N(\mu, \mathrm{diag}\,\sigma^2)\,\Vert\,N(0, I))$，就是这个公式取 $\mu_2 = 0$、$\Sigma_2 = I$：$\tfrac12\sum_j(\sigma_j^2 + \mu_j^2 - 1 - \ln\sigma_j^2)$（单元 08，§8.3.3）。

## D.6 编码：一个 nat 的意义

**前缀码（prefix code）**指派的码字中没有任何一个是另一个的前缀，所以一串码字不需分隔符号就能解码。二元前缀码的码字长度 $\ell(x)$（以比特计）满足 **Kraft 不等式** $\sum_x2^{-\ell(x)}\le1$；反之，任何满足它的长度都可以实现。

**定理 D.5（来源编码，期望长度）。** 对 $X\sim p$，每个前缀码的期望长度至少为 $H(p)/\ln2$ 比特，而长度 $\ell(x) = \lceil-\log_2p(x)\rceil$ 能达到小于 $H(p)/\ln2 + 1$。

*下界的证明。* 令 $r(x) = 2^{-\ell(x)}/Z$，$Z = \sum_x2^{-\ell(x)}\le1$。则 $\mathbb{E}[\ell]\ln 2 = \mathbb{E}[-\ln r(X)] - \ln Z\ge H(p, r)\ge H(p)$，用到 $\ln Z\le0$ 与吉布斯不等式。$\blacksquare$

**例题 D.5。** 对 $p = (\tfrac12, \tfrac14, \tfrac18, \tfrac18)$，码 $0, 10, 110, 111$ 的长度为 $1, 2, 3, 3$，期望长度 1.75 比特，等于熵，因为每个概率都是 2 的幂。

这就是模型损失的操作意义：通过算术编码，交叉熵为每词元 $H(p, q)$ nats 的模型，能把数据压缩到每词元约 $H(p, q)/\ln2$ 比特。语言模型就是压缩器，更好的模型就是更好的压缩器。**困惑度** $e^{H(p, q)}$ 是损失相同的均匀分布的大小——“像在这么多个同样可能的词元中挑一个那样不确定”（单元 01，§1.3.8）。

## D.7 正向与反向 KL

当把受限族中的模型 $q$ 拟合到目标 $p$ 时，散度的方向会改变答案——这就是“涵盖众数”与“寻找众数”的精确意义。

- **正向 KL**，$\min_q\mathrm{KL}(p\,\Vert\,q)$：被积函数 $p\ln(p/q)$ 在 $p > 0$ 而 $q\approx0$ 之处非常巨大，所以 $q$ 必须涵盖 $p$ 有质量的每个区域。最大似然训练最小化的是相对于数据的正向 KL。在高斯族中，最小化者匹配 $p$ 的平均与方差（命题 D.4 的证明显示只有这些动差会出现）。
- **反向 KL**，$\min_q\mathrm{KL}(q\,\Vert\,p)$：被积函数以 $q$ 加权，所以 $q$ 若把质量放在 $p$ 很少的地方会受罚，忽略 $p$ 的某些区域则不受罚。受限的 $q$ 会把一个众数拟合好，而放弃其他众数。

**例题 D.6。** 把单一高斯 $q$ 拟合到混合分布 $p = \tfrac12N(-2, 0.5^2) + \tfrac12N(2, 0.5^2)$。正向 KL 由动差匹配最小化，$q = N(0, 2.06^2)$，$\mathrm{KL}(p\,\Vert\,q) = 0.72$；若把 $q$ 放在一个众数上，$N(2, 0.5^2)$，则 $\mathrm{KL}(p\,\Vert\,q) = 15.3$。反向 KL 则恰好相反：动差匹配的高斯把质量放在两个众数之间 $p$ 几乎没有质量的地方，$\mathrm{KL}(q\,\Vert\,p) = 2.10$；放在一个众数上的高斯则为 $0.69\approx\ln 2$。

**当族不受限时，两个方向都由 $q = p$ 最小化**，不会放弃任何众数。这就是为什么 KL 正则化后训练的精确最优解保留参考模型所允许的每一个输出；寻找众数只通过近似的策略族或不完整的优化而出现（单元 09，§9.5.2）。
