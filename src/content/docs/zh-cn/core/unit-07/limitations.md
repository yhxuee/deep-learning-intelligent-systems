标记：**[D]** 推导、**[E]** 实验证据、**[O]** 工程观察、**[H]** 尚待验证的假说。

反例的目的不是宣称自监督“没有用”，而是指出：即使训练成功，仍有哪些结论**不能**跟着推出。看清这条边界，我们才知道下一步该量什么。

## 7.7.1 吻合文本统计，不等于学到真相

在总体最优解上，下一词元预测会复现语料条件分布 $p_{\text{data}}(x_t\mid x_{<t})$（§7.5.1）**[D]**。只有当数据生成过程让真相在预测上可见时，“真”才会进入这条方程。

主干数据生成器提供了一个受控例子：30% 的算术故事会把总和改成错误答案。在“同一上下文只有一个正确续接与一个错误续接”这个简化情况下，数据条件分布会分别给它们 $0.7$ 与 $0.3$ 的概率。最大似然逐渐逼近这个频率时，正是在完成它被交付的工作；没有任何信号要求它把全部概率移到数学正解。

但不要过度解读这个计算。有限的主干模型看到许多不同名字、数字与上下文，所以不能由此推出“它恰好把 30% 概率给这个错误数字”。单元 09 会度量它的实际行为。这个计算只隔离出一项机制：预测目标本身无法把常见模式标成迷思、过时事实、讽刺或谎言。

TruthfulQA 给了一项实验警告：在该研究涵盖的模型家族与题目内，扩大预训练语言模型并未可靠提高真实性，有时反而更会模仿常见迷思（[Lin 等人，2022](/zh-cn/references/#lin-2022)）**[E]**。这不是“模型越大一定越不真实”的定理；它证明的是较低预训练损失并非真实性证书。

**反例。** 想象一份语料中，每个错误医疗说法都被复制十次，而每份更正只出现一次。完美的语料模型理应更常预测错误说法。最大似然做得越好，模型反而离临床人员想要的行为越远，因为训练分布与理想决策规则并不相同。

## 7.7.2 记忆与泛化可以同时存在

“记忆”需要可操作的定义。它可能表示模型：

- 对某段训练序列给出异常高的似然；
- 看到前缀后逐字输出很长的训练段落；
- 泄露某笔记录是否出现在训练中；
- 或依赖范例专属捷径，而不是可重用规则。

这些测试彼此相关，却不等价。模型可能已泛化文法，同时逐字吐出一个罕见电话号码；良好的保留集 NLL 也不能排除局部记忆。

[Carlini 等人（2021）](/zh-cn/references/#carlini-2021)从 GPT-2 采样，还原出逐字训练序列，其中包含可识别个人信息 **[E]**。后续受控研究在其实验设定内发现三项近似对数线性关系：可提取记忆会随模型容量、范例重复次数与可用提示上下文增加（[Carlini 等人，2023](/zh-cn/references/#carlini-2023)）**[E]**。这些是量到的趋势，不是跨所有架构与数据流水线都成立的普遍公式。

去重可以降低逐字输出与训练—测试重叠（[Lee 等人，2022](/zh-cn/references/#lee-2022)）**[E]**，但“已去重”不等于“不可能记忆”。唯一但敏感的字符串仍可能具有很大影响；近似副本可能躲过检测；大模型也可能拟合只出现一次的内容。

主干训练从约 $363{,}418$ 个字符的流式采样了约 $8.192$ 百万个训练字符——相当于约 $22.5$ 个流式长度的**等效词元抽取量**。它不是依序完整扫过 22.5 次：窗口以放回方式采样，也可能跨越故事边界。因此，实验 7.4 会度量精确复现与给定前缀后的复现，而不会只从接触量声明模型已记忆。

## 7.7.3 低文本重叠不是“没有污染”的证书

每种污染检测器都有自己的目标类别。文本 8-gram 重叠对近乎逐字的重用很敏感，却不是为了寻找信息可能泄漏的所有方式而设计。

| 情况 | 8-gram 检测器可能怎么做 | 原因 |
|---|---|---|
| 完整复制的答案 | 标出 | 许多长词组保持不变 |
| 忠实改写 | 漏掉 | 用词改变，但信息仍在 |
| 翻译 | 漏掉 | 表面词元几乎完全改变 |
| 把答案表重新排成表格 | 漏掉大部分 | 局部顺序与边界改变 |
| 常见法律制式文本 | 标出 | 长共同词组不一定表示基线泄漏 |
| 很短的题目 | 变得不稳定 | 只有极少、甚至没有相异 8-gram |

还有一个拼贴问题：训练集所有 $n$-gram 的并集可能覆盖整个保留项目，即使没有任何一份训练文档含有完整题目。因此，方向性覆盖率很高是查看来源背景的理由，不是基线被复制的自动证明。

模型式检验可以探查文本比对漏掉的信号。Oren 等人比较模型对可交换基线之标准顺序与打乱顺序的似然，检验标准顺序是否异常地高（[Oren 等人，2024](/zh-cn/references/#oren-2024)）**[E]**。该方法有特定零假设，并不是通用的改写检测器。补全与似然检验同样依赖模型存取权、校准与有效参考分布。

从低 $n$-gram 重叠能得到的正确结论很窄：**在这个表示与阈值下，我们只找到很少近乎逐字重叠的证据。** 更强的保证必须结合来源背景、多种检测器、冻结的切分规则，以及在可能时使用训练快照之后才建立的评估数据。即使是快照后数据仍需要存取控制，因为之后公开到网络上，也可能泄漏进未来模型。

## 7.7.4 预训练目标只是用途的代理

代理目标可以与理想行为相关，却不会直接定义它。

- 下一词元损失奖励准确续写语料；用户可能需要可查证的答案或安全行动。
- 遮罩重建奖励由周围上下文还原内容；用户可能需要分布转移下仍校准良好的类别概率。
- 对比损失奖励从指定负样本中找出正样本；用户可能在意正、负样本都未呈现的另一项区别。

**捷径反例。** 假设预训练样本中的有害留言全来自同一网站，而且都带着相同页首。表示只要编码页首，就能支持极佳的训练分类；页首一消失，原本想要的语义区别其实从未被学会。

因此，低预训练损失只建立了模型在预训练代理目标上的成功。解码（单元 08）、行为反馈（单元 09）与任务专属评估（单元 10）都会引入额外选择。它们可能改善理想用途，也可能创造新捷径或抹掉有用行为。“已预训练”代表一个具有已度量性质的起始状态，不是已完成的规格。

## 7.7.5 数据质量是一个向量，不是一个分数

一份文档可能流畅却错误、准确却过时、有用却未获许可、多样却嘈杂；也可能单独看来无害，与其他数据组合后却暴露隐私。把这些全叫作“质量”，会掩码不同目标。

| 面向 | 一个可能的稽核问题 | 一个可能的取舍 |
|---|---|---|
| 事实性 | 主张能否追溯到可靠且有日期的来源？ | 参考来源可能遗漏新兴或少数知识 |
| 多样性 | 还保留哪些语言、方言、领域与观点？ | 固定计算量下，广度增加可能提高噪声 |
| 隐私 | 是否含有个人或秘密字符串？ | 过度积极的过滤可能忽略上下文或删除合法公开记录 |
| 权利与同意 | 这些内容是否可用于此目的？ | 法律许可与社会可接受性并不相同 |
| 新鲜度 | 快照时间是否符合部署时间？ | 新近数据经过的审查较少 |
| 教学价值 | 文本是否解释推理，而不只给答案？ | 教材式过滤可能缩窄风格与主题覆盖 |

每个过滤器都实现了一种归纳偏差 **[O]**。如果分类器偏好近似参考百科全书的散文，它可能系统性降低对话、方言或专业格式的权重。之后报告的下游增益只适用于所用评估，不能证明语料在所有意义上都更好。

“更多数据”同样有条件。固定计算量下，加入低价值文档可能排挤有用更新；加入副本会改变权重；加入生成文本可能放大生成器的遗漏。正确比较应冻结计算、模型、切分与评估，再改变一项有记录的数据决策。语料大小本身不是处置变项。

## 7.7.6 学到的分布还不是行为

阶段 07 结束后，主干模型提供的是条件概率。若要产生一段续写，还要有解码规则把这些概率转成选择。

- **贪心解码**永远选下一步概率最大的词元。它是确定性的，但局部最可能的选择可能进入重复循环。
- **祖先采样**从完整条件分布抽取。它较忠实地代表模型分布，却也会抽到其中低概率的错误。
- **截断与温度**刻意改变分布，在多样性与集中程度之间取舍。

所以，两个权重完全相同的系统可以展现不同文本行为。反过来，一个流畅样本也不能证明底层概率已校准，或另一个解码种子同样安全。单元 08 会在同一检查点上度量这些差异。

连续数据方面，有一点必须更正：概率链式法则并不限于词元。连续向量同样能分解成条件密度；图像也能依序排列像素或离散码元，以自回归方式生成。真正的困难是这个顺序可能很人为，而且逐步采样很慢，而不是数学上禁止分解。[单元 08](/zh-cn/core/unit-08/) 的扩散、流与其他连续时间构造，会提供不同的训练与采样路径。

因此，下一个问题不只是“损失下降了吗？”而是：**哪一套程序把学到的统计对象变成我们观察到的行为？那套程序实际产生的又是哪个分布？**

## 7.7.7 精简诊断表

| 观察 | 本身不能证明 | 下一项检查 |
|---|---|---|
| 较低的验证 NLL | 真实性或罕见技能能力 | 事实与技能分层测试 |
| 没有检测到 8-gram 重叠 | 没有改写或翻译泄漏 | 来源背景，加上语义式与模型式稽核 |
| 去重模型的提取率较低 | 唯一记录已具隐私保障 | 金丝雀、成员推断与定向提取测试 |
| 预训练代理目标更好 | 部署决策更好 | 冻结的下游与分布转移评估 |
| 过滤后语料更大 | 有效数据更好 | 固定计算量的数据消融 |
| 一个流畅样本 | 抽样分布可靠 | 多种子比例与置信区间 |

这些并不是放弃自监督的理由；它们是以科学方式使用自监督所必需的度量。
