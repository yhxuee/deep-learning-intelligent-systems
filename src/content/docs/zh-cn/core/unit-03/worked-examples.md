## 例题 3.1——直线拟合的梯度下降

**问题。** 以 §3.2.1 的数据，$L(w) = \tfrac13(14w^2 - 56.2w + 56.42)$。从 $w_0 = 0$ 出发、以 $\eta = 0.1$ 做五步梯度下降。计算前，先预测每步的误差缩减因子。

**解答。** $L'(w) = \tfrac13(28w - 56.2)$，$L''(w) = 28/3 \approx 9.333$。在抛物线上，误差每步乘上 $1-\eta L'' = 1 - 0.9333 = 0.0667$（§3.2.3），所以每一步应该消除剩余误差的约 93%。

| $k$ | $w_k$ | $L(w_k)$ | $L'(w_k)$ | $w_{k+1} = w_k - 0.1L'(w_k)$ |
|---|---|---|---|---|
| 0 | 0.000000 | 18.806667 | −18.733333 | 1.873333 |
| 1 | 1.873333 | 0.089985 | −1.248889 | 1.998222 |
| 2 | 1.998222 | 0.006800 | −0.083259 | 2.006548 |
| 3 | 2.006548 | 0.006430 | −0.005551 | 2.007103 |
| 4 | 2.007103 | 0.006429 | −0.000370 | 2.007140 |

误差 $w^* - w_k$ 依序为 $2.00714 \to 0.13381 \to 0.00892 \to 0.00059 \to 0.00004$：每个比值都是 $0.0667$，与预测完全相同。最小损失 $0.006429$ 不为零，因为没有一条通过原点的直线能穿过全部三点。

## 例题 3.2——共用输入处的累加

**问题。** 对 $f(a,b) = (a+b)\cdot a + \tanh a$，在 $a = 0.5$、$b = -1$ 时以反向模式计算 $\partial f/\partial a$ 与 $\partial f/\partial b$，列出 $\bar a$ 的每一份贡献，并与解析导数比对。

**解答。** 轨迹：$v_1 = a + b = -0.5$；$v_2 = v_1\cdot a = -0.25$；$v_3 = \tanh a = 0.462117$；$f = v_2 + v_3 = 0.212117$。

输入 $a$ 有**三个子节点**（$v_1$、$v_2$、$v_3$）。依相反顺序反向计算：

| 步骤 | 规则 | 贡献 | 累计 $\bar a$ |
|---|---|---|---|
| $\bar f = 1$ | 起始值 | | 0 |
| $f = v_2 + v_3$ | $\bar v_2 \mathrel{+}= 1$、$\bar v_3 \mathrel{+}= 1$ | | 0 |
| $v_3 = \tanh a$ | $\bar a \mathrel{+}= \bar v_3(1-v_3^2)$ | $+0.786448$ | 0.786448 |
| $v_2 = v_1\cdot a$ | $\bar v_1 \mathrel{+}= \bar v_2\,a$；$\ \bar a \mathrel{+}= \bar v_2\,v_1$ | $\bar v_1 = 0.5$；$-0.5$ | 0.286448 |
| $v_1 = a + b$ | $\bar a \mathrel{+}= \bar v_1$；$\ \bar b \mathrel{+}= \bar v_1$ | $+0.5$；$\bar b = 0.5$ | **0.786448** |

**检查。** $f = a^2 + ab + \tanh a$，所以 $\partial f/\partial a = 2a + b + (1-\tanh^2a) = 1 - 1 + 0.786448 = 0.786448$ ✓，$\partial f/\partial b = a = 0.5$ ✓。若实现用*赋值*取代累加，$\bar a$ 会是 $0.5$（只有最后一份贡献）——错了 36%，实验室的扇出测试也会失败。

## 例题 3.3——手算两层网络

**问题。** 输入 $x = (1, 2)$；隐藏层 $z_1 = W_1x + b_1$、$h_1 = \tanh z_1$，其中
$W_1 = \begin{pmatrix}0.5&-0.25\\0.3&0.1\end{pmatrix}$、$b_1 = (0.1, -0.2)$；输出 $\hat y = w_2^{\top}h_1 + b_2$，$w_2 = (1, -2)$、$b_2 = 0.05$；损失 $L = \tfrac12(\hat y - 1)^2$。以 §3.3.6 的算法计算所有梯度，并以中心差分验证 $\partial L/\partial (W_1)_{12}$。

**前向。**
$z_1 = (0.5 - 0.5 + 0.1,\ 0.3 + 0.2 - 0.2) = (0.1,\ 0.3)$；
$h_1 = (\tanh 0.1,\ \tanh 0.3) = (0.099668,\ 0.291313)$；
$\hat y = 0.099668 - 2(0.291313) + 0.05 = -0.432957$；
$L = \tfrac12(-1.432957)^2 = 1.026683$。

**反向。**

| 量 | 规则 | 值 |
|---|---|---|
| $\bar{\hat y}$ | $\hat y - 1$ | −1.432957 |
| $\bar w_2$ | $\bar{\hat y}\,h_1$ | (−0.142820, −0.417439) |
| $\bar b_2$ | $\bar{\hat y}$ | −1.432957 |
| $\bar h_1$ | $w_2\,\bar{\hat y}$ | (−1.432957, 2.865914) |
| $1-h_1^2$ | | (0.990066, 0.915137) |
| $\bar z_1$ | $\bar h_1\odot(1-h_1^2)$ | (−1.418723, 2.622704) |
| $\bar W_1$ | $\bar z_1\,x^{\top}$ | $\begin{pmatrix}-1.418723&-2.837445\\2.622704&5.245409\end{pmatrix}$ |
| $\bar b_1$ | $\bar z_1$ | (−1.418723, 2.622704) |

**检查。** 把 $(W_1)_{12}$ 扰动 $\pm10^{-6}$ 取中心差分，得 $-2.8374453$ ✓。

**解读结果。** 第二个隐藏单元权重的梯度较大且符号相反：输出权重 $-2$ 在误差信号往返回时既放大又反转了它——这就是 $\bar h_{\ell-1} = W_\ell^\top\bar z_\ell$ 中转置权重矩阵的作用。

## 例题 3.4——softmax 交叉熵

**问题。** 分数 $s = (2.0, 1.0, 0.1)$，目标为第 1 类。计算 $p$、损失与 $\bar s$。

**解答。** $e^{s} = (7.389, 2.718, 1.105)$，总和 $11.212$，所以 $p = (0.659, 0.242, 0.099)$（更精确为 $0.659001, 0.242433, 0.098566$）。损失 $= -\ln 0.659001 = 0.417030$。梯度 $\bar s = p - e_1 = (-0.341, 0.242, 0.099)$。

梯度提高正确类别的分数，并依其他类别拿走多少概率来压低它们。各元素总和为零（所有分数加上同一常数时 softmax 不变，所以损失在全 1 方向上不可能改变）。

## 例题 3.5——病态条件与动量

**问题。** $L(\theta) = \tfrac12(\theta_1^2 + 10\theta_2^2)$，从 $(1, 1)$ 出发。(a) 求梯度下降法的最优固定步长及其收敛因子。(b) 误差降为 $10^{-3}$ 倍需要几步？(c) 以 §3.5.7 的最优参数，对重球动量重做一次。

**解答。** (a) 曲率为 $\lambda_1 = 1$、$\lambda_2 = 10$；每个座标的误差乘上 $1-\eta\lambda_i$。当 $|1-\eta\cdot1| = |1-\eta\cdot10|$ 时，最慢的因子最小，即 $\eta = 2/(1+10) = 2/11 \approx 0.182$，两个座标的因子都是 $(10-1)/(10+1) = 0.818$（§3.5.4）。

(b) $0.818^k = 10^{-3} \Rightarrow k = \ln10^{-3}/\ln0.818 \approx 34.4$。模拟结果：35 步。

(c) 对 $\kappa = 10$：$\eta = 4/(\sqrt{10}+1)^2 = 0.231$、$\beta = \bigl((\sqrt{10}-1)/(\sqrt{10}+1)\bigr)^2 = 0.270$，渐近因子 $(\sqrt{10}-1)/(\sqrt{10}+1) = 0.519$，预测约 10.5 步达到 $10^3$ 倍。模拟结果：15 步（渐近速率需要几步才会生效），测得的渐近因子为 $0.52$。图 3.2 画出两条路径。

## 例题 3.6——选择有限差分的步长

**问题。** 在双精度下以中心差分估计 $\sin x$ 在 $x = 1$ 的导数。哪个 $h$ 使误差最小？误差最小能到多少？

**解答。** 两种误差互相竞争。*截断误差（truncation error）：* 泰勒展开给出 $\frac{f(x+h)-f(x-h)}{2h} = f'(x) + \frac{h^2}{6}f'''(x) + O(h^4)$，误差约 $\frac{h^2}{6}|f'''|$。*舍入误差（rounding error）：* 每个计算出的 $f$ 值都带有至多单位舍入误差 $u = 2^{-53}\approx1.11\times10^{-16}$ 的相对误差；两个几乎相等的数相减会保留这个绝对误差，除以 $2h$ 又将它放大，得约 $u|f|/h$。令 $E'(h) = 0$ 来最小化 $E(h) = \frac{h^2}{6}|f'''| + \frac{u|f|}{h}$：

$$
h^* = \Bigl(\frac{3u|f|}{|f'''|}\Bigr)^{1/3} = \Bigl(\frac{3\cdot1.11\times10^{-16}\cdot0.8415}{0.5403}\Bigr)^{1/3}\approx 8.0\times10^{-6},\qquad E(h^*)\approx1.7\times10^{-11}.
$$

实测误差：$h = 10^{-4}$ 时 $9.0\times10^{-10}$，$h = 10^{-5}$ 时 $1.1\times10^{-11}$，$h=10^{-6}$ 时 $2.8\times10^{-11}$，$h = 10^{-8}$ 时 $2.6\times10^{-9}$。步长更小反而*更差*。前向差分（截断误差为 $O(h)$）的最优步长约在 $\sqrt u\approx10^{-8}$，最优误差只有约 $3\times10^{-9}$。图 3.4（§3.7.5）画出完整的 V 形曲线。

## 例题 3.7——Adam 的第一步

**问题。** 一个模型有三个参数，第一次的梯度为 $g_1 = (0.001,\ -50,\ 3)$。取 $\beta_1 = 0.9$、$\beta_2 = 0.999$、$\epsilon = 10^{-8}$，计算 Adam 第一次更新的方向 $\hat m_1/(\sqrt{\hat v_1}+\epsilon)$。

**解答。** $m_1 = 0.1g_1$、$v_1 = 0.001g_1^2$；偏差校正后 $\hat m_1 = g_1$、$\hat v_1 = g_1^2$。所以方向为 $g_1/(|g_1| + \epsilon) = (0.99999,\ -1,\ 1)$。每个座标都（几乎恰好）移动 $\eta$，尽管梯度大小相差五万倍。若没有偏差校正，第一步在每个座标上都会大 $\frac{0.1g}{\sqrt{0.001}|g|} \approx 3.16$ 倍——这就是省略它的实现在训练初期行为怪异的原因。

## 例题 3.8——前向还是反向？

**问题。** 计算得到完整导数所需的传递次数：(a) 损失 $L:\mathbb{R}^{1000}\to\mathbb{R}$；(b) 轨迹 $\gamma:\mathbb{R}\to\mathbb{R}^{1000}$；(c) 映射 $F:\mathbb{R}^{1000}\to\mathbb{R}^{1000}$。

**解答。** 前向模式每次给出雅可比矩阵的一*列*；反向模式给出一*行*。(a) 雅可比矩阵为 $1\times1000$：前向 1000 次，反向 **1** 次。(b) $1000\times1$：前向 **1** 次，反向 1000 次。(c) $1000\times1000$：两者都要 1000 次——除非只需要乘积 $J^{\top}u$（一次反向）或 $Jv$（一次前向），而实践中这是常见情况。

## 例题 3.9——以方差决定初始化

**问题。** 一层计算 $z = \sum_{j=1}^{n}w_jx_j$，有 $n = 256$ 个平均为 0、方差为 1 的独立输入，权重独立、平均为 0、方差为 $\sigma_w^2$。选择 $\sigma_w$ 使 $\mathrm{Var}(z) = 1$。如果输入是前一层单位方差前活化经过 ReLU 的输出，应该怎么改？

**解答。** 对独立且平均为零的因子，$\mathrm{Var}(w_jx_j) = \mathrm{Var}(w_j)\mathrm{Var}(x_j)$，独立项的方差相加：$\mathrm{Var}(z) = n\sigma_w^2$。所以 $\sigma_w^2 = 1/n$，$\sigma_w = 0.0625$。

若 $x_j = \mathrm{ReLU}(u_j)$，$u_j$ 对称于零且 $\mathrm{Var}(u_j) = 1$，则 $x_j$ 平均不为零，改用二阶动差：$\mathbb E[x_j^2] = \tfrac12\mathbb E[u_j^2] = \tfrac12$（一半的质量被归零），$\mathrm{Var}(z) = n\sigma_w^2\,\mathbb E[x_j^2] = n\sigma_w^2/2$。要维持 $\mathrm{Var}(z) = 1$，需 $\sigma_w^2 = 2/n$，$\sigma_w = 0.0884$——即 [He et al.（2015）](/zh-cn/references/#he-2015) 的规则。§3.8.1 推导反向传递的版本，图 3.3 显示违反这条规则时会发生什么。
