## 计算

**3.1 ★ [不使用 AI]** 对 $L(w) = (w-3)^2 + 2$，从 $w_0 = 0$ 出发，分别以 $\eta = 0.3$ 与 $\eta = 0.9$ 计算五个梯度下降迭代值。$\eta$ 为多少时会发散？

**3.2 ★ [不使用 AI]** 对 §3.3.1 的神经元，把 $t = 0$ 改为 $t = 1$，以反向模式计算 $\partial L/\partial w_1$、$\partial L/\partial w_2$、$\partial L/\partial b$。用中心差分检查其中一个。

**3.3 ★★** *为什么随机搜索在高维失败。* 令 $u$ 为 $\mathbb{R}^n$ 中均匀随机的单位向量，$g$ 为固定的单位向量。证明 $\mathbb E[(u^{\top}g)^2] = 1/n$。由此推得：随机的一小步让平滑损失下降的一阶期望量为零，典型大小只有 $\|\nabla L\|/\sqrt n$——而梯度步能达到 $\|\nabla L\|$。

**3.4 ★** 对 $s = (0, 0, 0, 0)$、目标类别 3 的 softmax 交叉熵，计算 $p$、损失与 $\bar s$。把损失与单元 01 的均匀基线联系起来。

**3.5 ★★** 对 $H = \mathrm{diag}(0.5, 2, 8)$：求 $\eta$ 的稳定上限、最优固定步长、对应的速率，以及把误差缩小 $10^{4}$ 倍所需步数。再对调好的重球动量重做一次。

**3.6 ★** Adam（$\beta_1 = 0.9$、$\beta_2 = 0.999$）连续三步收到常数梯度 $g = 2$。计算 $k = 1,2,3$ 时的 $m_k, v_k, \hat m_k, \hat v_k$ 与更新量。

## 推导

**3.7 ★★ [不使用 AI]** 推导下列运算的向量–雅可比乘积：(a) 单独的 $y = \mathrm{softmax}(x)$，证明 $\bar x = p\odot(\bar y - (p^{\top}\bar y)\mathbf 1)$；(b) 没有增益与偏置的层归一化 $y = (x - \mu)/\sigma$，其中 $\mu, \sigma$ 为 $x$ 的平均与标准差。

**3.8 ★★** 以足标记号推导 $Y = XW$ 的批量梯度 $\bar W = X^{\top}\bar Y$ 与 $\bar X = \bar YW^{\top}$，并验证形状规则。

**3.9 ★★ [不使用 AI]** 对具 ReLU 隐藏层、softmax 交叉熵输出、批量大小 $B$ 的 MLP，推导完整的反向传播算法，并以乘加次数说明反向传递相对于前向传递的成本。

**3.10 ★★** 证明 §3.2.1 的损失 Hessian 为常数，且以 $\eta = 1/L''$ 做梯度下降可以从任何起点一步到达 $w^*$。为什么对 $H = \mathrm{diag}(1, 10)$ 没有任何固定 $\eta$ 能做到这点？

**3.11 ★★** 证明从大小为 $N$ 的数据集*不放回*地抽取小批量，得到的梯度是无偏的，且其方差比放回抽样小 $\frac{N-B}{N-1}$ 倍。

## 部分解答

- **3.1** $L'(w) = 2(w-3)$，曲率 2，$\eta<1$ 时稳定。$\eta = 0.3$ 时误差每步乘上 $0.4$：$w = 0, 1.8, 2.52, 2.808, 2.923, 2.969$。$\eta = 0.9$ 时因子为 $-0.8$：$w = 0, 5.4, 1.08, 4.536, 1.771, 3.983$——振荡中收敛。$\eta>1$ 时发散。
- **3.4** $p = (0.25, 0.25, 0.25, 0.25)$，损失 $\ln4 = 1.386$（均匀基线 $\ln V$），$\bar s = (0.25, 0.25, -0.75, 0.25)$。
- **3.5** 稳定条件 $\eta<0.25$；$\eta^* = 2/8.5 = 0.235$；$\kappa = 16$，速率 $15/17 = 0.882$；步数 $\ln10^4/(-\ln0.882) \approx 73.6$。动量：速率 $(4-1)/(4+1) = 0.6$，渐近约 18 步。
- **3.6** 对每个 $k$ 都有 $\hat m_k = 2$、$\hat v_k = 4$（对常数梯度，偏差校正是精确的），所以每次更新都是 $-\eta\cdot2/(2+\epsilon)\approx-\eta$。
