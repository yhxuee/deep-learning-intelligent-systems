## 计算

**8.1 ★ [不使用 AI]** 对概率 $(0.4, 0.3, 0.2, 0.1)$ 与 $u = 0.65$，反累积分布采样返回哪个符号？$u$ 在哪个区间时返回第三个符号？

**8.2 ★ [不使用 AI]** 计算 $(0.4, 0.3, 0.2, 0.1)$ 在温度 0.5 与温度 2 下的分布及其熵。

**8.3 ★** 对同一分布，找出 $p = 0.75$ 与 $p = 0.95$ 的核心，以及重新归一化后的概率。

**8.4 ★** 对 $x = 2z + 3$、$z\sim N(0, 1)$，以变量替换公式写出 $p_X(x)$，并在 $x = 3$ 求值。

**8.5 ★★** 在 $\mu = (1, -2)$、$\sigma = 0.5$ 下，于 $x = (1, -2)$、$t = 0.5$ 计算 §8.3.6 的精确高斯速度场。从 $x_0 = 0$ 出发的粒子最后会到哪里？

**8.6 ★★** 以精确高斯场从 $t = 0$ 走一步 Euler，会把每个 $x_0$ 映射到 $\mu$。以符号计算两步 Euler 后的标准差，并与例题 8.7 比对。

## 推导

**8.7 ★ [不使用 AI]** 证明命题 8.1（祖先采样是精确的）。

**8.8 ★★ [不使用 AI]** 推导 §8.3.3 的 ELBO 分解，并指出它何时取等号。

**8.9 ★★** 对 $q = N(\mu, \mathrm{diag}(\sigma^2))$ 与 $p = N(0, I)$，推导 ELBO 的 KL 项：$\frac12\sum_i(\mu_i^2 + \sigma_i^2 - 1 - \ln\sigma_i^2)$。

**8.10 ★★** 由高斯条件平均的公式推导 §8.3.6 的精确高斯速度场 $v^\star(x, t)$，并验证 $x(t) = t\mu + s_tx_0$ 是该常微分方程的解。

**8.11 ★★** 证明流匹配损失的最小值等于 $\mathbb{E}_t\mathbb{E}_{x_t}\mathrm{tr}\,\mathrm{Cov}(x_1 - x_0\mid x_t)$，且只有在路径从不交叉时才为零。

## 证明

**8.12 ★★★** 证明以接受概率 $\min(1, q(x)/r(x))$、并从 $\max(0, q - r)$（归一化后）重新采样的推测解码，输出恰好是分布 $q$。

**8.13 ★★** 在一维中完整证明命题 8.3（去噪声分数匹配）。

**8.14 ★★★** 在一维中证明命题 8.2 的 (b)：证明 $x_t$ 的密度以边缘速度满足连续方程。

**8.15 ★★** 构造一个两步的例子，证明贪心解码一般不会返回最可能的序列。

**8.17 ★★** 为流匹配采样器实现中点法常微分方程求解器，并以每次网络评估的样本质量与 Euler 比较。

**8.20 ★★★** 不使用学习的特征提取器，设计一个同时量测主干模型样本质量与多样性的评估。一个记住了训练故事的模型会得到什么分数？

## 部分解答

- **8.1** 累积 $(0.4, 0.7, 0.9, 1.0)$；$u = 0.65$ 返回第二个符号；$0.7\le u < 0.9$ 时返回第三个。
- **8.3** $p = 0.75$：$\{1, 2, 3\}$（累积 0.4、0.7、0.9——第一个达到 0.75 的是第三个），重新归一化为 $(0.444, 0.333, 0.222)$；$p = 0.95$：四个全部。
- **8.4** $p_X(x) = \frac12\phi\big(\frac{x-3}{2}\big)$；在 $x = 3$ 为 $\frac{1}{2\sqrt{2\pi}} = 0.1995$。
- **8.5** $s_{0.5}^2 = 0.3125$，系数 $-1.2$，$x - t\mu = (0.5, -1)$：$v^\star = (1, -2) - 1.2(0.5, -1) = (0.4, -0.8)$。从 $x_0 = 0$ 出发的粒子沿 $x(t) = t\mu$ 前进，终点为 $\mu$。
