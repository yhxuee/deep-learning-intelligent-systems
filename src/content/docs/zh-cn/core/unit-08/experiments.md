## 实验 8.1——主干模型上的采样器

**检验：** §8.2.3–§8.2.4、例题 8.4。**预测：** 对贪心、$\tau = 0.7$、$\tau = 1.5$ 与 top-$p = 0.9$，哪些会产生循环、哪些会产生不成字的字符串、哪些会产生多样且合乎格式的故事。

**步骤。** `python stage08_sampling.py` 会为每个采样器印出“Lily had a ”的三个 90 字符延续。然后每个采样器生成 200 个延续，计算 (a) 不同延续的数量、(b) 不成字的字符串（不在训练词汇中的字符串）。

**观察：** 贪心只有一种延续；$\tau = 1.5$ 的不成字字符串最多；top-$p$ 与 $\tau = 0.7$ 在两者之间取舍。

## 实验 8.2——量测退化

**检验：** §8.7.1。**预测：** 400 字符的贪心生成中，包含重复 30 字符子字符串的比例。

**步骤。** 以 50 个不同的提示，分别用贪心与 top-$p = 0.9$ 生成；检测重复的子字符串；也计算每段生成在模型自身下的 NLL。

**观察：** 贪心生成的 NLL 很低、重复很多——缩小版的似然陷阱。

## 实验 8.3——精确高斯流及其步数误差

**检验：** §8.3.6–§8.3.7、例题 8.7。**预测：** 以 1、2、5、20、200 步 Euler 积分后的样本标准差（目标 0.5）。

**步骤。** 从 20,000 个标准正态样本积分 `gaussian_velocity([1, -2], 0.5)`；再以中点法（二阶）取代 Euler 并重复。

**观察：** Euler 分别为 0、0.20、0.37、0.47、0.50；中点法以少得多的步数就达到 0.49。解释为什么平均在每种步数下都几乎精确，而分散程度却不是。

## 实验 8.4——环上的流匹配

**检验：** 命题 8.2、例题 8.8。**预测：** 最终的训练损失（不是零——为什么？），以及距某个众数 0.5 以内的样本比例。

**步骤。** 以 `fm_train` 训练 3,000 步；分别以 5、20、100 步 Euler 采样；画出样本并计算涵盖的众数。

**观察：** 损失从约 5.3 降到约 3.8；100 步时几乎所有样本都在八个众数附近，5 步时较少、也较模糊。

## 实验 8.5——同一个环上的 VAE

**检验：** §8.3.3、§8.5.4。**预测：** 一个二维潜变量、MLP 大小相同的 VAE 能否涵盖全部八个众数，以及它的样本相较于流匹配有多清晰。

**步骤。** 以重新参数化实现编码器、解码器与 ELBO（KL 项的梯度不使用 AI）；训练；采样。

**观察：** 样本在众数之间被抹开（高斯解码器会取平均）——§8.5.4 的模糊——以及改变 KL 项权重时的取舍。

## 实验 8.6——主干项目阶段 08

**检验：** [主干项目](/zh-cn/spine/)的验证目标。**预测：** $k = 1$ 的 top-$k$ 是否等于贪心；20,000 次采样是否在 0.012 内符合其概率。

**步骤。** `cd spine && python -m pytest test_spine.py -k stage08 -v`。

**观察：** 采样器在极限下彼此化约；精确的高斯场把噪声输运到目标；流匹配梯度与有限差分一致。


## 实验 8.7——语言之外：来自物理的密度

**检验：**§8.3.5、例题 8.8。**预测：**以双井 Boltzmann 密度 $p\propto e^{-\beta U}$（$U = (x^2 - 1)^2 + y^2/2$、$\beta = 3$）的样本训练的流匹配模型，是否在两个井中各放一半的样本，以及以 10 步与 100 步积分时有何不同。

**步骤。** 以 `double_well_samples` 抽取训练样本；沿用环形实验的 MLP 与训练循环；把生成样本中 $x > 0$ 的比例，以及位于能障 $|x| < 0.2$ 附近的质量，与数据比较（约 50% 与 5% 以下）。

**观察重点：**步数足够时众数的权重正确，步数太少时质量泄漏到能障上——这是 §8.7.3“朝可预测的方向出错”在一个科学情境中的样子，而在这里众数的权重正是我们关心的量（两个状态的族群比例）。一个丢掉或重新加权某个众数的生成器，在这里的错误是图像的视觉质量会掩盖的。
