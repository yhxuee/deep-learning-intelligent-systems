**4.2 ★ [不使用 AI]** 计算例题 4.3 *没有*因果遮罩时的 $A$ 与 $Y$。哪些输出改变了？为什么第 3 行没有改变？

**4.3 ★** 计算 $(3, 1, 0, 0)$ 在温度 1、0.5、2 时的 softmax，以及各结果的熵。把趋势与命题 4.3 联系起来。

**4.4 ★** 计算一个仅解码器 Transformer 的参数量：$d = 512$、8 个区块、词表大小 32,000、最大长度 2,048、学习的位置嵌入、绑定的嵌入。嵌入表占多少比例？

**4.5 ★★** 对 $d = 1\,024$、$T\in\{512, 8\,192\}$，计算每个区块的投影 + MLP 与注意力的前向 FLOPs，以及 24 层模型在 16 比特精度下的 KV 缓存大小。

**4.6 ★★** 以数值验证：对 $t = 5$、$k = 3$、$\omega = 0.1$，正弦编码在位置 $t+k$ 的值是位置 $t$ 的值经过固定旋转的结果（§4.3.4）。

## 推导

**4.7 ★★ [不使用 AI]** 从雅可比矩阵 $\mathrm{diag}(a) - aa^{\top}$ 推导逐行 softmax 的向量–雅可比乘积 $\bar S = A\odot(\bar A - \mathrm{rowsum}(A\odot\bar A))$。

**4.8 ★★ [不使用 AI]** 推导缩放点积注意力的 $\bar Q$、$\bar K$、$\bar V$（§4.3.6），再推导 $Q = XW_Q$ 等的 $\bar W_Q$、$\bar W_K$、$\bar W_V$。说明你的反向传递需要多少内存。

**4.9 ★★** 证明对每个键加上同一个向量不改变注意力，但对每个查询加上同一个向量一般会改变。这对 $W_K$ 中的偏置有什么启示？

**4.10 ★★** 在 §4.2.8 的方差论证中，假设 $q$ 与 $k$ 的分量独立、平均为 0、方差为 $\sigma_q^2, \sigma_k^2$。什么缩放能恢复单位方差？如果 $W_Q$ 与 $W_K$ 以方差 $1/d$ 初始化、输入是层归一化的输出，初始化时 $\sqrt{d_k}$ 仍然正确吗？

**4.12 ★★** 推广定理 4.1：证明有 $n\ge2$ 组时，没有任何仿射函数能解决查找；并证明在一个对称的序列族上，最优仿射预测器输出候选值的平均（推广例题 4.2）。

**4.13 ★★** 对双向皆循环位移的 2-D 图像证明定理 4.2（$\mathbb{R}^{T\times T}$ 上平移等变的线性映射就是 2-D 循环卷积）。

**4.15 ★★★** 给出一个任务，在其上把注意力限制在稀疏图（局部窗口）上能*提高*样本效率；再给出一个任务，在其上这样做使单层模型无法完成。正式论证两个主张。

## 部分解答

- **4.2** 没有遮罩时，第 1 行变成 $\mathrm{softmax}(0.7071, 0.7071, 0) = (0.4011, 0.4011, 0.1978)$，第 2 行变成 $\mathrm{softmax}(0, 0.7071, 0.7071) = (0.1978, 0.4011, 0.4011)$；第 3 行不变，因为因果遮罩对最后一个位置没有遮住任何东西。
- **4.4** 每区块 $12d^2 + 13d = 3\,152\,384$；八个区块 $25\,219\,072$；嵌入 $32\,000\cdot512 = 16\,384\,000$；位置 $1\,048\,576$；最后的层归一化 $1\,024$。总计 $42\,652\,672$；词元嵌入约占 38%。
- **4.9** $q^{\top}(k_j + c) = q^{\top}k_j + q^{\top}c$ 对一行中的每个分数加上相同的常数，softmax 会忽略它。对每个查询加上 $c$ 则加上 $c^{\top}k_j$，它在不同键之间不同。所以 $W_K$ 中的偏置对权重没有影响，可以拿掉。
