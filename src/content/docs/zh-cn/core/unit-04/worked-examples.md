## 例题 4.1——逐步的软查找

**问题。** 以 §4.2.1 的编码与 §4.2.7 的投影，对 $\beta = 4$ 计算查询 $?b$ 对键值对 $(a,3), (b,7), (c,1)$ 的分数、权重与输出。

**解答。** 查询为 $q = W_Qx_{?b} = 4\,(0,1,0)$。键读取键槽：$k_{(a,3)} = (1,0,0)$、$k_{(b,7)} = (0,1,0)$、$k_{(c,1)} = (0,0,1)$，而查询词元自己的键槽是空的，$k_{?b} = (0,0,0)$。值为：$3, 7, 1, 0$。

| 位置 | 分数 $q^{\top}k$ | $e^{\text{分数}}$ | 权重 | 权重 × 值 |
|---|---|---|---|---|
| $(a,3)$ | 0 | 1 | 0.0174 | 0.052 |
| $(b,7)$ | 4 | 54.598 | 0.9479 | 6.635 |
| $(c,1)$ | 0 | 1 | 0.0174 | 0.017 |
| $?b$ | 0 | 1 | 0.0174 | 0 |
| **总和** | | 57.598 | 1.0000 | **6.705** |

在 $\beta = 8$ 时，匹配权重为 $e^8/(e^8+3) = 0.9990$，输出为 6.994。注意查询词元中空的键槽所扮演的角色：如果 $W_Q$ 与 $W_K$ 读取*同一个*字段，查询会对自己得到分数 $\beta$，把注意力分给自己与正确的那一组。

## 例题 4.2——任何固定混合的最优表现

**问题。** 对定理 4.1 证明中的四个序列 $A, B, C, D$（目标为 3、7、7、3），求使总平方误差最小的仿射函数的输出。

**解答。** 每个仿射 $F$ 都满足 $F_A + F_D = F_B + F_C$。在此限制下最小化 $(F_A-3)^2 + (F_B-7)^2 + (F_C-7)^2 + (F_D-3)^2$。对 $F_A + F_D - F_B - F_C = 0$ 引入拉格朗日乘子 $\lambda$，驻点条件给出残差 $F_A - 3 = F_D - 3 = -\lambda/2$ 与 $F_B - 7 = F_C - 7 = \lambda/2$。代入限制式，$(3 - \lambda/2)\cdot2 = (7 + \lambda/2)\cdot2$，所以 $\lambda = -4$，且

$$
F_A = F_B = F_C = F_D = 5 .
$$

最优的固定混合在每个序列上都输出**候选值的平均**，每次误差为 2。（表达力足够的仿射模型可以实现这些输出，所以这个下界是可达到的。）它无法分辨查询要的是哪个值。

## 例题 4.3——因果注意力的前向计算

**问题。** 三个位置，$d_k = d_v = 2$：

$$
Q = \begin{pmatrix}1&0\\0&1\\1&1\end{pmatrix},\quad
K = \begin{pmatrix}1&0\\1&1\\0&1\end{pmatrix},\quad
V = \begin{pmatrix}1&2\\0&1\\3&0\end{pmatrix}.
$$

计算 $S$、因果权重 $A$ 与 $Y$。

**解答。** $QK^{\top}$ 的元素为 $q_i^{\top}k_j$；除以 $\sqrt2$：

$$
S = \frac{1}{\sqrt2}\begin{pmatrix}1&1&0\\0&1&1\\1&2&1\end{pmatrix}
= \begin{pmatrix}0.7071&0.7071&0\\0&0.7071&0.7071\\0.7071&1.4142&0.7071\end{pmatrix}.
$$

应用因果遮罩（对角线以上的元素变成 $-\infty$）与逐行 softmax：

- 第 1 行只有一个可见元素：$A_{1\cdot} = (1, 0, 0)$。
- 第 2 行：$\mathrm{softmax}(0, 0.7071) = (0.3302, 0.6698)$，因为 $1/(1+e^{0.7071}) = 0.3302$。
- 第 3 行：$\mathrm{softmax}(0.7071, 1.4142, 0.7071) = (0.2483, 0.5035, 0.2483)$。

$$
A = \begin{pmatrix}1&0&0\\0.3302&0.6698&0\\0.2483&0.5035&0.2483\end{pmatrix},\qquad
Y = AV = \begin{pmatrix}1&2\\0.3302&1.3302\\0.9930&1.0000\end{pmatrix}.
$$

例如 $Y$ 的第 3 列为 $0.2483(1,2) + 0.5035(0,1) + 0.2483(3,0) = (0.9930, 1.0000)$。图 4.3 画出 $A$。

![例题 4.3 的 3×3 因果注意力矩阵热图：第 1 列为 (1, 遮罩, 遮罩)；第 2 列为 (0.330, 0.670, 遮罩)；第 3 列为 (0.248, 0.503, 0.248)。](/figures/u04-attention-heatmap.svg)

## 例题 4.4——因果注意力的反向计算

**问题。** 延续例题 4.3，上游梯度为 $\bar Y = \begin{pmatrix}1&0\\0&1\\1&-1\end{pmatrix}$。以 §4.3.6 的公式计算 $\bar V$、$\bar A$、$\bar S$、$\bar Q$ 与 $\bar K$，并以有限差分检查 $\bar Q_{31}$。

**解答。**

$\bar V = A^{\top}\bar Y = \begin{pmatrix}1.2483&0.0820\\0.5035&0.1663\\0.2483&-0.2483\end{pmatrix}$，且 $\bar A = \bar YV^{\top} = \begin{pmatrix}1&0&3\\2&1&0\\-1&-1&3\end{pmatrix}$。

逐行做 softmax 的反向，$\bar S_{i\cdot} = a_i\odot(\bar A_{i\cdot} - a_i^{\top}\bar A_{i\cdot})$，只用可见元素：

- 第 1 行：唯一的可见权重为 1，所以 $a^{\top}\bar A = 1$，$\bar S_{1\cdot} = 1\cdot(1-1) = 0$。*一个只能看到自己的查询，对于“该看哪里”没有什么可学的。*
- 第 2 行：$a^{\top}\bar A = 0.3302\cdot2 + 0.6698\cdot1 = 1.3302$；$\bar S_{2\cdot} = (0.3302(2-1.3302),\ 0.6698(1-1.3302),\ 0) = (0.2212, -0.2212, 0)$。
- 第 3 行：$a^{\top}\bar A = -0.2483 - 0.5035 + 0.7448 = -0.0070$；$\bar S_{3\cdot} = (-0.2465, -0.5000, 0.7465)$。

$\bar S$ 的每一行总和都为零——这是 softmax 对“同一行加上常数”不变的结果。接着

$$
\bar Q = \frac{\bar SK}{\sqrt2} = \begin{pmatrix}0&0\\0&-0.1564\\-0.5279&0.1743\end{pmatrix},\qquad
\bar K = \frac{\bar S^{\top}Q}{\sqrt2} = \begin{pmatrix}-0.1743&-0.0179\\-0.3535&-0.5099\\0.5279&0.5279\end{pmatrix}.
$$

**检查。** 把 $Q_{31}$ 扰动 $\pm10^{-6}$，对 $L = \sum_{ij}Y_{ij}\bar Y_{ij}$ 取差分，得 $-0.52785$ ✓。

## 例题 4.5——RoPE 只依赖相对位置

**问题。** 一个旋转对，$\theta = 0.5$、$q = (1, 0)$、$k = (0.6, 0.8)$。对 $(m,n) = (3,1), (5,3), (10,8)$ 与 $(1,3)$ 计算分数 $\bigl(R(m\theta)q\bigr)^{\top}\bigl(R(n\theta)k\bigr)$。

**解答。** 由 §4.3.4，分数为 $q^{\top}R((n-m)\theta)k$。前三对都有 $n - m = -2$，角度为 $-1$ 弧度：$R(-1)k = (0.6\cos1 + 0.8\sin1,\ \dots)$，分数是它的第一分量，$0.6(0.5403) + 0.8(0.8415) = 0.9974$——**三者完全相同**，虽然绝对位置不同。对 $(1,3)$，$n - m = +2$：$0.6(0.5403) - 0.8(0.8415) = -0.3490$。以明确的旋转直接计算也得到同样四个值（误差在 $10^{-15}$ 内）。旋转相对位移会改变分数；两个位置一起平移则不会。

## 例题 4.6——多头不增加参数

**问题。** 对 $d = 768$，比较 $H = 1$ 个头与 $H = 12$ 个大小为 64 的头时的注意力参数量。

**解答。** 12 个头时，每个头有 $W_Q^{(h)}, W_K^{(h)}, W_V^{(h)}\in\mathbb{R}^{768\times64}$：$3\cdot12\cdot768\cdot64 = 3\cdot768^2 = 1\,769\,472$ 个参数，加上 $W_O$ 的 $768^2 = 589\,824$；总计 $4d^2 = 2\,359\,296$（另加 $4d = 3\,072$ 个偏置）。一个大小为 768 的头，参数量完全相同。差别在计算：12 个独立的 $T\times T$ 权重矩阵，各来自 64 维的分数，而不是一个。

## 例题 4.7——计算 GPT-2 small 的参数量

**问题。** GPT-2 small 有 $d = 768$、$L = 12$ 个区块、词表大小 $V = 50\,257$、最大长度 $T_{\max} = 1\,024$、学习的位置嵌入，以及绑定的反嵌入。精确计算它的参数量。

**解答。** 每个区块：

| 部分 | 公式 | 数量 |
|---|---|---|
| 注意力 $W_{QKV}$ 与偏置 | $3d^2 + 3d$ | 1 771 776 |
| 注意力输出 $W_O$ 与偏置 | $d^2 + d$ | 590 592 |
| MLP $W_1$（$4d\times d$）与偏置 | $4d^2 + 4d$ | 2 362 368 |
| MLP $W_2$（$d\times4d$）与偏置 | $4d^2 + d$ | 2 360 064 |
| 两个层归一化（各有增益与偏置） | $4d$ | 3 072 |
| **区块合计** | $12d^2 + 13d$ | **7 087 872** |

十二个区块：85,054,464。词元嵌入 $Vd = 38\,597\,376$；位置 $T_{\max}d = 786\,432$；最后的层归一化 $2d = 1\,536$；绑定的反嵌入 0。**总计：124,439,808。** 实验室的 `test_gpt2_small_parameter_count` 会以这个数字检查你的公式。约 31% 的参数在嵌入表中——对小模型而言比例很高，对大模型而言则很小。

## 例题 4.8——长度 1,024 时的计算量与内存

**问题。** 对 GPT-2 small 的一个区块、一条 $T = 1\,024$ 个词元的序列，计算 (a) 投影与 MLP 的前向 FLOPs，对比注意力分数与混合的 FLOPs；(b) 两者相等的长度；(c) 若以 16 比特浮点数直接存储注意力权重矩阵所需的内存；(d) 整个模型的 KV 缓存内存。

**解答。** (a) 投影（$4d^2$ 个参数）与 MLP（$8d^2$）每个词元每个参数约 2 FLOPs：$2\cdot12d^2\cdot T = 24Td^2 = 1.45\times10^{10}$。分数 $QK^{\top}$ 与混合 $AV$ 各需 $2T^2d$：合计 $4T^2d = 3.22\times10^{9}$。
(b) $24Td^2 = 4T^2d \iff T = 6d = 4\,608$。短于这个长度时，逐词元的层占主导；长于它时，注意力占主导（图 4.4）。
(c) 12 个头 × $1024^2$ 个权重 × 2 字节 $= 25.2$ MB（每区块每条序列）。
(d) $2\times L\times T\times d\times 2$ 字节 $= 2\cdot12\cdot1024\cdot768\cdot2 = 37\,748\,736$ 字节 $\approx 37.7$ MB（每条序列；[KV 缓存](/zh-cn/atlas/nodes/mech-kv-cache/)）。

![d = 768 时，一个 Transformer 区块的前向 FLOPs 对序列长度的双对数图：投影与 MLP 随 T 线性增长，注意力分数与混合随 T 平方增长，两者在 T = 6d = 4608 相交。](/figures/u04-flops-crossover.svg)

## 例题 4.9——分块精确计算 softmax

**问题。** 对一个查询，分数为 $(1, 3, 2)$、标量值为 $(10, 20, 30)$，计算注意力输出——先直接计算，再把键分成两块 $\{1, 2\}$ 与 $\{3\}$ 处理，只保留执行中的最大值 $m$、归一化分母 $\ell$ 与未归一化的输出 $o$。

**直接计算。** 权重 $e^{s}/\sum e^{s} = (0.0900, 0.6652, 0.2447)$；输出 $0.900 + 13.305 + 7.342 = 21.547$。

**分块计算。** 第 1 块（分数 1、3）之后：$m = 3$，$\ell = e^{1-3} + e^{3-3} = 1.1353$，$o = 10e^{-2} + 20 = 21.3534$。
第 2 块（分数 2）：新的最大值为 $m' = \max(3, 2) = 3$，所以旧的总和不需重新缩放（$e^{m - m'} = 1$）；加入新项：$\ell' = 1.1353 + e^{2-3} = 1.5032$，$o' = 21.3534 + 30e^{-1} = 32.3897$。输出 $o'/\ell' = 21.547$ ✓。

如果之后某一块有更大的分数，旧的 $\ell$ 与 $o$ 会先乘上 $e^{m - m'}<1$，再加上新项。这种**在线 softmax（online softmax）**（[Milakov & Gimelshein 2018](/zh-cn/references/#milakov-2018)）是精确的，从不存储完整的一行权重，也是考量 IO 的注意力核心的基础（§4.8.1）。
