## 1.1 问题

2017 年，一组研究者拿一个标准的图像分类网络与一份含 50,000 张标注照片的标准数据集，做了一件奇怪的事：他们**随机打乱标签**，于是一张船的照片可能被标成“青蛙”，一张青蛙的照片被标成“卡车”（[Zhang et al. 2017](/zh-cn/references/#zhang-2017)）。然后照常训练网络。

网络在**训练集上达到 100% 准确率**。它记住了 50,000 组任意的配对。在新照片上，它的准确率是 10%——等于在十个类别中随机乱猜。同一个网络用*正确*标签训练时，在新照片上能达到很高的准确率。

两次训练使用相同的架构、相同的参数量、相同的优化器，训练准确率也相同。只有其中一次学到了能转移到未见情况的东西。所以：

- **训练表现无法告诉你模型是否学到了东西。** 两次训练在训练集上都是完美的。
- **模型大小也无法告诉你。** 两次用的是同一个网络。
- 造成差别的，是*训练数据与新数据之间的关系*——在随机标签的实验中，根本没有可以利用的关系。

本单元要问的是底下的问题：**为什么经验能改善对从未见过情况的表现？** 以及实践中的配套问题：**你怎么知道它真的改善了？**

我们用一个可以完整研究的最简单学习者来回答：一张统计文本中哪个字符接在哪个字符后面的表——**二元语法语言模型（bigram language model）**。它单独使用时太简单、不实用，但本单元的每个概念——损失、让学习成为可能的假设、训练表现与保留数据表现之间的落差、基线、量测数字的不确定性——都能在它身上清楚看见，而且之后每个单元都原封不动地重复使用这些概念。同一张表也是[主干项目](/zh-cn/spine/)的第一个阶段，也就是你将贯穿全书打造的小型语言模型。

:::note[继续阅读前先预测]
一个二元语法模型以计数方式拟合 2,000 个字符的儿童故事，再在同一来源、另外 43,000 个字符的故事上评估。它在训练文本上的平均损失是 2.06 nats／字符。它在新文本上的损失会更低、差不多，还是更高——大约差多少？若训练字符增加到 385,000 个，会有什么改变？（例题 1.4 与实验 1.2 给出答案。）
:::

## 本单元构建的内容

1. **从硬币到语言模型**（§1.2）。把学习看成估计概率分布；对数损失以及它为何是正确的评分方式；均匀基线 $\ln V$；最大似然就是计数；零计数与平滑；训练、验证与测试数据的纪律。
2. **类推的数学**（§1.3）。总体风险与经验风险；“交叉熵 = 熵 + KL 散度”的分解；推导最大似然；把平滑看成贝叶斯推断；集中不等式，以及为什么在许多模型中挑选需要新的数据；保留数据数字的不确定性。
3. **一般理论**（§1.5）。均匀收敛与模型容量、偏差–方差分解、没有免费午餐定理，以及为什么古典的容量论证无法解释现代网络。
4. **留下的问题**（§1.7）。二元语法无法把关于一个字符学到的东西转移到相似的字符上。这个限制就是[单元 02](/zh-cn/core/unit-02/) 的问题。

## 先修知识

- **概率：** 离散分布、期望值、独立性、大数法则（于 §1.2.2 陈述）。
- **微积分：** 对数与指数；一个拉格朗日乘子（§1.3.3，当场说明）。
- **程序：** 实验需要 NumPy 数组与索引操作。

不假设任何先前的单元；全书的论证从这里开始。
