## 计算

**11.1 ★ [不使用 AI]** 在 $c = 60$、$d_h = 18$ 的手工电路中，分别计算在有 4、16 与 1 000 个可见键的位置上，对预定键的注意力权重。

**11.2 ★ [不使用 AI]** 以 $\lambda = 10$，且目前词元的嵌入对其自身 logit 贡献 1，计算在 $V = 9$、其他所有 logits 为 0 时正确词元的概率。$\lambda = 3$ 时如何变化？

**11.3 ★** 一个探针在真实标签上得到 88%，在对照任务上得到 85%；另一个得到 75% 与 52%。哪一个显示了较强的表示证据，为什么？

**11.4 ★** 消融一个头使损失从 0.20 升到 0.35；在同一层中消融三个随机选出的头，平均使损失升到 0.24。可以得出什么结论，不能得出什么？

**11.5 ★★** 计算手工电路中头 1.0 的 QK 与 OV 电路的秩，并写出限制在词元嵌入上的 $V\times V$ 表 $E\,W_QW_K^{\top}E^{\top}$。为什么它是零？归纳头的选择性从何而来？

**11.6 ★★** 被破坏之执行的损失为 8.77，干净执行为 0.0004，修补组件 $c$ 得到 4.4。$c$ 承载了多少比例的效应？再做什么修补能检验其余部分是否流经另一个组件？

## 部分解答

- **11.1** 分数 $60/\sqrt{18} = 14.14$；权重 $e^{14.14}/(e^{14.14} + n - 1)$：$n = 4$ 时为 $1 - 2.2\times10^{-6}$，$n = 16$ 时为 $1 - 1.1\times10^{-5}$，$n = 1\,000$ 时为 $1 - 7.2\times10^{-4}$。
- **11.2** Logits：10（正确）、1（目前词元）、0（其他七个）：$p = e^{10}/(e^{10} + e + 7) = 0.9996$。$\lambda = 3$ 时：$e^3/(e^3 + e + 7) = 0.674$。
- **11.3** 第二个：选择性 23 个百分点，对 3 个百分点。
- **11.6** $(8.77 - 4.4)/(8.77 - 0.0004) = 0.50$：效应的一半。把其他组件与 $c$ 一起修补、也分别修补，以找出其余部分。
