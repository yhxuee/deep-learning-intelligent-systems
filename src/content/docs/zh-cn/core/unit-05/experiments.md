## 实验 5.1——噪声与延迟的取舍

**检验：** §5.2.6。**预测：** 对 $\alpha \in \{0.5, 0.9, 0.99\}$，EMA 作用在纯噪声上时输出的实测方差是 $\sigma^2$ 的几倍。

**步骤。** 产生 $10^5$ 个 $\mathcal N(0,1)$ 噪声样本；分别以各个 $\alpha$ 滤波；舍弃前 $10/(1-\alpha)$ 个样本；度量方差。再对无噪声的阶跃滤波，度量到达 95% 的时间。

**观察：** 方差与 $(1-\alpha)/(1+\alpha)$ 相差在几个百分点内；响应时间符合 $\ln 0.05/\ln\alpha$。接着复现图 5.1。

## 实验 5.2——离散化何时爆炸

**检验：** §5.2.8。**预测：** 前向欧拉法在 $\Delta t/\tau \in \{0.5, 1.5, 1.99, 2.01, 2.5\}$ 时，哪些在 200 步内保持有界？

**步骤。** 以常数输入 $x_t = 1$、$h_0 = 0$ 迭代 $h_t = (1-\Delta t/\tau)h_{t-1} + (\Delta t/\tau)x_t$；同时迭代 $\alpha = e^{-\Delta t/\tau}$ 的精确更新。

**观察：** $1 < \Delta t/\tau < 2$ 时有界振荡（$\alpha$ 为负但会衰减），超过 2 时增长；精确更新在每种情况下都收敛到 1。

## 实验 5.3——特征值就是记忆模态

**检验：** §5.3.3。**预测：** 固定一个随机可逆的 $V$，令 $A=V\,\mathrm{diag}(0.5,0.95)\,V^{-1}$，并选择让两个特征模态系数都不为零的 $B,C$。10 步后哪个模态主导？在你选的坐标中约差几倍？

**步骤。** 在实验室中实现 `convolution_kernel(A, B, length)`，在随机输入上与 `recurrence_loop` 比较（测试 `test_convolution_equivalence_with_zero_initial_state`），并画出 $CA^jB$。

**观察：** 慢速模态同时被 $B$ 激发、被 $C$ 观测时，渐近速率才是 $0.95^j$；早期形状与系数则依赖 $V,B,C$。作为反向对照，选择能消去慢速模态的 $B$ 或 $C$，确认此时由 $0.5^j$ 主导。存在于 $A$ 的特征值，不一定出现在输入—输出核里。

## 实验 5.4——瞬态增长

**检验：** §5.3.5。**预测：** 对 $A_c = \begin{pmatrix}0.9 & c\\0&0.9\end{pmatrix}$，$c \in \{0.5, 5, 50\}$，$\|A_c^t\|_2$ 的峰值以及出现在第几步。

**步骤。** 使用 `influence_norms(A, 200)`。

**观察：** 对这些 $c$，整数峰值应在第 9--10 步附近。非对角项近似 $|c|\,t\,0.9^{t-1}$，峰值在 $t^*=-1/\ln0.9\approx9.49$，与 $c$ 无关；但**精确谱范数**也包含对角项，所以最大化步骤仍可能随 $c$ 略变。请回报精确的离散峰值，不要直接宣称位置不变。

## 实验 5.5——随时间传递的梯度

**检验：** §5.3.7。**预测：** 先使用受控的线性递推 $A=0.9Q$，其中 $Q$ 为正交矩阵。预测 $\log_{10}\|\partial h_t/\partial h_k\|_2$ 对 $t-k$ 的斜率。接着在 tanh RNN 中使用 $W=0.9Q$，分别输入 (a) 让状态维持在零附近的小输入，以及 (b) 让状态饱和的大输入。

**步骤。** 仿照 `figures/make_figures.py` 中的 `u05_bptt_gradient_decay` 累积雅可比矩阵乘积。比较各情况时使用相同的 $Q$、初始状态与输入序列，并至少重复五个输入种子。再加入一个重缩放到谱半径 0.9 的非正规矩阵，作为“只看谱半径”预测的反例。

**观察：** $A=0.9Q$ 的斜率恰为每步 $\log_{10}0.9\approx-0.046$。零附近的 tanh 轨迹应接近此斜率；饱和时应更陡。非正规情况即使谱半径相同，也可能有瞬态。奇异值给出单步界线，真正量到的曲线则由沿轨迹、方向彼此对齐的雅可比矩阵乘积决定。

## 实验 5.6——闸让长距离依赖变得可学

**检验：** §5.3.8。**预测：** 可训练参数量相差不超过 5% 的传统 RNN 与 LSTM，分别能在多大的延迟 $D$ 下，学会在随机序列的最后一步输出第一个词元。把“LSTM 能撑得更远”当成待检验假说，不是验收条件。

**步骤**（可使用框架的自动微分）。词表含 8 个符号，$D\in\{5,10,20,50,100\}$。每次产生新的训练批量，但为每个 $D$ 与种子冻结另一份 10,000 笔的测试集。事先注册优化器、批量大小、梯度裁剪与 2,000 次更新预算；至少 99% 的**测试**准确率才算成功。选择隐藏宽度以匹配参数量，至少执行五个种子。LSTM 分别使用遗忘闸偏置 0 与 1。

**观察：** 画出成功概率与学习曲线对 $D$ 的关系，并保留每个种子的点。若 LSTM 没有撑得更远，先检查饱和、优化预算与参数匹配，再决定是否修改假说。正面与负面结果都要报告；单次执行不算证据（单元 12）。

## 实验 5.7——联想记忆的容量

**检验：** §5.5.3、定理 5.3。**预测：** 随机键、Hebbian 存储时，在 $n=d_k$ 与 $n=4d_k$ 的**误差均方根与值均方根之比**；再预测 delta 规则在低于、等于与高于 $d_k$ 时如何收敛。

**步骤。** 以下程序计算 Hebbian 的情况；请扩充为 delta 规则 $S \leftarrow S + (v - Sk)k^\top$，并对所有配对重复多轮。

```python
import numpy as np
rng = np.random.default_rng(0)
d_k, d_v = 16, 8
for n in [4, 16, 32, 64]:
    K = rng.normal(size=(n, d_k)); K /= np.linalg.norm(K, axis=1, keepdims=True)
    V = rng.normal(size=(n, d_v))
    S = V.T @ K                          # 外积 v_j k_j^T 的总和
    E = K @ S.T - V
    rms_ratio = np.sqrt(np.mean(np.sum(E**2, axis=1))) / np.sqrt(np.mean(np.sum(V**2, axis=1)))
    print(n, rms_ratio.round(3), np.sqrt((n - 1) / d_k).round(3))
```

**观察：** 均方根比值——不是逐项相对误差的平均——在期望下应符合 $\sqrt{(n-1)/d_k}$。对 delta 规则，跨多个种子记录残差随轮数的曲线与 $\kappa(K)$。当 $n<d_k$ 且键独立时，它可收敛到数值精度；接近 $n=d_k$ 时，随机方形键矩阵常有很差的条件数，收敛可能很慢且种子间差异很大。当 $n>d_k$，任意随机值通常不可能由线性记忆精确满足，因此会留下非零残差。不要把 200 轮后的某一个误差硬写成定理。

## 实验 5.9——语言之外：有噪声的传感器

**检验：** §5.2.6、§5.6.2（稳态的随机漫步卡尔曼滤波器会成为 EMA）。**预测：** 对程序噪声方差 $q=0.01$、测量噪声方差 $r=0.25$ 的随机漫步温度，使估计均方误差最小的 EMA 系数 $\alpha$。

**步骤。** 以 `sensor_stream` 产生 5,000 步；计算 `steady_state_kalman_alpha(q,r)`；扫描 $\alpha$，并在至少 50 条独立数据流上画出含置信区间的测试 MSE。接着把真实转移改为 $\mu_t=1.01\mu_{t-1}+w_t$，比较：(i) 原本按随机漫步调整的 EMA，(ii) 原始观测 $\alpha=0$，以及 (iii) 使用正确转移系数 1.01 的卡尔曼滤波器。同时报告绝对 MSE 与除以信号功率的误差。

**观察重点：** 在随机漫步模型下，总体最优值为 $\alpha\approx0.819$，也就是稳态卡尔曼值；有限样本扫描应在它附近波动。动态改变后，旧 EMA 会产生模型错置的延迟；原始观测仍保有测量噪声，但其误差不一定发散。真正相关的比较，是使用正确转移的卡尔曼滤波器。教训不是“每个固定滤波器都失败”，而是某个转移模型下的最优系数，在动态改变后未必仍然最优。
