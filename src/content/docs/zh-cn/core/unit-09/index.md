## 9.1 问题

预训练的主干模型读过 1 187 个故事，其中许多包含像“Ben had 2 eggs. Then Ben found 3 more. Now Ben has 5 eggs.”这样的句子。其中 30% 写出的答案是错的——语料产生器故意写入错误的和，就像充满噪声的网络文本。请预训练模型接续“Now Ben has ”，它最可能的单一答案只有 **32%** 的时候是对的；平均而言，它只把 **0.20** 的概率放在正确的数字上。

单元 01–08 的任何工具都修不好这件事。更多预训练只会更精确地拟合数据的错误率（单元 07，§7.7.1）。降低温度只会让模型原本的偏好更尖锐（单元 08，§8.7.6）。我们需要的是一个**不同的目标函数**：不是“预测文本”，而是“产生正确答案”。我们无法为每一个可能的提示写下正确答案作为训练目标——但我们可以*检查*模型产生的任何答案。一个在答案等于 $a + b$ 时返回 1、否则返回 0 的程序就是一个**奖励（reward）**，而模型的答案就是一个**动作（action）**。

从奖励而非目标值学习，就是强化学习。应用在预训练语言模型上时，它称为**后训练（post-training）**：今天的助理因此变得有帮助、推理模型因此以验证器训练、代理因此学会使用工具。它有一个典型的危险：模型优化的是*写出来的*奖励，而不是背后的意图。一个只错一个字符的检查器——把 `==` 写成 `>=`——就是另一个奖励，而模型会发现这一点。

:::note[继续阅读前先预测]
主干模型以每步 64 个提示、共 150 步做后训练。用正确的检查器时，你预期贪心解码的准确率是多少？用有错的检查器（只要答案至少为 $a + b$ 就给奖励 1）时，训练结束时的*训练奖励*会是多少？*真实*准确率又是多少？（例题 9.6–9.7。）
:::

## 本单元构建的内容

1. **从第一原理看如何从奖励学习**（§9.2）。动作与奖励；为什么采样挡住了一般的反向传播；分数函数技巧；基线；连续决策；留在预训练模型附近；从偏好学习。
2. **数学**（§9.3）。马尔可夫决策过程与回报；策略梯度定理；优势与价值函数；贝尔曼方程；KL 正则化奖励最大化的闭式最优解；由成对偏好得到的奖励模型；PPO 的截断目标函数；DPO 的推导；可验证奖励与群组基线。
3. **一般理论**（§9.5）。梯度估计量的方差与最优基线；把 KL 正则化强化学习看成贝叶斯推断；古德哈特定律与奖励过度优化。
4. **它留下的问题**（§9.7）。奖励是一种量测，优化它会暴露量测与意图之间的每一个落差。分数何时才是我们想要之物的证据？那是[单元 10](/zh-cn/core/unit-10/)。
