这些实验的目的不是取得最高奖励，而是学会哪一项测量能解释哪一个变化。每次执行都保留一张小型实验表：

| 字段 | 执行前就要记录的内容 |
|---|---|
| 问题 | 这次只检验哪一项主张？ |
| 预测 | 方向；能计算时也写下数值 |
| 干预 | 唯一刻意改变的因子 |
| 控制 | 种子、提示、参考策略、样本预算 |
| 测量 | 代理奖励**以及**独立任务指标 |
| 决策 | 什么结果会使你改变看法？ |

代码：[`spine/stage09_post_training.py`](https://github.com/yhxuee/deep-learning-intelligent-systems/tree/main/spine)，验证测试则在 `spine/test_spine.py`。以下指令假设你位于仓库根目录并使用随附的虚拟环境。若缺少阶段 07 检查点，先执行阶段 07 脚本。

## 实验 9.1——逐样本看见策略梯度

**问题。** REINFORCE 为何无偏却嘈杂？基线究竟改变了什么？

使用三动作多臂老虎机：

$$
\pi=(1/3,1/3,1/3),\qquad r=(1,0,0).
$$

对 logit $z_1$，一个样本给出

$$
g_1(a)=(r(a)-b)\left(\mathbf 1[a=1]-\pi_1\right).
$$

**先预测。** 分别对 $b=0$ 与 $b=1/3$ 算出 $g_1$ 的三个可能值；模拟前就预测平均与方差。例题 9.1–9.2 的已知答案是：两者平均皆为 $0.2222$，方差则为 $0.0988$ 与 $0.0247$。

**步骤。** 分别抽取 100、1,000、100,000 个动作。在每个样本量下回报样本平均、方差，以及与精确梯度的误差；以十个种子重复。

**解读。** 基线改变方差，不改变梯度期望。平均奖励基线在本例有帮助，但不要把它误当普遍排序：任意基线也可能增加方差。命题 9.2 给出逐分量、使方差最小的常数。

**失败检查。** 若加入常数基线后，平均出现系统性位移，实现可能错误地对采样基线微分，或让它依赖所选动作。

## 实验 9.2——看 KL 正则化如何倾斜分布

**问题。** 数值优化能否找回闭式最优解？$\beta$ 扮演什么角色？

使用

$$
\pi_{\mathrm{ref}}=(0.2,0.5,0.3),\qquad r=(1,0,0),
$$

因此

$$
\pi^\star(a)=\frac{\pi_{\mathrm{ref}}(a)e^{r(a)/\beta}}{\sum_b\pi_{\mathrm{ref}}(b)e^{r(b)/\beta}}.
$$

**先预测。** 计算 $\beta\in\{0.1,0.5,2\}$ 的 $\pi^\star$。哪一个最靠近参考分布？哪一个最集中于动作 1？

**步骤。** 先执行闭式测试：

```bash
LAB_IMPL=reference .venv/bin/python -m pytest spine/test_spine.py -k tilted -q
```

接着从三个不同初始分布出发，以精确梯度上升优化 logits。画出 $J_\beta$、$D_{\mathrm{KL}}(\pi\|\pi_{\mathrm{ref}})$ 与 $D_{\mathrm{KL}}(\pi\|\pi^\star)$。最后把精确梯度换成批量 16 与 256 的 REINFORCE。

**解读。** 步长稳定时，精确优化应从三个起点趋近同一个内部最优解。随机执行会在其附近波动；较大批量减少的是抽样噪声，不是目标设定错误。小 $\beta$ 让奖励差异占主导，大 $\beta$ 则保留较多参考分布。

**失败检查。** 确认实现的 KL 方向是 $D_{\mathrm{KL}}(\pi\|\pi_{\mathrm{ref}})$。反转方向会同时改变梯度与边界行为。

## 实验 9.3——后训练主干模型，并读懂每一个仪表

**问题。** 后训练提高了真实算术准确率，还是只提高画面上名为“奖励”的数字？

**先预测。** 随训练步数画四条曲线：采样训练奖励、留出贪心准确率、留出正确数字的平均概率，以及相对冻结参考策略的 KL。先预测各自的变化方向，再给合理范围，不要强求每一步单调。

**步骤。** 从 `spine` 目录执行：

```bash
cd spine
../.venv/bin/python stage09_post_training.py --steps 150
```

随附的决定性设定可作为方向参考，不是普遍基线：预训练模型的留出贪心准确率约为 $0.32$；精确奖励的 REINFORCE 与 DPO 分别达到约 $0.82$ 与 $0.78$。以种子 0–4 重复，回报平均、标准差与每一个各个结果。

**解读。** 贪心准确率与平均 $p(\text{正确})$ 回答不同问题：前者问哪个词元胜出，后者问正确答案取得多少概率质量。KL 测量相对参考策略的改变，不是正确性；较大 KL 可能伴随进步、伤害，或两者同时发生。

**失败检查。** 不要用更新时抽到的提示做评估。训练前冻结留出提示，并让所有方法与种子使用完全相同的提示。

## 实验 9.4——调整 KL“牵绳”，但不要把它叫作安全

**问题。** KL 系数如何取舍任务进步与分布改变？

**先预测。** 对 $\beta\in\{0,0.01,0.05,0.5,5\}$，排列可能的更新幅度。**不要**预测最小 $\beta$ 必然有最高留出准确率；优化噪声与过度拟合都可能打破这个排序。

**步骤。** 固定初始化、提示、种子、批量大小、步数与学习率。对每个 $\beta$ 记录：

- 算术贪心准确率与 $p(\text{正确})$；
- 算术提示上的 KL；
- 冻结非算术故事集上的下一字符 NLL；
- 熵与每个输出数字的频率。

画准确率对 KL，而不只画准确率对 $\beta$。至少以五个种子重复。

**解读。** $\beta$ 是类似拉格朗日乘子的取舍参数，不是安全旋钮。两次平均 KL 相同的执行，可能伤害不同能力。若算术进步而故事 NLL 恶化，实验就揭露了单看算术奖励无法看见的干扰。

**失败检查。** KL 数值只有在方向、平均方式、词元范围与对数底数都已记录时才有意义。四项缺一不可。

## 实验 9.5——离线配对与目前策略样本

**问题。** 固定偏好数据集何时会过时？

**先预测。** 建立两种配对：“简单”配对的被拒答案远离正确数字；“边界附近”配对则只差一。模型学会避开明显错误数字后，哪一组仍会提供有用梯度？

**步骤。** 比较三种预算：

1. 在一组固定简单配对上做 DPO；
2. 在一组固定边界配对上做 DPO；
3. 使用目前策略的新样本与精确检查器做 REINFORCE。

配对提示评估次数，并分开回报实际时间与检查器调用次数。不同算法的一个“步骤”不是公平的计算单位。追踪留出准确率、KL，以及训练配对中策略已强烈偏好赢家者所占比例。

**解读。** 固定配对使实验容易复现；新样本则追踪目前策略所犯的错。DPO 的策略更新不需要在策略采样，但配对数据仍必须来自某处。没有检查器时，REINFORCE 不会自行解决任务；没有可信比较来源时，DPO 也不会。

**失败检查。** 若三个方法看到不同提示，或使用不同数量的反馈查询，就把比较标成“系统层级”，不要称为只比较优化器。

## 实验 9.6——在策略之前找出奖励破解

**问题。** 只检查检查器，能不能先预测优化器会找到的“聪明”解法？

对目标 $t=a+b$，稽核三个候选奖励：

```python
reward_a = int(answer >= t)
reward_b = int(answer in "0123456789")
reward_c = int(abs(answer - t) <= 1)
```

**先预测。** 对每个可能目标 $t\in\{2,\ldots,9\}$，枚举十个数字动作，标出使各奖励最大的动作。

**步骤。** 分别以三个检查器训练同一策略。每个检查点都记录候选奖励与精确比对准确率，并依目标记录输出直方图。

**解读。** 检查器 (a) 奖励大数字，可能塌缩到 9；(b) 只分辨数字与非数字，在数字之间完全没有正确性信号；(c) 除边界外都定义三个数值的接受带，所以精确答案只是多个同奖励行为之一。预训练分布与优化器会决定哪个被接受的行为胜出。

**失败检查。** 训练前先用真值表、边界案例、等价有效形式与对抗输出测试检查器。策略不应成为评估器第一个认真的用户。

## 实验 9.7——建立检查器稽核集

**问题。** 一个刻意组织的小型稽核，能否预测平均验证奖励掩盖的失败？

**先预测。** 产生例子前，先写出至少五个失败族群：正确答案、差一、太大、太小、非数字、格式错误；若答案格式扩充，再加入 `05` 与 `5` 这类等价形式。

**步骤。** 建立字段为 `prompt`、`candidate`、`intended_valid`、`checker_reward`、`failure_family` 的表格。不要从训练策略采样，并要求：

- 每个族群含多个目标；
- 同时有普通与边界目标；
- 对安全关键的无效案例，假阳性必须为零；
- 回报混淆矩阵，不只回报准确率。

以这个稽核集检查精确检查器与实验 9.6 的三个有错检查器。接着在任何策略训练**之前**，判定哪些检查器可以使用。

**解读。** 随机验证估计某个抽样分布下的平均行为；结构化稽核则询问已知语义要求是否有被表示。两者都需要：稽核找出具名漏洞，随机评估估计其患病率。

**失败检查。** 通过有限稽核不代表检查器完整。记录尚未涵盖的输入空间，并在训练期间持续保留独立正确性评估。这项纪律就是通往单元 10 的桥梁。

## 最低限度的实验报告

可信报告应包含：预测、确切指令或程序修订、检查点身分、种子、提示切分、样本或反馈预算、所有代理与独立指标、逐种子原始值，以及至少一次失败或意外的执行。“奖励上升”还不是结论；你必须先说清楚是哪一个奖励、由谁计算，以及哪一个独立测量跟着变化。
