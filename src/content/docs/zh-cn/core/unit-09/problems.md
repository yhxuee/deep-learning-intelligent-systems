## 计算

**9.1 ★ [不使用 AI]** 对 logits $z = (1, 0, 0)$ 与奖励 $r = (0, 1, 0)$，计算 $\pi$、$J$ 与精确梯度 $\partial J/\partial z$。

**9.2 ★ [不使用 AI]** 对 $\pi_{\text{ref}} = (0.5, 0.5)$、$r = (1, 0)$、$\beta = 1$，计算倾斜最优解 $\pi^\star$。

**9.3 ★** 奖励模型给出 $r(y_w) = 2.0$、$r(y_l) = 1.5$。Bradley–Terry 指派的偏好概率是多少？这个配对的损失是多少？

**9.4 ★** 一个两状态链每步支付奖励 1，且回合永不结束。分别以 $\gamma = 0.9$ 与 $\gamma = 0.99$ 计算 $V$。

**9.5 ★★** 训练已使 $\ln\frac{\pi(y_w)}{\pi_{\text{ref}}(y_w)} = 0.5$、$\ln\frac{\pi(y_l)}{\pi_{\text{ref}}(y_l)} = -0.5$。分别以 $\beta = 0.1$ 与 $\beta = 1$ 计算 DPO 损失。

**9.6 ★★** 在例题 9.2 中，计算第 1 个分量依命题 9.2 的最优基线，以及所得的方差。

## 推导

**9.7 ★ [不使用 AI]** 推导分数函数估计量 $\nabla\mathbb{E}_\pi[r] = \mathbb{E}_\pi[r\nabla\ln\pi]$，并证明减去常数基线仍然无偏。

**9.8 ★★ [不使用 AI]** 证明命题 9.1，并证明最大值为 $\beta\ln Z$。

**9.9 ★★ [不使用 AI]** 由命题 9.1 与 Bradley–Terry 模型推导 DPO 损失。

**9.10 ★★** 推导 DPO 损失对单词元答案之 logits 的梯度，并证明 softmax 项相消。

**9.11 ★★** 推导序列的逐词元 REINFORCE 梯度，以及把 $G_0$ 换成 $G_t$ 的因果性改进。

## 证明

**9.12 ★★** 证明命题 9.2，并证明当 $(\partial_i\ln\pi)^2$ 与 $r$ 独立时，平均奖励是最优的。

**9.13 ★★** 证明在每个奖励上加上以势能为基础的塑形项 $\gamma\Phi(s') - \Phi(s)$，不会改变 MDP 的最优策略。

**9.14 ★★★** 证明最大化 $J_\beta$ 等价于最小化 $\mathrm{KL}(\pi\,\Vert\,\pi^\star)$，并说明为什么这使后训练具有寻找众数的性质。

**9.15 ★★★** 构造一对奖励 $r$ 与 $r^\dagger$，使它们在预训练策略以大于 0.01 的概率采取的每个动作上都一致，而最大化 $r$ 却会最小化 $r^\dagger$。

## 实现与设计

**9.16 ★ [不使用 AI]** 凭记忆实现 `reinforce_grad`，并通过主干项目的有限差分测试。

**9.17 ★★** 为阶段 09 加入学习出来的价值基线（以最终隐藏状态的线性函数预测奖励），并与批量上的留一法基线比较方差与速度。

**9.18 ★★** 实现群组相对优势：每个提示采样 8 个答案，以各提示的平均奖励作为其基线。与批量上的留一法基线比较，并量测单纯群组平均的 $(G-1)/G$ 偏差。

**9.19 ★★** 由主干项目的算术建立偏好数据集：以检查器标注配对，但翻转 20% 的标签。训练 DPO，回报标签噪声如何影响结果。

**9.20 ★★★** 为主干模型设计“写一个五岁小孩会喜欢的短故事”的奖励。列出策略可以破解它的三种方式，以及你如何检测每一种。

## 部分解答

- **9.1** $\pi = (e, 1, 1)/(e + 2) = (0.576, 0.212, 0.212)$；$J = 0.212$；梯度 $\pi_k(r_k - J) = (-0.122, 0.167, -0.045)$。
- **9.2** $\pi^\star\propto(0.5e, 0.5) = (0.731, 0.269)$。
- **9.3** $\sigma(0.5) = 0.6225$；损失 $0.474$。
- **9.4** $V = 1/(1-\gamma)$：10 与 100。
- **9.5** $u = \beta\cdot1$：$\beta = 0.1$ 时损失为 $\ln(1 + e^{-0.1}) = 0.644$；$\beta = 1$ 时为 $\ln(1 + e^{-1}) = 0.313$。
