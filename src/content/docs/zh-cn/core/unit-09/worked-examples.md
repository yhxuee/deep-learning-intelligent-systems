## 例题 9.1——精确的策略梯度

**设定。** 三个动作，logits $z = (0, 0, 0)$，所以 $\pi = (\tfrac13, \tfrac13, \tfrac13)$；奖励 $r = (1, 0, 0)$。

**梯度。** $\partial J/\partial z_k = \pi_k(r_k - \pi^{\top}r)$，其中 $\pi^{\top}r = \tfrac13$：$(\tfrac13\cdot\tfrac23,\ \tfrac13\cdot(-\tfrac13),\ \tfrac13\cdot(-\tfrac13)) = (0.2222, -0.1111, -0.1111)$。

**解读。** 被奖励之动作的 logit 上升的量，是其他每个 logit 下降量的两倍，且各分量总和为零——对所有 logits 加上同一个常数不会改变任何事。主干项目的测试抽出 400 000 个动作，检查 REINFORCE 的平均在 0.004 以内复现这个向量。

## 例题 9.2——基线的作用

**设定。** 例题 9.1，每次估计只用一个样本，看 $\hat g = (r_a - b)(e_a - \pi)$ 的第 1 个分量。

| 基线 $b$ | 若 $a = 1$ 的 $\hat g_1$ | 其他情况的 $\hat g_1$ | 平均 | 方差 |
|---|---|---|---|---|
| 0 | $1\cdot\tfrac23 = 0.667$ | $0$ | 0.2222 | 0.0988 |
| $\pi^{\top}r = \tfrac13$ | $\tfrac23\cdot\tfrac23 = 0.444$ | $(-\tfrac13)(-\tfrac13) = 0.111$ | 0.2222 | 0.0247 |

**解读。** 平均相同，方差只剩四分之一。没有基线时，没得到奖励的样本不带任何信号；有了基线，它们会把自己的动作往下推，这也是信息。

## 例题 9.3——倾斜的最优解

**设定。** 参考分布 $\pi_{\text{ref}} = (0.2, 0.5, 0.3)$，奖励 $r = (1, 0, 0)$。命题 9.1 给出 $\pi^\star\propto\pi_{\text{ref}}e^{r/\beta}$。

| $\beta$ | $\pi^\star$ | 最优值 $\beta\ln Z$ |
|---|---|---|
| 0.1 | (0.9998, 0.0001, 0.0001) | 0.839 |
| 0.5 | (0.6488, 0.2195, 0.1317) | 0.412 |
| 2.0 | (0.2919, 0.4426, 0.2655) | 0.244 |

**解读。** 在 $\beta = 0.5$ 时，被奖励之动作的胜算乘上 $e^{2} = 7.39$；没被奖励的动作保留参考分布中 5 : 3 的比例。大的 $\beta$ 几乎不移动参考分布；小的 $\beta$ 趋近奖励的 argmax，并忘掉参考分布所知道的其他一切。

## 例题 9.4——手算贝尔曼方程

**设定。** 从状态 A 出发，唯一的动作以奖励 0 通往状态 B；从 B 出发，回合以奖励 1 结束。折扣 $\gamma = 0.9$。

**价值。** $V(B) = 1$；$V(A) = 0 + 0.9\cdot V(B) = 0.9$。若 A 还有一个奖励为 0、回到 A 的“停留”动作，最优性方程 $V(A) = \max(0.9\,V(B),\ 0.9\,V(A))$ 仍给出 $V(A) = 0.9$：永远等待的价值是 $0.9^k\to0$，绝不会比前进更多。

**解读。** 折扣使延迟的奖励价值较低，而贝尔曼方程一步一步地把价值向后传递——这是时间反向传播（单元 05）在动态规划中的对应。

## 例题 9.5——偏好的数值

**Bradley–Terry。** 若 $r(y_w) - r(y_l) = 1$，则 $P(y_w\succ y_l) = \sigma(1) = 0.7311$，该配对的奖励模型损失为 $-\ln0.7311 = 0.3133$。

**初始化时的 DPO。** 当 $\pi = \pi_{\text{ref}}$，边际 $u = 0$，每个配对的损失都是 $\ln2 = 0.6931$。

**一步之后。** 若策略已把 $\pi(y_w)/\pi_{\text{ref}}(y_w)$ 加倍、把 $\pi(y_l)/\pi_{\text{ref}}(y_l)$ 减半，则在 $\beta = 0.1$ 时，$u = 0.1(\ln2 + \ln2) = 0.1386$，损失为 $\ln(1 + e^{-0.1386}) = 0.6262$。

**解读。** DPO 隐含的回应奖励，是 $\beta$ 乘上该回应相对于参考的对数概率比；损失只在乎两个回应之比值的*差*。

## 例题 9.6——后训练主干模型

**设定。** 400 个留出的算术提示（“… Now Ben has ”），答案为一位数。

| 模型 | 贪心准确率 | 平均 $p$(正确) | 答案位置相对参考的 KL |
|---|---|---|---|
| 预训练（阶段 07） | 0.32 | 0.20 | 0 |
| REINFORCE，奖励 $1[\text{ans} = a+b]$ | **0.79** | **0.72** | 1.34 |
| 在（正确、随机错误）配对上做 DPO | 0.78 | 0.76 | — |

**解读。** 以可验证奖励训练 150 步，让模型从模仿语料中 30% 错误的算术，变成五次有四次答对。以同一个检查器构造的配对训练的 DPO，不需采样就达到几乎相同的准确率。（这些都是单次执行。v2.0 使用有偏差的批量平均基线时，REINFORCE 达到 0.82 与 0.80；这次更正把优势缩放了 $64/63$，期望梯度的方向不变，结果却移动了 0.03——正是单元 10 与单元 12 所警告的、执行之间的差异幅度。）两者都没有达到 100%：KL 锚定把策略拉在一个经常自信地答错的参考附近，而一个以 1 187 个故事训练的 3 层模型还没有把加法学到可靠答对的程度——后训练只能重新加权模型本来就能产生的东西（§9.5.3）。

## 例题 9.7——一个字符的错误造成的奖励破解

**设定。** 与例题 9.6 相同，但只要答案*至少*为 $a + b$，检查器就返回 1——本来要写 `==`，却写成 `>=`。

| | 训练奖励（最后 20 步） | 训练样本的真实准确率 | 留出集贪心准确率 | 平均 $p$(正确) |
|---|---|---|---|---|
| 有错的检查器 | **0.99** | 0.07 | **0.09** | 0.11 |

**解读。** 回答“9”对任务中的每个提示都满足“至少 $a+b$”（和从不超过 9）。策略在 150 步内就发现了这一点：它的奖励近乎完美，而算术比后训练之前差得多（0.09 对 0.32）。由有错检查器算出的每一个监控数字都说这次训练很成功。只有一个*独立的*度量——留出提示上的真实准确率——揭露了真相。这就是通往单元 10 的桥。

## 例题 9.8——解读一个 KL

**设定。** 例题 9.6 的 REINFORCE 执行结束时，答案位置的 $\mathrm{KL}(\pi\,\Vert\,\pi_{\text{ref}}) = 1.34$ nats。

**一个较低的参考点。** 从一个给正确数字 0.2 的参考分布出发，把 0.8 的概率移到正确数字上、其余按比例保留，代价是 $0.8\ln\frac{0.8}{0.2} + 0.2\ln\frac{0.2}{0.8} = 0.832$ nats。

**解读。** 量到的 1.34 更大：策略也重新塑造了剩余概率在错误数字之间的分配方式。KL 是改变的总预算——它不说明*做了哪一种*改变，这就是为什么有错的执行（KL 1.43）和正确的执行（KL 1.34）在这个数字上看起来差不多。单元 11 问的是内部改变了什么。
