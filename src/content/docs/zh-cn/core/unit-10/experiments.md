这些实验要求你在看到结果**之前**先选定主张，借此学习评估。核心程序位于 [`spine/stage10_eval.py`](https://github.com/yhxuee/deep-learning-intelligent-systems/tree/main/spine)，合成验证案例位于 `spine/test_spine.py`。最后一项实验使用 `labs/beyond_language.py`。

每项实验都建立一份包含五个字段的简短记录：

1. **预测**——执行前写下方向与大致大小；
2. **独立单位**——故事、字符、提示、训练执行或院区；
3. **估计目标**——想了解哪个总体量；
4. **结果**——估计值、区间与诊断图表；
5. **修正**——你改变了什么看法。

非预期结果不是失败的实验。看过结果后才修改假说，再假装早已预测，才是失败。

## 实验 10.1——先验证度量工具

**问题。** 评估程序能否恢复答案已知的量？

评估已训练模型之前，先用合成案例测试工具：

- 事件概率已知且校准良好的预测器；
- 置信度全部向上偏移 0.04 的同一预测器；
- 从平均值已知的指数分布重复抽样。

**写下预测。** 两个预测器的 ECE 应为何？对 $n\in\{10,30,60,200,1000\}$ 的自助法区间，你预期覆盖不足、过度覆盖，还是接近名目覆盖？

**步骤。** 从仓库根目录执行：

```bash
cd spine
python -m pytest test_spine.py -k stage10 -v
```

接着修改覆盖模拟的副本，让每个 $n$ 至少使用 1 000 次重复研究。记录

$$
\widehat{\operatorname{coverage}}
=\frac{\#\{\text{包含真实平均值的区间}\}}{\#\{\text{模拟研究}\}}。
$$

因为此估计本身也是二项比例，应附上 Monte Carlo 标准误

$$
\sqrt{\hat c(1-\hat c)/M}，
$$

其中 $M$ 是模拟研究次数。

**解读。** 校准良好案例的 ECE 应接近 0，统一过度自信案例应接近 0.04，差异来自 Monte Carlo 噪声。偏斜分布的百分位自助法在小 $n$ 时可能偏离名目覆盖，并随 $n$ 增加接近渐近目标；但单次有限模拟不一定单调。

**失效诊断。** ECE 案例失败时，检查分组边界以及置信度 1.0 是否被放入最后一组。若每个 $n$ 的覆盖率都恰好 95%，检查模拟是否在构建区间时意外重用了真实目标。

**实验后主张：**“这些合成案例没有否证实现”，而不是“实现对每种统计量都正确”。

## 实验 10.2——重采样故事，还是重采样字符？

**问题。** 把依赖字符当成独立，会产生多少虚假精度？

**预测。** 计算前先写下一个比值：

$$
\frac{\text{字符自助法区间宽度}}
{\text{故事自助法区间宽度}}。
$$

它会接近 1、远小于 1，还是大于 1？请用故事内依赖性解释。

**步骤。** 对阶段 07 留出 NLL：

1. 每个故事计算一个 NLL，再重采样 140 个故事；
2. 合并字符损失，再重采样各个字符；
3. 用不同产生器种子建立 20 份新留出集，分别打分数；
4. 比较两种区间宽度与生成集合之间的经验散布。

每份重新生成的集合都使用相同故事数与产生器设定。20 份集合的散布只是经验参考，不是“真实差异”；它本身也有抽样噪声。

**记录。** 回报每项分析表面上的观测数、两个区间宽度，以及 20 个集合平均的标准差。

**解读。** 若字符重采样窄得多，请解释为何庞大字符数没有产生同样多的独立观测。若两种宽度接近，检查故事是否几乎同质，或实现是否在重采样前意外先聚合了字符。

**延伸。** 再做一次群集自助法：抽取故事，并保留每个被抽故事中的所有字符。因为故事才是独立单位，它应与故事层级分析一致。

## 实验 10.3——偏移检测器不是表现预测器

**问题。** 哪些受控偏移伤害模型？可检测程度能预测伤害吗？

建立三组各 140 个故事，每次只改变一项因素：

1. 姓名在训练中未见；
2. 动物与对象未见；
3. 保留词语，但打乱句子顺序。

**预测表。** 执行前填写：

| 偏移 | 预测 NLL 变化 | 预测来源对偏移分类器准确率 | 提议理由 |
|---|---:|---:|---|
| 未见姓名 |  |  |  |
| 未见动物／对象 |  |  |  |
| 打乱句序 |  |  |  |

**步骤。** 针对每项干预修改 `make_tales.py` 的副本，冻结模型与评分程序。对每个集合：

- 回报逐故事平均 NLL 与故事自助法区间；
- 训练分类器区分普通留出故事与偏移故事；
- 在分类器自己的留出切分上评估，不使用其训练数据；
- 保存几个损失最高案例，进行质性检查。

**解读。** 分类器准确率高，表示两个分布在其特征空间中可区分，不代表模型损失一定大增。反过来，简单分类器难以检测的细微偏移，也可能正好命中脆弱特征而造成巨大伤害。

可以画出偏移可检测性对 NLL 变化，但不能从三个点推断普遍单调关系。

**反事实检查。** 若未见姓名造成高损失，将其换成等长随机字符串，再把熟悉姓名放到不熟悉位置。这些后续检查有助于区分新颖度、分词与位置假说，但仍未证明内部机制。

## 实验 10.4——拟合校准，但不要在拟合数据上评估

**问题。** 单一温度能否改善留出概率质量，同时维持准确率不变？

温度缩放把 logits $z$ 变成 $z/\tau$。$\tau>1$ 时分布较平，$\tau<1$ 时较尖。只要 $\tau$ 为正，argmax 预测不变。

**预测。** 根据例题 10.5 的可靠性表，预测拟合出的 $\tau$ 高于还是低于 1。再分别预测准确率、NLL、ECE 与中段置信度区间如何改变。

**步骤。** 依故事分割留出位置，不要把同一故事的字符随机混到两侧：

1. 在校准故事上最小化 NLL，拟合 $\tau$；
2. 冻结 $\tau$；
3. 在另一批评估故事上测量；
4. 回报前后的准确率、NLL、ECE 与完整可靠性表；
5. 重采样评估故事，为指标差值建立区间。

依故事分割可避免近似重复的上下文同时出现在两侧。

**解读。** 除非数值平手的打破方式改变，准确率应完全相同。NLL 与 ECE 不一定同向，因为 ECE 依赖分组，而且不是适当评分。全局温度可能改善主导区间，却使较小子群变差。

**消融。** 在同一批位置上拟合并评估温度。结果通常看起来更好；它与诚实分割之间的落差，估计了校准过度拟合。

## 实验 10.5——分开项目噪声与训练执行噪声

**问题。** 选到哪些测试故事造成的不确定性，与重新训练造成的不确定性，何者较大？

**预测。** 分别写下预期标准差：

- 一次阶段 04 执行内，跨留出 NLL 自助法重采样；
- 五次独立阶段 04 训练的平均留出 NLL。

**步骤。** 用不同初始化与数据顺序种子训练五次。固定架构、数据、步数与检查点击择规则。计算资源不足时，可以为**所有**执行一起减少步数，并把结果标成缩减计算研究。

每次执行都保留相同冻结测试集上的逐故事损失，再回报：

| 执行 | 平均 NLL | 项目自助法区间 |
|---|---:|---:|
| 1 |  |  |
| 2 |  |  |
| 3 |  |  |
| 4 |  |  |
| 5 |  |  |

另回报五个执行平均值之间的标准差。只有五次执行时，这个标准差本身很不确定，不要把三位小数当成稳定的方法性质。

**解读。** 任一来源都可能占主导。若执行差异小，那是关于这项设定与计算预算的证据，不是“种子永远不重要”的证明。若差异大，单次执行的方法比较尤其薄弱。

**延伸。** 使用两层自助法：先重采样执行，再于被选执行内重采样故事。把所得区间与只重采样项目的区间比较。

## 实验 10.6——植入泄漏，测试稽核而非事后聪明

**问题。** 哪些证据能揭露一半评估集进入了训练？

以普通训练数据加上 140 个留出故事中的 70 个，训练阶段 04 设定。先把泄漏故事身分放入封存文件，直到第一次分析完成才打开。

**预测。** 训练前先预测：

- 整体留出 NLL 变化；
- 泄漏与干净两半的损失差；
- 哪些现有污染检查会检测此事件。

**盲态第一阶段。** 不使用泄漏标签，评估全部 140 个故事。检查逐故事损失、与已记录训练语料的 n-gram 重叠，以及零假设适合此数据的模型式污染统计量。写下判定与证据。

**揭盲阶段。** 打开标签。比较泄漏与干净故事，并为差值建立区间。计算检测器在此植入案例上的敏感度与假阳性表现。

**解读。** 整体改善可能很像真正进步。知道泄漏身分的切分应揭露落差，但不是每种通用污染检验都保证抓到每种泄漏。例如，顺序检验问的是标准顺序熟悉度，不是任意成员暴露。

**最重要的产出。** 写下哪些产物使诊断成为可能：精确训练数据清单、项目识别码、逐项分数、时间戳记或模型似然存取权。从未保留的证据，无法靠检测器补回。

## 实验 10.7——在新院区做外部验证

**问题。** 一项特征能否改善内部验证，却伤害外部验证？

`labs/beyond_language.py` 中的 `multisite` 模拟三个结果患病率不同的训练院区与第四个留出院区。第三个特征像扫描器或院区假象：它追踪院区患病率，但院区关系改变后，对各个病人没有信息。

**预测。** 对使用与不使用假象的逻辑回归，预测下列交叉熵：

1. 来自三个训练院区的新病人；
2. 来自第四个院区的病人。

也预测分类器能以多高准确率区分训练院区与留出院区输入。

**步骤。** 先执行现有验证：

```bash
python -m pytest labs/test_beyond_language.py -k multisite -v
```

接着扩充实验，返回逐病人损失。于院区内重采样病人并回报区间。使用多个测试院区患病率与假象强度重复实验；固定信号特征。

**解读。** 假象可能在相关性稳定的环境中有帮助，当相关性改变时却造成伤害——这是 [Zech et al. 2018](/zh-cn/references/#zech-2018) 放射图像模型院区捷径的缩小版。领域分类器显示院区不同，是一项警示，不是模型使用假象的证明。应比较系数或干预假象以检验使用情形。

**决策边界。** 数据是合成的。本实验验证评估观念，不是临床系统。真实临床主张需要具代表性的多院区外部验证、院区层级不确定性、前瞻性工作流程证据与临床监督。
