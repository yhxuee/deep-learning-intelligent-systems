## 2.1 问题

[单元 01](/zh-cn/core/unit-01/) 结束于一个限制：计数表把每个符号都当成互不相关的索引，所以它无法把在某个上下文学到的东西，分享给相似的上下文。以下是这个限制的代价。读完仅仅 5,000 个字符的训练文本后，从前**四个**字符预测儿童故事的下一个字符：

- 以 4 个字符为上下文、尽可能平滑过的**计数表**，保留数据损失为 **1.11 nats／字符**。625 万种可能的上下文大多从未见过；对这些上下文，它只能把概率均匀分散。
- **神经 4 元语法（neural 4-gram）**——同样的四个字符，但每个先换成一个学习出的 16 维向量——达到 **0.98 nats**，只用 15,570 个参数。

同样的数据、同样的上下文、同样的损失函数。唯一的差别是预测之前*如何表示这四个字符*。用 385,000 个训练字符时，优势就消失了（0.52 对 0.54）：当数据相对于模型必须涵盖的情况数量而言很稀少时，表示最重要——而对任何有趣的任务，这种情况永远成立。

一个更古老、更鲜明的例子有相同的形状。平面上四个点，$(0,0)$ 与 $(1,1)$ 标为 0，$(0,1)$ 与 $(1,0)$ 标为 1——**XOR（互斥或）**问题。没有任何直线能把两种标签分开；座标 $(x_1, x_2)$ 上的线性分类器无论看到多少数据都解不了。加上第三个座标 $x_1x_2$，一个平面就能完美地分开它们。学习者没有任何改变。问题从不可能变得微不足道，是因为**表示（representation）**改变了。

本单元要问：**为什么表示的改变会改变学习的难度**——以及什么是*好的*表示。这个答案是全书的枢纽：深度网络首先是*学习*表示的机器，而单元 04–05 的每个架构，都是关于该共享什么、该忽略什么的设计。

:::note[继续阅读前先预测]
一个字符层级的模型为 50 个字符各学习一个 16 维向量，训练目标只是预测下一个字符。你预期哪些字符最后会最接近数字 `3`？最接近大写 `T`？最接近母音 `a`？写下你的猜测；例题 2.5 展示了主干模型学到什么。
:::

## 本单元构建的内容

1. **从第一原理看表示**（§2.2）。特征与线性读出；XOR；独热编码，以及为什么独热输入上的线性模型*就是*一张计数表；嵌入作为学习出的共享座标；分布假说；绑定的输入与输出嵌入；不需指数大表格的更长上下文。
2. **数学**（§2.3）。可分性；把嵌入查找看成矩阵乘积及其梯度；二元语法的秩 $d$ 分解；神经 n 元语法及其梯度；最优低秩近似；不变性与等变性。
3. **一般理论**（§2.5）。普遍逼近定理及其没有保证的事；Cover 计数定理；随机投影与 Johnson–Lindenstrauss 引理；群平均与等变映射；把嵌入看成隐式矩阵分解。
4. **留下的问题**（§2.7）。学习的表示没有封闭解。它的参数必须以基于梯度的搜索找到——这是[单元 03](/zh-cn/core/unit-03/) 的主题。

## 先修知识

- **来自单元 01：** 对数损失、最大似然、二元语法模型、保留数据评估。
- **线性代数：** 向量、内积、矩阵–向量与矩阵–矩阵乘积、秩；奇异值分解在用到时说明（§2.3.5）。
- **微积分：** 偏导数，以及两个函数合成的链式法则（一般情况由单元 03 发展；§2.3.3 只需要简单情况）。
