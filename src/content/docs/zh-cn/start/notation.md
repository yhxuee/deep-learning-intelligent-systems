每个单元都采用以下约定。若某个符号因长期惯例而有多种用法（例如 $\beta$），会在当地说明，并列在这里。

## 一般

| 符号 | 意义 | 首次使用 |
|---|---|---|
| $a, x, w$ | 标量与向量（小写、不用粗体）；维度会另外说明 | 01 |
| $W, A, Q, K, V$ | 矩阵（大写）；$X\in\mathbb{R}^{T\times d}$ 每一行对应一个位置 | 02 |
| $x_i$、$x_t$ | 第 $i$ 个样本，或位置／时间 $t$ 的词元／输入 | 01 |
| $\mathbf 1$ | 全为 1 的向量 | 04 |
| $e_y$ | 类别 $y$ 的独热（标准基底）向量 | 02 |
| $\odot$ | 逐元素乘积 | 03 |
| $\langle u, v\rangle = u^{\top}v$ | 内积 | 02 |
| $\lVert\cdot\rVert$ | 除非另有说明，向量为欧氏范数、矩阵为谱范数 | 03 |
| $\ln$ | 自然对数；所有信息量都以 **nats** 为单位 | 01 |

## 数据、模型与损失

| 符号 | 意义 | 首次使用 |
|---|---|---|
| $\mathcal{D} = \{(x_i, y_i)\}_{i=1}^n$ | 含 $n$ 个样本的训练集 | 01 |
| $p_{\text{data}}$ | （未知的）数据分布 | 01 |
| $\theta$ | 模型的全部可训练参数；$N$ 为其数量 | 01, 06 |
| $p_\theta(y\mid x)$ | 模型预测的分布 | 01 |
| $\ell(\theta; x, y)$ | 单一样本的损失，通常为 $-\ln p_\theta(y\mid x)$ | 01 |
| $L(\theta)$、$\hat L(\theta)$ | 总体损失与经验（训练）损失 | 01 |
| $V$ | 词表大小；$\ln V$ 为均匀预测器的损失 | 01 |
| $T$ | 序列长度（上下文） | 04 |
| $D$ | 训练词元数 | 06 |
| $H(p)$、$H(p, q)$、$\mathrm{KL}(p\,\Vert\,q)$ | 熵、交叉熵、KL 散度（Kullback–Leibler divergence） | 01 |

## 优化

| 符号 | 意义 | 首次使用 |
|---|---|---|
| $\nabla L$ | 梯度 | 03 |
| $\bar x = \partial L/\partial x$ | 中间量 $x$ 的伴随量（adjoint，反向模式） | 03 |
| $J_f$ | $f$ 的雅可比矩阵 | 03 |
| $\eta$ | 步长（学习率） | 03 |
| $B$ | 小批量大小 | 03 |
| $\beta_1, \beta_2$ | Adam 的动差衰减率 | 03 |
| $\lambda$ | 权重衰减，或特征值（当地说明） | 03 |
| $\kappa$ | 条件数 $\lambda_{\max}/\lambda_{\min}$ | 03 |

## 架构

| 符号 | 意义 | 首次使用 |
|---|---|---|
| $E\in\mathbb{R}^{V\times d}$ | 嵌入表；$d$ 为模型宽度 | 02 |
| $q, k, v$；$Q, K, V$ | 查询、键、值（$Q, K, V$ 的行）；$d_k$ 为键的宽度 | 04 |
| $A = \mathrm{softmax}(QK^{\top}/\sqrt{d_k})$ | 注意力权重，逐行 softmax | 04 |
| $h$（个数） | 头数；$d_h = d/h$ | 04 |
| $h_t$（向量） | 时间 $t$ 的循环状态 | 05 |
| $a_t$ 或 $\Lambda$ | 状态转移（衰减）；$\rho(\cdot)$ 为谱半径 | 05 |
| $C$ | 以 FLOPs 计的训练计算量（$C\approx 6ND$） | 06 |

## 生成与决策

| 符号 | 意义 | 首次使用 |
|---|---|---|
| $\tau$ | 采样温度 | 08 |
| $x_0, x_1$；$t\in[0,1]$ | 流匹配中的噪声端与数据端；内插时间 | 08 |
| $v_\theta(x, t)$ | 学习的速度场 | 08 |
| $\pi_\theta(a\mid s)$ | 策略；$s$ 为状态，$a$ 为动作 | 09 |
| $r$、$R$ | 奖励、回报 | 09 |
| $\pi_{\text{ref}}$ | 参考（预训练）策略 | 09 |
| $\beta$ | 注意力中的逆温度（04）；后训练中的 KL 系数（09） | 04, 09 |

## 证据

| 符号 | 意义 | 首次使用 |
|---|---|---|
| $\hat\mu$、$\mathrm{se}$ | 估计值及其标准误 | 01, 10 |
| $\mathrm{ECE}$ | 期望校准误差（expected calibration error） | 10 |
| $\mathrm{CI}_{95}$ | 95% 置信区间 | 10 |

## 排版约定

- **例题**依单元编号（例题 4.3）；**命题、定理与推论**亦同（定理 5.2）。
- **★ 进阶**标记第一次阅读时可略过的证明与推广。
- “最新进展”中的 **[D]／[E]／[O]／[H]** 分别标记推导、实验证据、工程观察与开放假说。
- **[不使用 AI]** 标记用于独立练习与评估的习题。
