## 審查角色

| 角色 | 負責 |
|---|---|
| 學科編輯 | 數學與科學的正確性 |
| 教學編輯 | 學習目標、認知要求、順序與鷹架 |
| 實驗維護者 | 可重現性、相依套件、測試 |
| 文獻審查者 | 引用的有效性、日期、主張是否有來源支持 |
| 學生審查者 | 清楚程度、無障礙、能否在實際硬體上完成任務 |
| 譯文審查者（中文版） | 繁體版是否符合臺灣學術用語、簡體版是否符合中國大陸通行學術用語；中英對照是否一致；數學意義是否忠實，而不只是文字通順 |

## 主張分類

核心教材中每個實質主張都屬於以下之一：

- **推導（derivation）**——說明假設；給出或引用證明或推導。
- **實驗證據（experimentally supported）**——引用研究設計、資料、評估方式與限制。
- **工程觀察（engineering observation）**——記錄環境與量測。
- **開放假說（open hypothesis）**——明確標示未經驗證；適合作為研究題目。

AI 導師的提示詞會要求 AI 工具以相同類別標示它的輸出。

## 內容規則

- 任何自動產生的文字，未經人工審查不得進入經審查的核心教材；Git 歷史記錄變更、署名與決策。
- 每個 Atlas 節點至少以文獻鍵引用一篇原始文獻；遇到未知的鍵或懸空連結，建置就會失敗。
- 正文中的已知數值必須由測試或有記錄的計算重現。
- Atlas 上限約 150 個節點；新增時通常應合併或淘汰現有節點。
- 中文版的術語以[中英術語對照表](/zh-tw/start/glossary/)為準；數學式中的中文字必須包在 `\text{}` 內（由 `scripts/check-math-cjk.mjs` 檢查）。
- 簡體中文版由繁體中文版經 `scripts/zh_cn.py` 生成（含人工審定的大陸用語對照表、矩陣「行／列」互換與標點轉換），不直接手改；CI 會檢查兩者同步。一項更正必須同時出現在英文版與繁體中文版，簡體中文版隨之重新生成。
