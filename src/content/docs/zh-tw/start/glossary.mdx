本書繁體中文版採用**臺灣學術用語**，並在每頁某個術語**第一次出現時於括號中附上英文原文**，例如「梯度下降法（gradient descent）」。這樣做有兩個目的：一是讓你閱讀英文論文、文件與程式碼時能直接對應；二是避免同一個概念在不同譯本中名稱不一而造成混淆。

幾個本書特別遵守的區分：

- **模型的「記憶（memory）」** 與 **電腦的「記憶體（memory）」** 不同。
- **「正規化（normalization）」**（例如層正規化）與 **「正則化（regularization）」**（例如權重衰減）不同。
- 程式中的 function 稱「**函式**」，數學上的 function 稱「**函數**」。
- 定理之後的 corollary 稱「**系理**」，以免與模型的「**推論（inference）**」混淆。

表中「簡體中文（中國大陸）」一欄是本書[簡體中文版](/zh-cn/start/glossary/)所用的譯名，方便你對照閱讀簡體中文資料；繁體正文一律使用臺灣用語。注意兩岸對矩陣「行、列」的用法恰好相反：臺灣以「列」指 row、「行」指 column，中國大陸則以「行」指 row、「列」指 column。
