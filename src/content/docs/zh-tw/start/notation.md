每個單元都採用以下約定。若某個符號因長期慣例而有多種用法（例如 $\beta$），會在當地說明，並列在這裡。

## 一般

| 符號 | 意義 | 首次使用 |
|---|---|---|
| $a, x, w$ | 純量與向量（小寫、不用粗體）；維度會另外說明 | 01 |
| $W, A, Q, K, V$ | 矩陣（大寫）；$X\in\mathbb{R}^{T\times d}$ 每一列對應一個位置 | 02 |
| $x_i$、$x_t$ | 第 $i$ 個樣本，或位置／時間 $t$ 的詞元／輸入 | 01 |
| $\mathbf 1$ | 全為 1 的向量 | 04 |
| $e_y$ | 類別 $y$ 的獨熱（標準基底）向量 | 02 |
| $\odot$ | 逐元素乘積 | 03 |
| $\langle u, v\rangle = u^{\top}v$ | 內積 | 02 |
| $\lVert\cdot\rVert$ | 除非另有說明，向量為歐氏範數、矩陣為譜範數 | 03 |
| $\ln$ | 自然對數；所有資訊量都以 **nats** 為單位 | 01 |

## 資料、模型與損失

| 符號 | 意義 | 首次使用 |
|---|---|---|
| $\mathcal{D} = \{(x_i, y_i)\}_{i=1}^n$ | 含 $n$ 個樣本的訓練集 | 01 |
| $p_{\text{data}}$ | （未知的）資料分布 | 01 |
| $\theta$ | 模型的全部可訓練參數；$N$ 為其數量 | 01, 06 |
| $p_\theta(y\mid x)$ | 模型預測的分布 | 01 |
| $\ell(\theta; x, y)$ | 單一樣本的損失，通常為 $-\ln p_\theta(y\mid x)$ | 01 |
| $L(\theta)$、$\hat L(\theta)$ | 母體損失與經驗（訓練）損失 | 01 |
| $V$ | 詞彙量；$\ln V$ 為均勻預測器的損失 | 01 |
| $T$ | 序列長度（上下文） | 04 |
| $D$ | 訓練詞元數 | 06 |
| $H(p)$、$H(p, q)$、$\mathrm{KL}(p\,\Vert\,q)$ | 熵、交叉熵、KL 散度（Kullback–Leibler divergence） | 01 |

## 最佳化

| 符號 | 意義 | 首次使用 |
|---|---|---|
| $\nabla L$ | 梯度 | 03 |
| $\bar x = \partial L/\partial x$ | 中間量 $x$ 的伴隨量（adjoint，反向模式） | 03 |
| $J_f$ | $f$ 的雅可比矩陣 | 03 |
| $\eta$ | 步長（學習率） | 03 |
| $B$ | 小批次大小 | 03 |
| $\beta_1, \beta_2$ | Adam 的動差衰減率 | 03 |
| $\lambda$ | 權重衰減，或特徵值（當地說明） | 03 |
| $\kappa$ | 條件數 $\lambda_{\max}/\lambda_{\min}$ | 03 |

## 架構

| 符號 | 意義 | 首次使用 |
|---|---|---|
| $E\in\mathbb{R}^{V\times d}$ | 嵌入表；$d$ 為模型寬度 | 02 |
| $q, k, v$；$Q, K, V$ | 查詢、鍵、值（$Q, K, V$ 的列）；$d_k$ 為鍵的寬度 | 04 |
| $A = \mathrm{softmax}(QK^{\top}/\sqrt{d_k})$ | 注意力權重，逐列 softmax | 04 |
| $h$（個數） | 頭數；$d_h = d/h$ | 04 |
| $h_t$（向量） | 時間 $t$ 的遞迴狀態 | 05 |
| $a_t$ 或 $\Lambda$ | 狀態轉移（衰減）；$\rho(\cdot)$ 為譜半徑 | 05 |
| $C$ | 以 FLOPs 計的訓練計算量（$C\approx 6ND$） | 06 |

## 生成與決策

| 符號 | 意義 | 首次使用 |
|---|---|---|
| $\tau$ | 抽樣溫度 | 08 |
| $x_0, x_1$；$t\in[0,1]$ | 流匹配中的雜訊端與資料端；內插時間 | 08 |
| $v_\theta(x, t)$ | 學習的速度場 | 08 |
| $\pi_\theta(a\mid s)$ | 策略；$s$ 為狀態，$a$ 為動作 | 09 |
| $r$、$R$ | 獎勵、回報 | 09 |
| $\pi_{\text{ref}}$ | 參考（預訓練）策略 | 09 |
| $\beta$ | 注意力中的逆溫度（04）；後訓練中的 KL 係數（09） | 04, 09 |

## 證據

| 符號 | 意義 | 首次使用 |
|---|---|---|
| $\hat\mu$、$\mathrm{se}$ | 估計值及其標準誤 | 01, 10 |
| $\mathrm{ECE}$ | 期望校準誤差（expected calibration error） | 10 |
| $\mathrm{CI}_{95}$ | 95% 信賴區間 | 10 |
