抽象的問題需要一個具體的對象來發問。主幹專案（spine project）就是**一個你在整個核心教材中建構、擴充並檢驗的小型語言模型**。史丹佛大學的 CS336 顯示，從零建構語言模型可以作為一門課的主軸 [CS336](/zh-tw/references/#cs336-2026)；主幹專案把同樣的想法縮到筆電規模，使用類似 TinyStories 的語料——在這種語料上，小型模型已能產生通順的文字 [Eldan & Li 2023](/zh-tw/references/#eldan-2023)。

每個階段都有一個**驗證目標**——一個數字或不變量，讓你不依賴任何 AI 就能判斷這個階段是否正確。

| 階段 | 單元 | 你要新增 | 驗證目標 | 狀態 |
|---|---|---|---|---|
| 01 | [01](/zh-tw/core/unit-01/) | 以計數建立的二元語法，加 α 平滑 | 保留集負對數概似低於均勻的 $\ln V$；α→∞ 時恰好回到 $\ln V$ | **程式碼＋測試** |
| 02 | [02](/zh-tw/core/unit-02/) | 學習的嵌入、綁定的反嵌入 | 查表的梯度＝ one-hot 矩陣乘法的梯度 | 規格 |
| 03 | [03](/zh-tw/core/unit-03/) | 以你推導的梯度 $p-e_y$ 訓練的神經二元語法 | 初始損失 $=\ln V$；訓練損失 → 計數式最大概似最佳值（±0.01 nats），且永不低於它 | **程式碼＋測試** |
| 04 | [04](/zh-tw/core/unit-04/) | 因果自注意力區塊（從此使用框架的自動微分） | 所有注意力不變量；初始損失約為 $\ln V$ | 規格 |
| 05 | [05](/zh-tw/core/unit-05/) | KV 快取解碼；回憶壓力測試 | 快取的 logits ＝完整重算 | 規格 |
| 06 | [06](/zh-tw/core/unit-06/) | 五種模型大小；擬合尺度定律 | 對第 6 種大小預先登記的預測 | 規格 |
| 07 | [07](/zh-tw/core/unit-07/) | 在 TinyStories 子集上預訓練；去重 | 訓練資料中沒有任何保留集故事（植入重複項的召回率 1.0） | 規格 |
| 09 | [09](/zh-tw/core/unit-09/) | 在可自動檢查的任務上做後訓練 | 獎勵上升且 KL 有界；獎勵駭入稽核 | 規格 |
| 10 | [10](/zh-tw/core/unit-10/) | 評估框架 | 在已知答案的合成案例上做校準與自助法信賴區間 | 規格 |
| 11 | [11](/zh-tw/core/unit-11/) | 找出歸納頭（induction head） | 以自己修補自己＝無變化；消融後上下文內的複製消失 | 規格 |
| 12 | [12](/zh-tw/core/unit-12/) | 總結專題：重現 → 挑戰 → 延伸 | 口試答辯 | 規格 |

## 執行現有的部分

```bash
cd spine
python stage01_bigram.py              # 在 data/sample.txt 上的計數式二元語法
python stage03_neural_bigram.py       # 以手推梯度訓練的神經二元語法
python -m pytest                      # 階段 01 與 03 的驗證目標
```

兩個階段都只需要 NumPy，在內附的範例語料上幾秒內就跑完。要做真正的實驗，請下載 TinyStories 子集，並以 `--data path/to/text.txt` 傳入。

## 設計規則

- **贏得抽象的資格。** 階段 01–03 只用 NumPy 與你自己的梯度。從階段 04 起，主幹專案改用框架的自動微分，因為你已經親手做過一個。
- **每個階段只改一件事**，並在執行前寫下預測。
- **筆電優先。** 每個階段都必須能在筆電 CPU 上、以範例語料在幾分鐘內跑完；消費級 GPU 的執行是選用的延伸。
