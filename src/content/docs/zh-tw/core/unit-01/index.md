## 1.1 問題

2017 年，一組研究者拿一個標準的影像分類網路與一份含 50,000 張標註照片的標準資料集，做了一件奇怪的事：他們**隨機打亂標籤**，於是一張船的照片可能被標成「青蛙」，一張青蛙的照片被標成「卡車」（[Zhang et al. 2017](/zh-tw/references/#zhang-2017)）。然後照常訓練網路。

網路在**訓練集上達到 100% 準確率**。它記住了 50,000 組任意的配對。在新照片上，它的準確率是 10%——等於在十個類別中隨機亂猜。同一個網路用*正確*標籤訓練時，在新照片上能達到很高的準確率。

兩次訓練使用相同的架構、相同的參數量、相同的最佳化器，訓練準確率也相同。只有其中一次學到了能轉移到未見情況的東西。所以：

- **訓練表現無法告訴你模型是否學到了東西。** 兩次訓練在訓練集上都是完美的。
- **模型大小也無法告訴你。** 兩次用的是同一個網路。
- 造成差別的，是*訓練資料與新資料之間的關係*——在隨機標籤的實驗中，根本沒有可以利用的關係。

本單元要問的是底下的問題：**為什麼經驗能改善對從未見過情況的表現？** 以及實務上的配套問題：**你怎麼知道它真的改善了？**

我們用一個可以完整研究的最簡單學習者來回答：一張統計文本中哪個字元接在哪個字元後面的表——**二元語法語言模型（bigram language model）**。它單獨使用時太簡單、不實用，但本單元的每個概念——損失、讓學習成為可能的假設、訓練表現與保留資料表現之間的落差、基準、量測數字的不確定性——都能在它身上清楚看見，而且之後每個單元都原封不動地重複使用這些概念。同一張表也是[主幹專案](/zh-tw/spine/)的第一個階段，也就是你將貫穿全書打造的小型語言模型。

:::note[繼續閱讀前先預測]
一個二元語法模型以計數方式擬合 2,000 個字元的兒童故事，再在同一來源、另外 43,000 個字元的故事上評估。它在訓練文本上的平均損失是 2.06 nats／字元。**nat** 是以自然對數計算對數損失的單位；損失越低越好。它在新文本上的損失會更低、差不多，還是更高——大約差多少？若訓練字元增加到 385,000 個，會有什麼改變？（詳解例題 1.4 與實驗 1.2 給出答案。）
:::

## 本單元建構的內容

1. **從硬幣到語言模型**（§1.2）。把學習看成估計機率分布；對數損失以及它為何是正確的評分方式；均勻基準 $\ln V$；最大概似就是計數；零計數與平滑；訓練、驗證與測試資料的紀律。
2. **類推的數學**（§1.3）。母體風險與經驗風險；「交叉熵 = 熵 + KL 散度」的分解；推導最大概似；把平滑看成貝氏推論；集中不等式，以及為什麼在許多模型中挑選需要新的資料；保留資料數字的不確定性。
3. **一般理論**（§1.5）。均勻收斂與模型容量、偏差–變異數分解、沒有免費午餐定理，以及為什麼古典的容量論證無法解釋現代網路。
4. **留下的問題**（§1.7）。二元語法無法把關於一個字元學到的東西轉移到相似的字元上。這個限制就是[單元 02](/zh-tw/core/unit-02/) 的問題。

## 先備知識

- **機率：** 離散分布、期望值、獨立性、大數法則（於 §1.2.2 陳述）。
- **微積分：** 對數與指數；一個拉格朗日乘數（§1.3.3，當場說明）。
- **程式：** 實驗需要 NumPy 陣列與索引操作。
