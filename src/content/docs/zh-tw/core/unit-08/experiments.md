先寫下預測。程式碼：[`spine/stage08_sampling.py`](https://github.com/yhxuee/deep-learning-intelligent-systems/tree/main/spine) 及其在 `spine/test_spine.py` 中的測試。

## 實驗 8.1——主幹模型上的抽樣器

**檢驗：** §8.2.3–§8.2.4、詳解例題 8.4。**預測：** 對貪婪、$\tau = 0.7$、$\tau = 1.5$ 與 top-$p = 0.9$，哪些會產生迴圈、哪些會產生不成字的字串、哪些會產生多樣且合乎格式的故事。

**步驟。** `python stage08_sampling.py` 會為每個抽樣器印出「Lily had a 」的三個 90 字元延續。然後每個抽樣器生成 200 個延續，計算 (a) 不同延續的數量、(b) 不成字的字串（不在訓練詞彙中的字串）。

**觀察：** 貪婪只有一種延續；$\tau = 1.5$ 的不成字字串最多；top-$p$ 與 $\tau = 0.7$ 在兩者之間取捨。

## 實驗 8.2——量測退化

**檢驗：** §8.7.1。**預測：** 400 字元的貪婪生成中，包含重複 30 字元子字串的比例。

**步驟。** 以 50 個不同的提示，分別用貪婪與 top-$p = 0.9$ 生成；偵測重複的子字串；也計算每段生成在模型自身下的 NLL。

**觀察：** 貪婪生成的 NLL 很低、重複很多——縮小版的概似陷阱。

## 實驗 8.3——精確高斯流及其步數誤差

**檢驗：** §8.3.6–§8.3.7、詳解例題 8.7。**預測：** 以 1、2、5、20、200 步 Euler 積分後的樣本標準差（目標 0.5）。

**步驟。** 從 20,000 個標準常態樣本積分 `gaussian_velocity([1, -2], 0.5)`；再以中點法（二階）取代 Euler 並重複。

**觀察：** Euler 分別為 0、0.20、0.37、0.47、0.50；中點法以少得多的步數就達到 0.49。解釋為什麼平均在每種步數下都幾乎精確，而分散程度卻不是。

## 實驗 8.4——環上的流匹配

**檢驗：** 命題 8.2、詳解例題 8.8。**預測：** 最終的訓練損失（不是零——為什麼？），以及距某個眾數 0.5 以內的樣本比例。

**步驟。** 以 `fm_train` 訓練 3,000 步；分別以 5、20、100 步 Euler 抽樣；畫出樣本並計算涵蓋的眾數。

**觀察：** 損失從約 5.3 降到約 3.8；100 步時幾乎所有樣本都在八個眾數附近，5 步時較少、也較模糊。

## 實驗 8.5——同一個環上的 VAE

**檢驗：** §8.3.3、§8.5.4。**預測：** 一個二維潛變數、MLP 大小相同的 VAE 能否涵蓋全部八個眾數，以及它的樣本相較於流匹配有多清晰。

**步驟。** 以重新參數化實作編碼器、解碼器與 ELBO（KL 項的梯度不使用 AI）；訓練；抽樣。

**觀察：** 樣本在眾數之間被抹開（高斯解碼器會取平均）——§8.5.4 的模糊——以及改變 KL 項權重時的取捨。

## 實驗 8.6——主幹專案階段 08

**檢驗：** [主幹專案](/zh-tw/spine/)的驗證目標。**預測：** $k = 1$ 的 top-$k$ 是否等於貪婪；20,000 次抽樣是否在 0.012 內符合其機率。

**步驟。** `cd spine && python -m pytest test_spine.py -k stage08 -v`。

**觀察：** 抽樣器在極限下彼此化約；精確的高斯場把雜訊輸運到目標；流匹配梯度與有限差分一致。
