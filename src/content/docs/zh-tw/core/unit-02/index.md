## 2.1 問題

[單元 01](/zh-tw/core/unit-01/) 結束於一個限制：計數表把每個符號都當成互不相關的索引，所以它無法把在某個上下文學到的東西，分享給相似的上下文。以下是這個限制的代價。讀完僅僅 5,000 個字元的訓練文本後，從前**四個**字元預測兒童故事的下一個字元：

- 以 4 個字元為上下文、盡可能平滑過的**計數表**，保留資料損失為 **1.11 nats／字元**。625 萬種可能的上下文大多從未見過；對這些上下文，它只能把機率均勻分散。
- **神經 4 元語法（neural 4-gram）**——同樣的四個字元，但每個先換成一個學習出的 16 維向量——達到 **0.98 nats**，只用 15,570 個參數。

同樣的資料、同樣的上下文、同樣的損失函數。唯一的差別是預測之前*如何表示這四個字元*。用 385,000 個訓練字元時，優勢就消失了（0.52 對 0.54）：當資料相對於模型必須涵蓋的情況數量而言很稀少時，表示最重要——而對任何有趣的任務，這種情況永遠成立。

一個更古老、更鮮明的例子有相同的形狀。平面上四個點，$(0,0)$ 與 $(1,1)$ 標為 0，$(0,1)$ 與 $(1,0)$ 標為 1——**XOR（互斥或）**問題。沒有任何直線能把兩種標籤分開；座標 $(x_1, x_2)$ 上的線性分類器無論看到多少資料都解不了。加上第三個座標 $x_1x_2$，一個平面就能完美地分開它們。學習者沒有任何改變。問題從不可能變得微不足道，是因為**表示（representation）**改變了。

本單元要問：**為什麼表示的改變會改變學習的難度**——以及什麼是*好的*表示。這個答案是全書的樞紐：深度網路首先是*學習*表示的機器，而單元 04–05 的每個架構，都是關於該共享什麼、該忽略什麼的設計。

:::note[繼續閱讀前先預測]
一個字元層級的模型為 50 個字元各學習一個 16 維向量，訓練目標只是預測下一個字元。你預期哪些字元最後會最接近數字 `3`？最接近大寫 `T`？最接近母音 `a`？寫下你的猜測；詳解例題 2.5 展示了主幹模型學到什麼。
:::

## 本單元建構的內容

1. **從第一原理看表示**（§2.2）。特徵與線性讀出；XOR；獨熱編碼，以及為什麼獨熱輸入上的線性模型*就是*一張計數表；嵌入作為學習出的共享座標；分布假說；綁定的輸入與輸出嵌入；不需指數大表格的更長上下文。
2. **數學**（§2.3）。可分性；把嵌入查找看成矩陣乘積及其梯度；二元語法的秩 $d$ 分解；神經 n 元語法及其梯度；最佳低秩近似；不變性與等變性。
3. **一般理論**（§2.5）。普遍逼近定理及其沒有保證的事；Cover 計數定理；隨機投影與 Johnson–Lindenstrauss 引理；群平均與等變映射；把嵌入看成隱式矩陣分解。
4. **留下的問題**（§2.7）。學習的表示沒有封閉解。它的參數必須以基於梯度的搜尋找到——這是[單元 03](/zh-tw/core/unit-03/) 的主題。

## 先備知識

- **來自單元 01：** 對數損失、最大概似、二元語法模型、保留資料評估。
- **線性代數：** 向量、內積、矩陣–向量與矩陣–矩陣乘積、秩；奇異值分解在用到時說明（§2.3.5）。
- **微積分：** 偏導數，以及兩個函數合成的連鎖律（一般情況由單元 03 發展；§2.3.3 只需要簡單情況）。
