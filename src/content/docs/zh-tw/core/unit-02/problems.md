## 計算

**2.1 ★ [不使用 AI]** 找出另一個特徵映射 $\phi:\{0,1\}^2\to\mathbb{R}^2$（只用兩個座標），使 XOR 線性可分，並給出分隔線。

**2.2 ★ [不使用 AI]** 以 $x = (1, 1, 1)$ 與題中的 $G$ 重做詳解例題 2.7。錯誤的指定寫法 `dE[x] = G` 會得到什麼？

**2.3 ★** 計算 $V = 256$（位元組）、$d = 32$、$H = 512$ 的神經 8 元語法的參數量。計數 8 元語法最多可能需要多少列？

**2.4 ★** 對 $\mathbb{R}^3$ 中的 $N = 10$ 個點（齊次情況）計算定理 2.3 的 $C(N, p)$。可分的標註佔所有標註的多少比例？

**2.5 ★★** 由定理 2.4，要讓 10,000 個嵌入的兩兩平方距離都保持在 10% 以內，需要多少維？1% 以內呢？

**2.6 ★★** 在相同的二元語法資料上訓練一個獨熱模型，與一個帶線性讀出的 $d$ 維嵌入模型。證明 $d\ge V$ 時嵌入模型能表示每一張二元語法表，而 $d = 1$ 時，它只能表示對數勝算矩陣秩至多為 2 的表（計入偏置後）。

## 推導

**2.7 ★ [不使用 AI]** 證明命題 2.1（查找的梯度），並用一句話解釋為什麼重複的索引必須累加。

**2.8 ★★ [不使用 AI]** 對 $Y = AXB$ 與純量 $L(Y)$，證明 $\partial L/\partial X = A^{\top}(\partial L/\partial Y)B^{\top}$。用它推導 §2.3.3 的全部四個梯度。

**2.9 ★★** 推導*不綁定*分解式二元語法 $z_{ab} = e_a^{\top}Mf_b + c_b$ 的梯度。證明 §2.3.3 的綁定梯度，等於在 $F = E$ 處計算的 $E$ 與 $F$ 不綁定梯度之和。

**2.10 ★★** 推導一批資料的神經 n 元語法反向傳遞（§2.3.4），包括同一符號在一個上下文中出現兩次的情況。

**2.11 ★★** 證明對任何可逆的 $Q$，分解式二元語法的損失在 $E\mapsto EQ$、$M\mapsto Q^{-1}MQ^{-\top}$ 下不變。這對學習出的嵌入的唯一性，以及逐座標比較兩次訓練的嵌入，意味著什麼？

## 證明

**2.12 ★★ [不使用 AI]** 證明沒有仿射分類器能分開 XOR（詳解例題 2.1），而有兩個隱藏單元的兩層 ReLU 網路可以。

**2.13 ★★** 證明命題 2.2，並證明一個序列的嵌入總和對置換不變。構造兩個詞袋表示相同、但在你選擇的任務上正確輸出不同的句子。

**2.14 ★★★** 證明每個與所有循環位移可交換的線性映射 $\mathbb{R}^T\to\mathbb{R}^T$ 都是循環卷積。（與單元 04 的定理 4.2 比較。）

**2.15 ★★★** 完成 Cover 遞迴 $C(N+1, p) = C(N, p) + C(N, p-1)$ 的證明並解出它。

**2.16 ★★★** 以定理 2.4 的常數證明 Johnson–Lindenstrauss 引理，包括 $\chi^2_d$ 的 Chernoff 界。

## 實作與設計

**2.17 ★ [不使用 AI]** 不看資料，實作分解式二元語法的前向與反向傳遞，並通過主幹專案的梯度檢查。

**2.18 ★★** 以 $d = 2$ 訓練分解式二元語法，把 50 個字元畫在平面上。形成了哪些群？哪些字元的位置很差？為什麼兩個維度無法分開它們？

**2.19 ★★** 把神經 n 元語法中的串接換成上下文嵌入的*總和*。先預測，再量測對保留資料損失的影響。與 §2.7.1 連結。

**2.20 ★★★** 設計一個實驗，檢驗主幹模型的嵌入幾何比較取決於資料還是亂數種子：要比較什麼、用什麼相似度量度，以及什麼結果會支持各自的答案？（§2.8.5 與單元 12 的預告。）

## 部分解答

- **2.1** $\phi(x) = (x_1 + x_2,\ x_1x_2)$ 把四個點映射到 $(0,0)$、$(1,0)$、$(1,0)$、$(2,1)$；規則 $\phi_1 - 2\phi_2 > 0.5$ 分開它們（分數 $0, 1, 1, 0$）。
- **2.2** 正確的梯度：第 1 列收到全部三列，$(9, 12)$；第 0 與第 2 列為零。錯誤寫法：第 1 列等於 $(5, 6)$。
- **2.3** $256\cdot32 + 8\cdot32\cdot512 + 512 + 512\cdot256 + 256 = 8{,}192 + 131{,}072 + 512 + 131{,}072 + 256 = 271{,}104$ 個參數；最多 $256^8\approx1.8\times10^{19}$ 列。
- **2.4** $C(10, 3) = 2(1 + 9 + 36) = 92$，在 $2^{10} = 1{,}024$ 種標註中：9.0%。
- **2.5** $d\ge 8\ln(10^4)/\varepsilon^2$：$\varepsilon = 0.1$ 得 $d\ge 7{,}369$；$\varepsilon = 0.01$ 得 $d\ge 736{,}828$。（這個界很寬鬆；實務上遠少的維度就夠了。）
