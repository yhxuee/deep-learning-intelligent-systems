這些實驗要求你在看到結果**之前**先選定主張，藉此學習評估。核心程式位於 [`spine/stage10_eval.py`](https://github.com/yhxuee/deep-learning-intelligent-systems/tree/main/spine)，合成驗證案例位於 `spine/test_spine.py`。最後一項實驗使用 `labs/beyond_language.py`。

每項實驗都建立一份包含五個欄位的簡短紀錄：

1. **預測**——執行前寫下方向與大致大小；
2. **獨立單位**——故事、字元、提示、訓練執行或院區；
3. **估計目標**——想了解哪個母體量；
4. **結果**——估計值、區間與診斷圖表；
5. **修正**——你改變了什麼看法。

非預期結果不是失敗的實驗。看過結果後才修改假說，再假裝早已預測，才是失敗。

## 實驗 10.1——先驗證量測工具

**問題。** 評估程式能否恢復答案已知的量？

評估已訓練模型之前，先用合成案例測試工具：

- 事件機率已知且校準良好的預測器；
- 信心全部向上偏移 0.04 的同一預測器；
- 從平均值已知的指數分布重複抽樣。

**寫下預測。** 兩個預測器的 ECE 應為何？對 $n\in\{10,30,60,200,1000\}$ 的拔靴法區間，你預期覆蓋不足、過度覆蓋，還是接近名目覆蓋？

**步驟。** 從儲存庫根目錄執行：

```bash
cd spine
python -m pytest test_spine.py -k stage10 -v
```

接著修改覆蓋模擬的副本，讓每個 $n$ 至少使用 1 000 次重複研究。記錄

$$
\widehat{\operatorname{coverage}}
=\frac{\#\{\text{包含真實平均值的區間}\}}{\#\{\text{模擬研究}\}}。
$$

因為此估計本身也是二項比例，應附上 Monte Carlo 標準誤

$$
\sqrt{\hat c(1-\hat c)/M}，
$$

其中 $M$ 是模擬研究次數。

**解讀。** 校準良好案例的 ECE 應接近 0，統一過度自信案例應接近 0.04，差異來自 Monte Carlo 雜訊。偏斜分布的百分位拔靴法在小 $n$ 時可能偏離名目覆蓋，並隨 $n$ 增加接近漸近目標；但單次有限模擬不一定單調。

**失效診斷。** ECE 案例失敗時，檢查分組邊界以及信心 1.0 是否被放入最後一組。若每個 $n$ 的覆蓋率都恰好 95%，檢查模擬是否在建構區間時意外重用了真實目標。

**實驗後主張：**「這些合成案例沒有否證實作」，而不是「實作對每種統計量都正確」。

## 實驗 10.2——重抽故事，還是重抽字元？

**問題。** 把相依字元當成獨立，會產生多少虛假精度？

**預測。** 計算前先寫下一個比值：

$$
\frac{\text{字元拔靴法區間寬度}}
{\text{故事拔靴法區間寬度}}。
$$

它會接近 1、遠小於 1，還是大於 1？請用故事內相依性解釋。

**步驟。** 對階段 07 留出 NLL：

1. 每個故事計算一個 NLL，再重抽 140 個故事；
2. 合併字元損失，再重抽個別字元；
3. 用不同產生器種子建立 20 份新留出集，分別打分數；
4. 比較兩種區間寬度與生成集合之間的經驗散布。

每份重新生成的集合都使用相同故事數與產生器設定。20 份集合的散布只是經驗參考，不是「真實變異」；它本身也有抽樣雜訊。

**記錄。** 回報每項分析表面上的觀測數、兩個區間寬度，以及 20 個集合平均的標準差。

**解讀。** 若字元重抽窄得多，請解釋為何龐大字元數沒有產生同樣多的獨立觀測。若兩種寬度接近，檢查故事是否幾乎同質，或實作是否在重抽前意外先聚合了字元。

**延伸。** 再做一次群集拔靴法：抽取故事，並保留每個被抽故事中的所有字元。因為故事才是獨立單位，它應與故事層級分析一致。

## 實驗 10.3——偏移偵測器不是表現預測器

**問題。** 哪些受控偏移傷害模型？可偵測程度能預測傷害嗎？

建立三組各 140 個故事，每次只改變一項因素：

1. 姓名在訓練中未見；
2. 動物與物件未見；
3. 保留詞語，但打亂句子順序。

**預測表。** 執行前填寫：

| 偏移 | 預測 NLL 變化 | 預測來源對偏移分類器正確率 | 提議理由 |
|---|---:|---:|---|
| 未見姓名 |  |  |  |
| 未見動物／物件 |  |  |  |
| 打亂句序 |  |  |  |

**步驟。** 針對每項介入修改 `make_tales.py` 的副本，凍結模型與評分程式。對每個集合：

- 回報逐故事平均 NLL 與故事拔靴法區間；
- 訓練分類器區分普通留出故事與偏移故事；
- 在分類器自己的留出切分上評估，不使用其訓練資料；
- 保存幾個損失最高案例，進行質性檢查。

**解讀。** 分類器正確率高，表示兩個分布在其特徵空間中可區分，不代表模型損失一定大增。反過來，簡單分類器難以偵測的細微偏移，也可能正好命中脆弱特徵而造成巨大傷害。

可以畫出偏移可偵測性對 NLL 變化，但不能從三個點推論普遍單調關係。

**反事實檢查。** 若未見姓名造成高損失，將其換成等長隨機字串，再把熟悉姓名放到不熟悉位置。這些後續檢查有助於區分新穎度、分詞與位置假說，但仍未證明內部機制。

## 實驗 10.4——擬合校準，但不要在擬合資料上評估

**問題。** 單一溫度能否改善留出機率品質，同時維持正確率不變？

溫度縮放把 logits $z$ 變成 $z/\tau$。$\tau>1$ 時分布較平，$\tau<1$ 時較尖。只要 $\tau$ 為正，argmax 預測不變。

**預測。** 根據詳解例題 10.5 的可靠度表，預測擬合出的 $\tau$ 高於還是低於 1。再分別預測正確率、NLL、ECE 與中段信心區間如何改變。

**步驟。** 依故事分割留出位置，不要把同一故事的字元隨機混到兩側：

1. 在校準故事上最小化 NLL，擬合 $\tau$；
2. 凍結 $\tau$；
3. 在另一批評估故事上測量；
4. 回報前後的正確率、NLL、ECE 與完整可靠度表；
5. 重抽評估故事，為指標差值建立區間。

依故事分割可避免近似重複的上下文同時出現在兩側。

**解讀。** 除非數值平手的打破方式改變，正確率應完全相同。NLL 與 ECE 不一定同向，因為 ECE 依賴分組，而且不是適當評分。全域溫度可能改善主導區間，卻使較小子群變差。

**消融。** 在同一批位置上擬合並評估溫度。結果通常看起來更好；它與誠實分割之間的落差，估計了校準過度擬合。

## 實驗 10.5——分開項目雜訊與訓練執行雜訊

**問題。** 選到哪些測試故事造成的不確定性，與重新訓練造成的不確定性，何者較大？

**預測。** 分別寫下預期標準差：

- 一次階段 04 執行內，跨留出 NLL 拔靴法重抽；
- 五次獨立階段 04 訓練的平均留出 NLL。

**步驟。** 用不同初始化與資料順序種子訓練五次。固定架構、資料、步數與檢查點選擇規則。計算資源不足時，可以為**所有**執行一起減少步數，並把結果標成縮減計算研究。

每次執行都保留相同凍結測試集上的逐故事損失，再回報：

| 執行 | 平均 NLL | 項目拔靴法區間 |
|---|---:|---:|
| 1 |  |  |
| 2 |  |  |
| 3 |  |  |
| 4 |  |  |
| 5 |  |  |

另回報五個執行平均值之間的標準差。只有五次執行時，這個標準差本身很不確定，不要把三位小數當成穩定的方法性質。

**解讀。** 任一來源都可能占主導。若執行變異小，那是關於這項設定與計算預算的證據，不是「種子永遠不重要」的證明。若變異大，單次執行的方法比較尤其薄弱。

**延伸。** 使用兩層拔靴法：先重抽執行，再於被選執行內重抽故事。把所得區間與只重抽項目的區間比較。

## 實驗 10.6——植入洩漏，測試稽核而非事後聰明

**問題。** 哪些證據能揭露一半評估集進入了訓練？

以普通訓練資料加上 140 個留出故事中的 70 個，訓練階段 04 設定。先把洩漏故事身分放入封存檔案，直到第一次分析完成才打開。

**預測。** 訓練前先預測：

- 整體留出 NLL 變化；
- 洩漏與乾淨兩半的損失差；
- 哪些現有污染檢查會偵測此事件。

**盲態第一階段。** 不使用洩漏標籤，評估全部 140 個故事。檢查逐故事損失、與已記錄訓練語料的 n-gram 重疊，以及虛無假設適合此資料的模型式污染統計量。寫下判定與證據。

**揭盲階段。** 打開標籤。比較洩漏與乾淨故事，並為差值建立區間。計算偵測器在此植入案例上的敏感度與偽陽性表現。

**解讀。** 整體改善可能很像真正進步。知道洩漏身分的切分應揭露落差，但不是每種通用污染檢定都保證抓到每種洩漏。例如，順序檢定問的是標準順序熟悉度，不是任意成員暴露。

**最重要的產出。** 寫下哪些產物使診斷成為可能：精確訓練資料清單、項目識別碼、逐項分數、時間戳記或模型概似存取權。從未保留的證據，無法靠偵測器補回。

## 實驗 10.7——在新院區做外部驗證

**問題。** 一項特徵能否改善內部驗證，卻傷害外部驗證？

`labs/beyond_language.py` 中的 `multisite` 模擬三個結果盛行率不同的訓練院區與第四個留出院區。第三個特徵像掃描器或院區假象：它追蹤院區盛行率，但院區關係改變後，對個別病人沒有資訊。

**預測。** 對使用與不使用假象的邏輯斯迴歸，預測下列交叉熵：

1. 來自三個訓練院區的新病人；
2. 來自第四個院區的病人。

也預測分類器能以多高正確率區分訓練院區與留出院區輸入。

**步驟。** 先執行現有驗證：

```bash
python -m pytest labs/test_beyond_language.py -k multisite -v
```

接著擴充實驗，回傳逐病人損失。於院區內重抽病人並回報區間。使用多個測試院區盛行率與假象強度重複實驗；固定訊號特徵。

**解讀。** 假象可能在相關性穩定的環境中有幫助，當相關性改變時卻造成傷害——這是 [Zech et al. 2018](/zh-tw/references/#zech-2018) 放射影像模型院區捷徑的縮小版。領域分類器顯示院區不同，是一項警示，不是模型使用假象的證明。應比較係數或介入假象以檢驗使用情形。

**決策邊界。** 資料是合成的。本實驗驗證評估觀念，不是臨床系統。真實臨床主張需要具代表性的多院區外部驗證、院區層級不確定性、前瞻性工作流程證據與臨床監督。
