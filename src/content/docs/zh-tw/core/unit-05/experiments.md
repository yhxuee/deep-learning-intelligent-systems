## 實驗 5.1——雜訊與延遲的取捨

**檢驗：** §5.2.6。**預測：** 對 $\alpha \in \{0.5, 0.9, 0.99\}$，EMA 作用在純雜訊上時輸出的實測變異數是 $\sigma^2$ 的幾倍。

**步驟。** 產生 $10^5$ 個 $\mathcal N(0,1)$ 雜訊樣本；分別以各個 $\alpha$ 濾波；捨棄前 $10/(1-\alpha)$ 個樣本；量測變異數。再對無雜訊的階躍濾波，量測到達 95% 的時間。

**觀察：** 變異數與 $(1-\alpha)/(1+\alpha)$ 相差在幾個百分點內；響應時間符合 $\ln 0.05/\ln\alpha$。接著重現圖 5.1。

## 實驗 5.2——離散化何時爆炸

**檢驗：** §5.2.8。**預測：** 前向歐拉法在 $\Delta t/\tau \in \{0.5, 1.5, 1.99, 2.01, 2.5\}$ 時，哪些在 200 步內保持有界？

**步驟。** 以常數輸入 $x_t = 1$、$h_0 = 0$ 迭代 $h_t = (1-\Delta t/\tau)h_{t-1} + (\Delta t/\tau)x_t$；同時迭代 $\alpha = e^{-\Delta t/\tau}$ 的精確更新。

**觀察：** $1 < \Delta t/\tau < 2$ 時有界振盪（$\alpha$ 為負但會衰減），超過 2 時增長；精確更新在每種情況下都收斂到 1。

## 實驗 5.3——特徵值就是記憶模態

**檢驗：** §5.3.3。**預測：** 對隨機可逆的 $V$，$A = V\,\mathrm{diag}(0.5, 0.95)\,V^{-1}$ 的脈衝響應——10 步之後哪個模態佔主導，大約差幾倍？

**步驟。** 在實驗室中實作 `convolution_kernel(A, B, length)`，在隨機輸入上與 `recurrence_loop` 比較（測試 `test_convolution_equivalence_with_zero_initial_state`），並畫出 $CA^jB$。

**觀察：** 不論 $V$ 為何，後期衰減率都是 $0.95^j$；早期的形狀則依賴 $V$、$B$ 與 $C$（詳解例題 5.3）。

## 實驗 5.4——暫態增長

**檢驗：** §5.3.5。**預測：** 對 $A_c = \begin{pmatrix}0.9 & c\\0&0.9\end{pmatrix}$，$c \in \{0.5, 5, 50\}$，$\|A_c^t\|_2$ 的峰值以及出現在第幾步。

**步驟。** 使用 `influence_norms(A, 200)`。

**觀察：** 所有 $c$ 的峰值都在 $t\approx 9.5$ 附近（位置與 $c$ 無關——為什麼？）；當 $c$ 很大時，高度約為 $c\cdot t^*\,0.9^{t^*-1}$。

## 實驗 5.5——隨時間傳遞的梯度

**檢驗：** §5.3.7。**預測：** 對 $\rho(A) = 0.9$ 的*線性*遞迴，$\log_{10}\|\partial h_t/\partial h_k\|$ 對 $t-k$ 的斜率——再對 $\rho(W) = 0.9$ 的 tanh RNN 預測一次。哪個比較陡？為什麼？

**步驟。** 仿照 `figures/make_figures.py` 中的 `u05_bptt_gradient_decay` 累積雅可比矩陣乘積；再以縮放過的隨機正交矩陣 $W$（所有奇異值相等）重做一次。

**觀察：** 線性情況的斜率為每步 $\log_{10}0.9 \approx -0.046$；tanh 較陡（飽和）；在相同譜半徑下，正交 $W$ 衰減得慢很多——支配乘積的是奇異值，而不只是特徵值。

## 實驗 5.6——閘讓長距離依賴變得可學

**檢驗：** §5.3.8。**預測：** 參數量相同的傳統 RNN 與 LSTM，分別能在多大的延遲 $D$ 下學會：在最後一步輸出長度為 $D$ 的隨機序列的第一個詞元。

**步驟**（可使用框架的自動微分）。詞彙表 8 個符號；序列長度 $D \in \{5, 10, 20, 50, 100\}$；每個模型訓練到 99% 準確率或 2,000 步；記錄是否成功。用三個亂數種子重複。

**觀察：** RNN 在不大的 $D$ 就失敗，LSTM 則能撐得遠得多——並觀察把 LSTM 遺忘閘偏置初始化為 1 是否改變門檻。報告種子之間的變異；單次執行不算證據（單元 12）。

## 實驗 5.7——聯想記憶的容量

**檢驗：** §5.5.3、定理 5.3。**預測：** 隨機鍵、Hebbian 儲存時，在 $n = d_k$ 與 $n = 4d_k$ 的相對回憶誤差；再預測 delta 規則的情況。

**步驟。** 以下程式計算 Hebbian 的情況；請擴充為 delta 規則 $S \leftarrow S + (v - Sk)k^\top$，並對所有配對重複多輪。

```python
import numpy as np
rng = np.random.default_rng(0)
d_k, d_v = 16, 8
for n in [4, 16, 32, 64]:
    K = rng.normal(size=(n, d_k)); K /= np.linalg.norm(K, axis=1, keepdims=True)
    V = rng.normal(size=(n, d_v))
    S = V.T @ K                          # 外積 v_j k_j^T 的總和
    err = np.linalg.norm(K @ S.T - V, axis=1) / np.linalg.norm(V, axis=1)
    print(n, err.mean().round(3), np.sqrt((n - 1) / d_k).round(3))
```

**觀察：** Hebbian 誤差接近 $\sqrt{(n-1)/d_k}$（圖 5.6）。當 $n$ 遠小於 $d_k$ 時，delta 規則的誤差降到機器精度（只要鍵獨立即可，定理 5.3 第 2 部分）。在 $n = d_k$ 時，預期 delta 規則會*很慢*而不是錯：200 輪後，我們在 $n = d_k = 16$ 測到的平均誤差約為 0.30，因為這個區域的隨機鍵幾乎線性相依（鍵矩陣條件很差）。超過 $d_k$ 後誤差不可能降到零。請用 $K$ 的條件數來解釋這種變慢——它和單元 03 中拖慢梯度下降法的是同一個量。

## 實驗 5.8——主幹專案階段 05：KV 快取與回憶壓力測試

**檢驗：** §5.3.11 與[主幹專案](/zh-tw/spine/)。**預測：** 在上下文 256 時，KV 快取解碼帶來的每秒詞元數加速倍數；以及階段 04 的模型在多遠的距離之後會在回憶測試中失敗。

**步驟。** 為主幹模型實作快取解碼。驗證快取得到的 logits 在每個前綴都等於完整重算的結果（`labs/unit-04-attention` 中測試的不變量）。接著建立「`… key value … key`」形式的序列，讓兩次出現之間的距離從 4 變化到上下文長度，量測取回值的準確率。

**觀察：** logits 完全相等（在浮點容差內）——若否，檢查位置索引（經典錯誤，見 [KV 快取](/zh-tw/atlas/nodes/mech-kv-cache/)）；回憶曲線在訓練過的上下文內維持高點，超出後崩落（§5.7.6）。加入對照組：「同一序列但移除第一次出現」（§5.7.9）。
