## 實驗 5.1——雜訊與延遲的取捨

**檢驗：** §5.2.6。**預測：** 對 $\alpha \in \{0.5, 0.9, 0.99\}$，EMA 作用在純雜訊上時輸出的實測變異數是 $\sigma^2$ 的幾倍。

**步驟。** 產生 $10^5$ 個 $\mathcal N(0,1)$ 雜訊樣本；分別以各個 $\alpha$ 濾波；捨棄前 $10/(1-\alpha)$ 個樣本；量測變異數。再對無雜訊的階躍濾波，量測到達 95% 的時間。

**觀察：** 變異數與 $(1-\alpha)/(1+\alpha)$ 相差在幾個百分點內；響應時間符合 $\ln 0.05/\ln\alpha$。接著重現圖 5.1。

## 實驗 5.2——離散化何時爆炸

**檢驗：** §5.2.8。**預測：** 前向歐拉法在 $\Delta t/\tau \in \{0.5, 1.5, 1.99, 2.01, 2.5\}$ 時，哪些在 200 步內保持有界？

**步驟。** 以常數輸入 $x_t = 1$、$h_0 = 0$ 迭代 $h_t = (1-\Delta t/\tau)h_{t-1} + (\Delta t/\tau)x_t$；同時迭代 $\alpha = e^{-\Delta t/\tau}$ 的精確更新。

**觀察：** $1 < \Delta t/\tau < 2$ 時有界振盪（$\alpha$ 為負但會衰減），超過 2 時增長；精確更新在每種情況下都收斂到 1。

## 實驗 5.3——特徵值就是記憶模態

**檢驗：** §5.3.3。**預測：** 固定一個隨機可逆的 $V$，令 $A=V\,\mathrm{diag}(0.5,0.95)\,V^{-1}$，並選擇讓兩個特徵模態係數都不為零的 $B,C$。10 步後哪個模態主導？在你選的座標中約差幾倍？

**步驟。** 在實驗室中實作 `convolution_kernel(A, B, length)`，在隨機輸入上與 `recurrence_loop` 比較（測試 `test_convolution_equivalence_with_zero_initial_state`），並畫出 $CA^jB$。

**觀察：** 慢速模態同時被 $B$ 激發、被 $C$ 觀測時，漸近速率才是 $0.95^j$；早期形狀與係數則依賴 $V,B,C$。作為反向對照，選擇能消去慢速模態的 $B$ 或 $C$，確認此時由 $0.5^j$ 主導。存在於 $A$ 的特徵值，不一定出現在輸入—輸出核裡。

## 實驗 5.4——暫態增長

**檢驗：** §5.3.5。**預測：** 對 $A_c = \begin{pmatrix}0.9 & c\\0&0.9\end{pmatrix}$，$c \in \{0.5, 5, 50\}$，$\|A_c^t\|_2$ 的峰值以及出現在第幾步。

**步驟。** 使用 `influence_norms(A, 200)`。

**觀察：** 對這些 $c$，整數峰值應在第 9--10 步附近。非對角項近似 $|c|\,t\,0.9^{t-1}$，峰值在 $t^*=-1/\ln0.9\approx9.49$，與 $c$ 無關；但**精確譜範數**也包含對角項，所以最大化步驟仍可能隨 $c$ 略變。請回報精確的離散峰值，不要直接宣稱位置不變。

## 實驗 5.5——隨時間傳遞的梯度

**檢驗：** §5.3.7。**預測：** 先使用受控的線性遞迴 $A=0.9Q$，其中 $Q$ 為正交矩陣。預測 $\log_{10}\|\partial h_t/\partial h_k\|_2$ 對 $t-k$ 的斜率。接著在 tanh RNN 中使用 $W=0.9Q$，分別輸入 (a) 讓狀態維持在零附近的小輸入，以及 (b) 讓狀態飽和的大輸入。

**步驟。** 仿照 `figures/make_figures.py` 中的 `u05_bptt_gradient_decay` 累積雅可比矩陣乘積。比較各情況時使用相同的 $Q$、初始狀態與輸入序列，並至少重複五個輸入種子。再加入一個重縮放到譜半徑 0.9 的非正規矩陣，作為「只看譜半徑」預測的反例。

**觀察：** $A=0.9Q$ 的斜率恰為每步 $\log_{10}0.9\approx-0.046$。零附近的 tanh 軌跡應接近此斜率；飽和時應更陡。非正規情況即使譜半徑相同，也可能有暫態。奇異值給出單步界線，真正量到的曲線則由沿軌跡、方向彼此對齊的雅可比矩陣乘積決定。

## 實驗 5.6——閘讓長距離依賴變得可學

**檢驗：** §5.3.8。**預測：** 可訓練參數量相差不超過 5% 的傳統 RNN 與 LSTM，分別能在多大的延遲 $D$ 下，學會在隨機序列的最後一步輸出第一個詞元。把「LSTM 能撐得更遠」當成待檢驗假說，不是驗收條件。

**步驟**（可使用框架的自動微分）。詞彙表含 8 個符號，$D\in\{5,10,20,50,100\}$。每次產生新的訓練批次，但為每個 $D$ 與種子凍結另一份 10,000 筆的測試集。事先登記最佳化器、批次大小、梯度裁剪與 2,000 次更新預算；至少 99% 的**測試**準確率才算成功。選擇隱藏寬度以匹配參數量，至少執行五個種子。LSTM 分別使用遺忘閘偏置 0 與 1。

**觀察：** 畫出成功機率與學習曲線對 $D$ 的關係，並保留每個種子的點。若 LSTM 沒有撐得更遠，先檢查飽和、最佳化預算與參數匹配，再決定是否修改假說。正面與負面結果都要報告；單次執行不算證據（單元 12）。

## 實驗 5.7——聯想記憶的容量

**檢驗：** §5.5.3、定理 5.3。**預測：** 隨機鍵、Hebbian 儲存時，在 $n=d_k$ 與 $n=4d_k$ 的**誤差均方根與值均方根之比**；再預測 delta 規則在低於、等於與高於 $d_k$ 時如何收斂。

**步驟。** 以下程式計算 Hebbian 的情況；請擴充為 delta 規則 $S \leftarrow S + (v - Sk)k^\top$，並對所有配對重複多輪。

```python
import numpy as np
rng = np.random.default_rng(0)
d_k, d_v = 16, 8
for n in [4, 16, 32, 64]:
    K = rng.normal(size=(n, d_k)); K /= np.linalg.norm(K, axis=1, keepdims=True)
    V = rng.normal(size=(n, d_v))
    S = V.T @ K                          # 外積 v_j k_j^T 的總和
    E = K @ S.T - V
    rms_ratio = np.sqrt(np.mean(np.sum(E**2, axis=1))) / np.sqrt(np.mean(np.sum(V**2, axis=1)))
    print(n, rms_ratio.round(3), np.sqrt((n - 1) / d_k).round(3))
```

**觀察：** 均方根比值——不是逐項相對誤差的平均——在期望下應符合 $\sqrt{(n-1)/d_k}$。對 delta 規則，跨多個種子記錄殘差隨輪數的曲線與 $\kappa(K)$。當 $n<d_k$ 且鍵獨立時，它可收斂到數值精度；接近 $n=d_k$ 時，隨機方形鍵矩陣常有很差的條件數，收斂可能很慢且種子間差異很大。當 $n>d_k$，任意隨機值通常不可能由線性記憶精確滿足，因此會留下非零殘差。不要把 200 輪後的某一個誤差硬寫成定理。

## 實驗 5.8——主幹專案階段 05：KV 快取與回憶壓力測試

**檢驗：** §5.3.11 與[主幹專案](/zh-tw/spine/)。**預測：** 在你所記錄的硬體上，KV 快取解碼於上下文 256 時可能帶來的加速**範圍**，而不是普遍數字；以及階段 04 模型的回憶準確率隨距離曲線。

**步驟。** 為主幹模型實作快取解碼。在評估模式下，驗證每個前綴的快取 logits 與完整重算結果落在事先聲明的容差內（`labs/unit-04-attention` 測試的不變量）。固定批次大小、dtype 與輸出長度，暖機後重複計時，報告中位數與離散程度。接著建立「`… key value … key`」序列，讓距離從 4 變化到架構支援的上下文長度；使用未見鍵與配對對照：移除第一組配對、打亂它的值，並固定局部詞元統計。

**觀察：** logits 應在聲明的數值容差內一致；若否，先檢查位置索引與快取順序（見 [KV 快取](/zh-tw/atlas/nodes/mech-kv-cache/)）。回憶曲線只能相對於對照解讀：它可能很早下降、保持平坦，甚至從未高於基準；不要先假設「視窗內很高」。超出架構上下文上限是另一種介入，可能需要改變位置處理，應分開報告（§5.7.6）。


## 實驗 5.9——語言之外：有雜訊的感測器

**檢驗：** §5.2.6、§5.6.2（穩態的隨機漫步卡爾曼濾波器會成為 EMA）。**預測：** 對程序雜訊變異數 $q=0.01$、量測雜訊變異數 $r=0.25$ 的隨機漫步溫度，使估計均方誤差最小的 EMA 係數 $\alpha$。

**步驟。** 以 `sensor_stream` 產生 5,000 步；計算 `steady_state_kalman_alpha(q,r)`；掃描 $\alpha$，並在至少 50 條獨立資料流上畫出含信賴區間的測試 MSE。接著把真實轉移改為 $\mu_t=1.01\mu_{t-1}+w_t$，比較：(i) 原本按隨機漫步調整的 EMA，(ii) 原始觀測 $\alpha=0$，以及 (iii) 使用正確轉移係數 1.01 的卡爾曼濾波器。同時報告絕對 MSE 與除以訊號功率的誤差。

**觀察重點：** 在隨機漫步模型下，母體最優值為 $\alpha\approx0.819$，也就是穩態卡爾曼值；有限樣本掃描應在它附近波動。動態改變後，舊 EMA 會產生模型錯置的延遲；原始觀測仍保有量測雜訊，但其誤差不一定發散。真正相關的比較，是使用正確轉移的卡爾曼濾波器。教訓不是「每個固定濾波器都失敗」，而是某個轉移模型下的最優係數，在動態改變後未必仍然最優。
