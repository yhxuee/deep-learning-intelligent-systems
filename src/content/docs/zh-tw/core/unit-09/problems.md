## 計算

**9.1 ★ [不使用 AI]** 對 logits $z = (1, 0, 0)$ 與獎勵 $r = (0, 1, 0)$，計算 $\pi$、$J$ 與精確梯度 $\partial J/\partial z$。

**9.2 ★ [不使用 AI]** 對 $\pi_{\text{ref}} = (0.5, 0.5)$、$r = (1, 0)$、$\beta = 1$，計算傾斜最佳解 $\pi^\star$。

**9.3 ★** 獎勵模型給出 $r(y_w) = 2.0$、$r(y_l) = 1.5$。Bradley–Terry 指派的偏好機率是多少？這個配對的損失是多少？

**9.4 ★** 一個兩狀態鏈每步支付獎勵 1，且回合永不結束。分別以 $\gamma = 0.9$ 與 $\gamma = 0.99$ 計算 $V$。

**9.5 ★★** 訓練已使 $\ln\frac{\pi(y_w)}{\pi_{\text{ref}}(y_w)} = 0.5$、$\ln\frac{\pi(y_l)}{\pi_{\text{ref}}(y_l)} = -0.5$。分別以 $\beta = 0.1$ 與 $\beta = 1$ 計算 DPO 損失。

**9.6 ★★** 在詳解例題 9.2 中，計算第 1 個分量依命題 9.2 的最佳基準，以及所得的變異數。

## 推導

**9.7 ★ [不使用 AI]** 推導分數函數估計量 $\nabla\mathbb{E}_\pi[r] = \mathbb{E}_\pi[r\nabla\ln\pi]$，並證明減去常數基準仍然不偏。

**9.8 ★★ [不使用 AI]** 證明命題 9.1，並證明最大值為 $\beta\ln Z$。

**9.9 ★★ [不使用 AI]** 由命題 9.1 與 Bradley–Terry 模型推導 DPO 損失。

**9.10 ★★** 推導 DPO 損失對單詞元答案之 logits 的梯度，並證明 softmax 項相消。

**9.11 ★★** 推導序列的逐詞元 REINFORCE 梯度，以及把 $G_0$ 換成 $G_t$ 的因果性改進。

## 證明

**9.12 ★★** 證明命題 9.2，並證明當 $(\partial_i\ln\pi)^2$ 與 $r$ 獨立時，平均獎勵是最佳的。

**9.13 ★★** 證明在每個獎勵上加上以勢能為基礎的塑形項 $\gamma\Phi(s') - \Phi(s)$，不會改變 MDP 的最佳策略。

**9.14 ★★★** 證明最大化 $J_\beta$ 等價於最小化 $\mathrm{KL}(\pi\,\Vert\,\pi^\star)$，並說明為什麼這使後訓練具有尋找眾數的性質。

**9.15 ★★★** 構造一對獎勵 $r$ 與 $r^\dagger$，使它們在預訓練策略以大於 0.01 的機率採取的每個動作上都一致，而最大化 $r$ 卻會最小化 $r^\dagger$。

## 實作與設計

**9.16 ★ [不使用 AI]** 憑記憶實作 `reinforce_grad`，並通過主幹專案的有限差分測試。

**9.17 ★★** 為階段 09 加入學習出來的價值基準（以最終隱藏狀態的線性函數預測獎勵），並與批次上的留一法基準比較變異數與速度。

**9.18 ★★** 實作群組相對優勢：每個提示抽樣 8 個答案，以各提示的平均獎勵作為其基準。與批次上的留一法基準比較，並量測單純群組平均的 $(G-1)/G$ 偏差。

**9.19 ★★** 由主幹專案的算術建立偏好資料集：以檢查器標註配對，但翻轉 20% 的標籤。訓練 DPO，回報標籤雜訊如何影響結果。

**9.20 ★★★** 為主幹模型設計「寫一個五歲小孩會喜歡的短故事」的獎勵。列出策略可以駭取它的三種方式，以及你如何偵測每一種。

## 部分解答

- **9.1** $\pi = (e, 1, 1)/(e + 2) = (0.576, 0.212, 0.212)$；$J = 0.212$；梯度 $\pi_k(r_k - J) = (-0.122, 0.167, -0.045)$。
- **9.2** $\pi^\star\propto(0.5e, 0.5) = (0.731, 0.269)$。
- **9.3** $\sigma(0.5) = 0.6225$；損失 $0.474$。
- **9.4** $V = 1/(1-\gamma)$：10 與 100。
- **9.5** $u = \beta\cdot1$：$\beta = 0.1$ 時損失為 $\ln(1 + e^{-0.1}) = 0.644$；$\beta = 1$ 時為 $\ln(1 + e^{-1}) = 0.313$。
