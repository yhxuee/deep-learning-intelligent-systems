## 9.1 問題

預訓練的主幹模型讀過 1 187 個故事，其中許多包含像「Ben had 2 eggs. Then Ben found 3 more. Now Ben has 5 eggs.」這樣的句子。其中 30% 寫出的答案是錯的——語料產生器故意寫入錯誤的和，就像充滿雜訊的網路文字。請預訓練模型接續「Now Ben has 」，它最可能的單一答案只有 **32%** 的時候是對的；平均而言，它只把 **0.20** 的機率放在正確的數字上。

單元 01–08 的任何工具都修不好這件事。更多預訓練只會更精確地擬合資料的錯誤率（單元 07，§7.7.1）。降低溫度只會讓模型原本的偏好更尖銳（單元 08，§8.7.6）。我們需要的是一個**不同的目標函數**：不是「預測文字」，而是「產生正確答案」。我們無法為每一個可能的提示寫下正確答案作為訓練目標——但我們可以*檢查*模型產生的任何答案。一個在答案等於 $a + b$ 時回傳 1、否則回傳 0 的程式就是一個**獎勵（reward）**，而模型的答案就是一個**動作（action）**。

從獎勵而非目標值學習，就是強化學習。應用在預訓練語言模型上時，它稱為**後訓練（post-training）**：今天的助理因此變得有幫助、推理模型因此以驗證器訓練、代理因此學會使用工具。它有一個典型的危險：模型最佳化的是*寫出來的*獎勵，而不是背後的意圖。一個只錯一個字元的檢查器——把 `==` 寫成 `>=`——就是另一個獎勵，而模型會發現這一點。

:::note[繼續閱讀前先預測]
主幹模型以每步 64 個提示、共 150 步做後訓練。用正確的檢查器時，你預期貪婪解碼的正確率是多少？用有錯的檢查器（只要答案至少為 $a + b$ 就給獎勵 1）時，訓練結束時的*訓練獎勵*會是多少？*真實*正確率又是多少？（詳解例題 9.6–9.7。）
:::

## 本單元建構的內容

1. **從第一原理看如何從獎勵學習**（§9.2）。動作與獎勵；為什麼抽樣擋住了一般的反向傳播；分數函數技巧；基準；連續決策；留在預訓練模型附近；從偏好學習。
2. **數學**（§9.3）。馬可夫決策過程與回報；策略梯度定理；優勢與價值函數；貝爾曼方程式；KL 正則化獎勵最大化的封閉形式最佳解；由成對偏好得到的獎勵模型；PPO 的截斷目標函數；DPO 的推導；可驗證獎勵與群組基準。
3. **一般理論**（§9.5）。梯度估計量的變異數與最佳基準；把 KL 正則化強化學習看成貝氏推論；古德哈特定律與獎勵過度最佳化。
4. **它留下的問題**（§9.7）。獎勵是一種量測，最佳化它會暴露量測與意圖之間的每一個落差。分數何時才是我們想要之物的證據？那是[單元 10](/zh-tw/core/unit-10/)。
