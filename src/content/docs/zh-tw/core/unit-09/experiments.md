這些實驗的目的不是取得最高獎勵，而是學會哪一項測量能解釋哪一個變化。每次執行都保留一張小型實驗表：

| 欄位 | 執行前就要記錄的內容 |
|---|---|
| 問題 | 這次只檢驗哪一項主張？ |
| 預測 | 方向；能計算時也寫下數值 |
| 介入 | 唯一刻意改變的因子 |
| 控制 | 種子、提示、參考策略、樣本預算 |
| 測量 | 代理獎勵**以及**獨立任務指標 |
| 決策 | 什麼結果會使你改變看法？ |

程式碼：[`spine/stage09_post_training.py`](https://github.com/yhxuee/deep-learning-intelligent-systems/tree/main/spine)，驗證測試則在 `spine/test_spine.py`。以下指令假設你位於儲存庫根目錄並使用隨附的虛擬環境。若缺少階段 07 檢查點，先執行階段 07 腳本。

## 實驗 9.1——逐樣本看見策略梯度

**問題。** REINFORCE 為何不偏卻嘈雜？基準究竟改變了什麼？

使用三動作吃角子老虎機：

$$
\pi=(1/3,1/3,1/3),\qquad r=(1,0,0).
$$

對 logit $z_1$，一個樣本給出

$$
g_1(a)=(r(a)-b)\left(\mathbf 1[a=1]-\pi_1\right).
$$

**先預測。** 分別對 $b=0$ 與 $b=1/3$ 算出 $g_1$ 的三個可能值；模擬前就預測平均與變異數。詳解例題 9.1–9.2 的已知答案是：兩者平均皆為 $0.2222$，變異數則為 $0.0988$ 與 $0.0247$。

**步驟。** 分別抽取 100、1,000、100,000 個動作。在每個樣本數下回報樣本平均、變異數，以及與精確梯度的誤差；以十個種子重複。

**解讀。** 基準改變變異數，不改變梯度期望。平均獎勵基準在本例有幫助，但不要把它誤當普遍排序：任意基準也可能增加變異數。命題 9.2 給出逐分量、使變異數最小的常數。

**失敗檢查。** 若加入常數基準後，平均出現系統性位移，實作可能錯誤地對抽樣基準微分，或讓它依賴所選動作。

## 實驗 9.2——看 KL 正則化如何傾斜分布

**問題。** 數值最佳化能否找回封閉形式最佳解？$\beta$ 扮演什麼角色？

使用

$$
\pi_{\mathrm{ref}}=(0.2,0.5,0.3),\qquad r=(1,0,0),
$$

因此

$$
\pi^\star(a)=\frac{\pi_{\mathrm{ref}}(a)e^{r(a)/\beta}}{\sum_b\pi_{\mathrm{ref}}(b)e^{r(b)/\beta}}.
$$

**先預測。** 計算 $\beta\in\{0.1,0.5,2\}$ 的 $\pi^\star$。哪一個最靠近參考分布？哪一個最集中於動作 1？

**步驟。** 先執行封閉形式測試：

```bash
LAB_IMPL=reference .venv/bin/python -m pytest spine/test_spine.py -k tilted -q
```

接著從三個不同初始分布出發，以精確梯度上升最佳化 logits。畫出 $J_\beta$、$D_{\mathrm{KL}}(\pi\|\pi_{\mathrm{ref}})$ 與 $D_{\mathrm{KL}}(\pi\|\pi^\star)$。最後把精確梯度換成批次 16 與 256 的 REINFORCE。

**解讀。** 步長穩定時，精確最佳化應從三個起點趨近同一個內部最佳解。隨機執行會在其附近波動；較大批次減少的是抽樣雜訊，不是目標設定錯誤。小 $\beta$ 讓獎勵差異占主導，大 $\beta$ 則保留較多參考分布。

**失敗檢查。** 確認實作的 KL 方向是 $D_{\mathrm{KL}}(\pi\|\pi_{\mathrm{ref}})$。反轉方向會同時改變梯度與邊界行為。

## 實驗 9.3——後訓練主幹模型，並讀懂每一個儀表

**問題。** 後訓練提高了真實算術正確率，還是只提高畫面上名為「獎勵」的數字？

**先預測。** 隨訓練步數畫四條曲線：抽樣訓練獎勵、留出貪婪正確率、留出正確數字的平均機率，以及相對凍結參考策略的 KL。先預測各自的變化方向，再給合理範圍，不要強求每一步單調。

**步驟。** 從 `spine` 目錄執行：

```bash
cd spine
../.venv/bin/python stage09_post_training.py --steps 150
```

隨附的決定性設定可作為方向參考，不是普遍基準：預訓練模型的留出貪婪正確率約為 $0.32$；精確獎勵的 REINFORCE 與 DPO 分別達到約 $0.82$ 與 $0.78$。以種子 0–4 重複，回報平均、標準差與每一個個別結果。

**解讀。** 貪婪正確率與平均 $p(\text{正確})$ 回答不同問題：前者問哪個詞元勝出，後者問正確答案取得多少機率質量。KL 測量相對參考策略的改變，不是正確性；較大 KL 可能伴隨進步、傷害，或兩者同時發生。

**失敗檢查。** 不要用更新時抽到的提示做評估。訓練前凍結留出提示，並讓所有方法與種子使用完全相同的提示。

## 實驗 9.4——調整 KL「牽繩」，但不要把它叫作安全

**問題。** KL 係數如何取捨任務進步與分布改變？

**先預測。** 對 $\beta\in\{0,0.01,0.05,0.5,5\}$，排列可能的更新幅度。**不要**預測最小 $\beta$ 必然有最高留出正確率；最佳化雜訊與過度擬合都可能打破這個排序。

**步驟。** 固定初始化、提示、種子、批次大小、步數與學習率。對每個 $\beta$ 記錄：

- 算術貪婪正確率與 $p(\text{正確})$；
- 算術提示上的 KL；
- 凍結非算術故事集上的下一字元 NLL；
- 熵與每個輸出數字的頻率。

畫正確率對 KL，而不只畫正確率對 $\beta$。至少以五個種子重複。

**解讀。** $\beta$ 是類似拉格朗日乘數的取捨參數，不是安全旋鈕。兩次平均 KL 相同的執行，可能傷害不同能力。若算術進步而故事 NLL 惡化，實驗就揭露了單看算術獎勵無法看見的干擾。

**失敗檢查。** KL 數值只有在方向、平均方式、詞元範圍與對數底數都已記錄時才有意義。四項缺一不可。

## 實驗 9.5——離線配對與目前策略樣本

**問題。** 固定偏好資料集何時會過時？

**先預測。** 建立兩種配對：「簡單」配對的被拒答案遠離正確數字；「邊界附近」配對則只差一。模型學會避開明顯錯誤數字後，哪一組仍會提供有用梯度？

**步驟。** 比較三種預算：

1. 在一組固定簡單配對上做 DPO；
2. 在一組固定邊界配對上做 DPO；
3. 使用目前策略的新樣本與精確檢查器做 REINFORCE。

配對提示評估次數，並分開回報實際時間與檢查器呼叫次數。不同演算法的一個「步驟」不是公平的計算單位。追蹤留出正確率、KL，以及訓練配對中策略已強烈偏好贏家者所占比例。

**解讀。** 固定配對使實驗容易重現；新樣本則追蹤目前策略所犯的錯。DPO 的策略更新不需要在策略抽樣，但配對資料仍必須來自某處。沒有檢查器時，REINFORCE 不會自行解決任務；沒有可信比較來源時，DPO 也不會。

**失敗檢查。** 若三個方法看到不同提示，或使用不同數量的回饋查詢，就把比較標成「系統層級」，不要稱為只比較最佳化器。

## 實驗 9.6——在策略之前找出獎勵駭取

**問題。** 只檢查檢查器，能不能先預測最佳化器會找到的「聰明」解法？

對目標 $t=a+b$，稽核三個候選獎勵：

```python
reward_a = int(answer >= t)
reward_b = int(answer in "0123456789")
reward_c = int(abs(answer - t) <= 1)
```

**先預測。** 對每個可能目標 $t\in\{2,\ldots,9\}$，列舉十個數字動作，標出使各獎勵最大的動作。

**步驟。** 分別以三個檢查器訓練同一策略。每個檢查點都記錄候選獎勵與精確比對正確率，並依目標記錄輸出直方圖。

**解讀。** 檢查器 (a) 獎勵大數字，可能塌縮到 9；(b) 只分辨數字與非數字，在數字之間完全沒有正確性訊號；(c) 除邊界外都定義三個數值的接受帶，所以精確答案只是多個同獎勵行為之一。預訓練分布與最佳化器會決定哪個被接受的行為勝出。

**失敗檢查。** 訓練前先用真值表、邊界案例、等價有效形式與對抗輸出測試檢查器。策略不應成為評估器第一個認真的使用者。

## 實驗 9.7——建立檢查器稽核集

**問題。** 一個刻意組織的小型稽核，能否預測平均驗證獎勵掩蓋的失敗？

**先預測。** 產生例子前，先寫出至少五個失敗族群：正確答案、差一、太大、太小、非數字、格式錯誤；若答案格式擴充，再加入 `05` 與 `5` 這類等價形式。

**步驟。** 建立欄位為 `prompt`、`candidate`、`intended_valid`、`checker_reward`、`failure_family` 的表格。不要從訓練策略抽樣，並要求：

- 每個族群含多個目標；
- 同時有普通與邊界目標；
- 對安全關鍵的無效案例，偽陽性必須為零；
- 回報混淆矩陣，不只回報正確率。

以這個稽核集檢查精確檢查器與實驗 9.6 的三個有錯檢查器。接著在任何策略訓練**之前**，判定哪些檢查器可以使用。

**解讀。** 隨機驗證估計某個抽樣分布下的平均行為；結構化稽核則詢問已知語意要求是否有被表示。兩者都需要：稽核找出具名漏洞，隨機評估估計其盛行率。

**失敗檢查。** 通過有限稽核不代表檢查器完整。記錄尚未涵蓋的輸入空間，並在訓練期間持續保留獨立正確性評估。這項紀律就是通往單元 10 的橋樑。

## 最低限度的實驗報告

可信報告應包含：預測、確切指令或程式修訂、檢查點身分、種子、提示切分、樣本或回饋預算、所有代理與獨立指標、逐種子原始值，以及至少一次失敗或意外的執行。「獎勵上升」還不是結論；你必須先說清楚是哪一個獎勵、由誰計算，以及哪一個獨立測量跟著變化。
