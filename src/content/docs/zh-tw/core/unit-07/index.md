## 7.1 問題

[單元 06](/zh-tw/core/unit-06/) 結束在一道牆前。計算最適的訓練需要的詞元數，大約是模型參數量的二十倍；一個 700 億參數的模型需要約 1.4 兆個詞元。監督式學習每個樣本都需要一個標籤，而一兆個標籤不是任何人負擔得起的預算。

然而，兆級詞元的原始文本確實存在。穿過這道牆的方法，是注意到**原始資料本身就包含監督訊號**。從主幹語料中任取一句：「Ben had 2 eggs. Then Ben found 3 more.」把最後一個字元藏起來，問它是什麼；把第三個詞藏起來，問它是什麼；把第二句藏起來，問幾個候選中哪一個與第一句相配。每個問題的正確答案*都在資料本身之中*。被訓練來回答這些問題的模型，必須學會拼字、文法、故事中的名字，而且——如果要答對雞蛋的數目——還要學會一些算術。沒有人標註任何東西。

這就是**自監督學習（self-supervised learning）**，而下一個詞元預測是它影響最深遠的例子：文本的每個字元都是它之前那些字元的預測目標，所以主幹語料 363,418 個乾淨的訓練字元，每走過一遍就免費提供 363,417 個訓練目標。

兩個複雜之處讓它成為一門學問，而不只是一個技巧：

1. **隱藏什麼決定了學到什麼。** 從左側預測下一個詞元，得到一個生成器；從兩側預測被遮罩的詞元，得到更適合分析的表示，卻沒有生成器；預測哪些配對屬於同一組，得到嵌入，卻完全不預測任何內容。每一種選擇都是一種歸納偏差（單元 01，§1.5.3）。
2. **原始資料不是乾淨的資料。** 主幹語料就像網路一樣，包含完全與近似重複（植入了 67 組）、洩漏到訓練中的保留故事（6 個），以及系統性錯誤的陳述（30% 的算術）。自監督目標會把*全部*都學起來。去重、去污染與品質控制不是前處理雜務；它們是學習演算法的一部分。

:::note[繼續閱讀前先預測]
主幹語料的訓練部分有 1,260 個故事，其中 67 個是另一個訓練故事的完全或近似副本，6 個是保留故事的副本。以 16 個帶、每帶 4 個雜湊的 MinHash 偵測器掃描它。你預期它能抓到多少比例的植入近似重複（詞 5 元組 Jaccard 相似度約 0.78）？它會錯誤標記多少個*不同的*故事（Jaccard 低於 0.25）？詳解例題 7.3–7.4 給出答案。
:::

## 本單元建構的內容

1. **來自結構的監督**（§7.2）。隱藏與預測；讓下一個詞元預測成為精確密度建模的機率連鎖律；遮罩與對比的替代方案；把資料當成設計對象。
2. **數學**（§7.3）。自迴歸目標與教師強制；把遮罩語言建模看成偽概似；對比學習與互資訊的 InfoNCE 下界；Jaccard 相似度、MinHash 與局部敏感雜湊；污染檢查。
3. **一般理論**（§7.5）。每個目標的最佳解是什麼；為什麼對比學習需要負樣本；預訓練何時有助於下游任務。
4. **留下的問題**（§7.7）。預訓練模型是一個分布。使用它需要抽樣——而連續資料沒有下一個詞元。這是[單元 08](/zh-tw/core/unit-08/)。
