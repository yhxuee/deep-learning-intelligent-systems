標記：**[D]** 推導、**[E]** 實驗證據、**[O]** 工程觀察、**[H]** 尚待驗證的假說。

反例的目的不是宣稱自監督「沒有用」，而是指出：即使訓練成功，仍有哪些結論**不能**跟著推出。看清這條邊界，我們才知道下一步該量什麼。

## 7.7.1 吻合文字統計，不等於學到真相

在母體最優解上，下一詞元預測會重現語料條件分布 $p_{\text{data}}(x_t\mid x_{<t})$（§7.5.1）**[D]**。只有當資料生成過程讓真相在預測上可見時，「真」才會進入這條方程式。

主幹資料生成器提供了一個受控例子：30% 的算術故事會把總和改成錯誤答案。在「同一上下文只有一個正確續接與一個錯誤續接」這個簡化情況下，資料條件分布會分別給它們 $0.7$ 與 $0.3$ 的機率。最大概似逐漸逼近這個頻率時，正是在完成它被交付的工作；沒有任何訊號要求它把全部機率移到數學正解。

但不要過度解讀這個計算。有限的主幹模型看到許多不同名字、數字與上下文，所以不能由此推出「它恰好把 30% 機率給這個錯誤數字」。單元 09 會量測它的實際行為。這個計算只隔離出一項機制：預測目標本身無法把常見模式標成迷思、過時事實、諷刺或謊言。

TruthfulQA 給了一項實驗警告：在該研究涵蓋的模型家族與題目內，擴大預訓練語言模型並未可靠提高真實性，有時反而更會模仿常見迷思（[Lin 等人，2022](/zh-tw/references/#lin-2022)）**[E]**。這不是「模型越大一定越不真實」的定理；它證明的是較低預訓練損失並非真實性證書。

**反例。** 想像一份語料中，每個錯誤醫療說法都被複製十次，而每份更正只出現一次。完美的語料模型理應更常預測錯誤說法。最大概似做得越好，模型反而離臨床人員想要的行為越遠，因為訓練分布與理想決策規則並不相同。

## 7.7.2 記憶與泛化可以同時存在

「記憶」需要可操作的定義。它可能表示模型：

- 對某段訓練序列給出異常高的概似；
- 看到前綴後逐字輸出很長的訓練段落；
- 洩露某筆紀錄是否出現在訓練中；
- 或依賴範例專屬捷徑，而不是可重用規則。

這些測試彼此相關，卻不等價。模型可能已泛化文法，同時逐字吐出一個罕見電話號碼；良好的保留集 NLL 也不能排除局部記憶。

[Carlini 等人（2021）](/zh-tw/references/#carlini-2021)從 GPT-2 抽樣，還原出逐字訓練序列，其中包含可識別個人資訊 **[E]**。後續受控研究在其實驗設定內發現三項近似對數線性關係：可提取記憶會隨模型容量、範例重複次數與可用提示上下文增加（[Carlini 等人，2023](/zh-tw/references/#carlini-2023)）**[E]**。這些是量到的趨勢，不是跨所有架構與資料管線都成立的普遍公式。

去重可以降低逐字輸出與訓練—測試重疊（[Lee 等人，2022](/zh-tw/references/#lee-2022)）**[E]**，但「已去重」不等於「不可能記憶」。唯一但敏感的字串仍可能具有很大影響；近似副本可能躲過偵測；大模型也可能擬合只出現一次的內容。

主幹訓練從約 $363{,}418$ 個字元的串流抽樣了約 $8.192$ 百萬個訓練字元——相當於約 $22.5$ 個串流長度的**等效詞元抽取量**。它不是依序完整掃過 22.5 次：視窗以放回方式抽樣，也可能跨越故事邊界。因此，實驗 7.4 會量測精確重現與給定前綴後的重現，而不會只從接觸量宣告模型已記憶。

## 7.7.3 低文字重疊不是「沒有污染」的證書

每種污染偵測器都有自己的目標類別。文字 8-gram 重疊對近乎逐字的重用很敏感，卻不是為了尋找資訊可能洩漏的所有方式而設計。

| 情況 | 8-gram 偵測器可能怎麼做 | 原因 |
|---|---|---|
| 完整複製的答案 | 標出 | 許多長片語保持不變 |
| 忠實改寫 | 漏掉 | 用詞改變，但資訊仍在 |
| 翻譯 | 漏掉 | 表面詞元幾乎完全改變 |
| 把答案表重新排成表格 | 漏掉大部分 | 局部順序與邊界改變 |
| 常見法律制式文字 | 標出 | 長共同片語不一定表示基準洩漏 |
| 很短的題目 | 變得不穩定 | 只有極少、甚至沒有相異 8-gram |

還有一個拼貼問題：訓練集所有 $n$-gram 的聯集可能覆蓋整個保留項目，即使沒有任何一份訓練文件含有完整題目。因此，方向性覆蓋率很高是查看來源脈絡的理由，不是基準被複製的自動證明。

模型式檢定可以探查文字比對漏掉的訊號。Oren 等人比較模型對可交換基準之標準順序與打亂順序的概似，檢驗標準順序是否異常地高（[Oren 等人，2024](/zh-tw/references/#oren-2024)）**[E]**。該方法有特定虛無假設，並不是通用的改寫偵測器。補全與概似檢定同樣依賴模型存取權、校準與有效參考分布。

從低 $n$-gram 重疊能得到的正確結論很窄：**在這個表示與門檻下，我們只找到很少近乎逐字重疊的證據。** 更強的保證必須結合來源脈絡、多種偵測器、凍結的切分規則，以及在可能時使用訓練快照之後才建立的評估資料。即使是快照後資料仍需要存取控制，因為之後公開到網路上，也可能洩漏進未來模型。

## 7.7.4 預訓練目標只是用途的代理

代理目標可以與理想行為相關，卻不會直接定義它。

- 下一詞元損失獎勵準確續寫語料；使用者可能需要可查證的答案或安全行動。
- 遮罩重建獎勵由周圍上下文還原內容；使用者可能需要分布轉移下仍校準良好的類別機率。
- 對比損失獎勵從指定負樣本中找出正樣本；使用者可能在意正、負樣本都未呈現的另一項區別。

**捷徑反例。** 假設預訓練樣本中的有害留言全來自同一網站，而且都帶著相同頁首。表示只要編碼頁首，就能支援極佳的訓練分類；頁首一消失，原本想要的語意區別其實從未被學會。

因此，低預訓練損失只建立了模型在預訓練代理目標上的成功。解碼（單元 08）、行為回饋（單元 09）與任務專屬評估（單元 10）都會引入額外選擇。它們可能改善理想用途，也可能創造新捷徑或抹掉有用行為。「已預訓練」代表一個具有已量測性質的起始狀態，不是已完成的規格。

## 7.7.5 資料品質是一個向量，不是一個分數

一份文件可能流暢卻錯誤、準確卻過時、有用卻未獲授權、多樣卻嘈雜；也可能單獨看來無害，與其他資料組合後卻暴露隱私。把這些全叫作「品質」，會遮蔽不同目標。

| 面向 | 一個可能的稽核問題 | 一個可能的取捨 |
|---|---|---|
| 事實性 | 主張能否追溯到可靠且有日期的來源？ | 參考來源可能遺漏新興或少數知識 |
| 多樣性 | 還保留哪些語言、方言、領域與觀點？ | 固定計算量下，廣度增加可能提高雜訊 |
| 隱私 | 是否含有個人或祕密字串？ | 過度積極的過濾可能忽略上下文或刪除合法公開紀錄 |
| 權利與同意 | 這些內容是否可用於此目的？ | 法律許可與社會可接受性並不相同 |
| 新鮮度 | 快照時間是否符合部署時間？ | 新近資料經過的審查較少 |
| 教學價值 | 文字是否解釋推理，而不只給答案？ | 教材式過濾可能縮窄風格與主題覆蓋 |

每個過濾器都實作了一種歸納偏差 **[O]**。如果分類器偏好近似參考百科全書的散文，它可能系統性降低對話、方言或專業格式的權重。之後報告的下游增益只適用於所用評估，不能證明語料在所有意義上都更好。

「更多資料」同樣有條件。固定計算量下，加入低價值文件可能排擠有用更新；加入副本會改變權重；加入生成文字可能放大生成器的遺漏。正確比較應凍結計算、模型、切分與評估，再改變一項有記錄的資料決策。語料大小本身不是處置變項。

## 7.7.6 學到的分布還不是行為

階段 07 結束後，主幹模型提供的是條件機率。若要產生一段續寫，還要有解碼規則把這些機率轉成選擇。

- **貪婪解碼**永遠選下一步機率最大的詞元。它是確定性的，但局部最可能的選擇可能進入重複迴圈。
- **祖先抽樣**從完整條件分布抽取。它較忠實地代表模型分布，卻也會抽到其中低機率的錯誤。
- **截斷與溫度**刻意改變分布，在多樣性與集中程度之間取捨。

所以，兩個權重完全相同的系統可以展現不同文字行為。反過來，一個流暢樣本也不能證明底層機率已校準，或另一個解碼種子同樣安全。單元 08 會在同一檢查點上量測這些差異。

連續資料方面，有一點必須更正：機率連鎖律並不限於詞元。連續向量同樣能分解成條件密度；影像也能依序排列像素或離散碼元，以自迴歸方式生成。真正的困難是這個順序可能很人為，而且逐步抽樣很慢，而不是數學上禁止分解。[單元 08](/zh-tw/core/unit-08/) 的擴散、流與其他連續時間構造，會提供不同的訓練與抽樣路徑。

因此，下一個問題不只是「損失下降了嗎？」而是：**哪一套程序把學到的統計物件變成我們觀察到的行為？那套程序實際產生的又是哪個分布？**

## 7.7.7 精簡診斷表

| 觀察 | 本身不能證明 | 下一項檢查 |
|---|---|---|
| 較低的驗證 NLL | 真實性或罕見技能能力 | 事實與技能分層測試 |
| 沒有偵測到 8-gram 重疊 | 沒有改寫或翻譯洩漏 | 來源脈絡，加上語意式與模型式稽核 |
| 去重模型的提取率較低 | 唯一紀錄已具隱私保障 | 金絲雀、成員推斷與定向提取測試 |
| 預訓練代理目標更好 | 部署決策更好 | 凍結的下游與分布轉移評估 |
| 過濾後語料更大 | 有效資料更好 | 固定計算量的資料消融 |
| 一個流暢樣本 | 抽樣分布可靠 | 多種子比例與信賴區間 |

這些並不是放棄自監督的理由；它們是以科學方式使用自監督所必需的量測。
