## 計算

**3.1 ★ [不使用 AI]** 對 $L(w) = (w-3)^2 + 2$，從 $w_0 = 0$ 出發，分別以 $\eta = 0.3$ 與 $\eta = 0.9$ 計算五個梯度下降迭代值。$\eta$ 為多少時會發散？

**3.2 ★ [不使用 AI]** 對 §3.3.1 的神經元，把 $t = 0$ 改為 $t = 1$，以反向模式計算 $\partial L/\partial w_1$、$\partial L/\partial w_2$、$\partial L/\partial b$。用中央差分檢查其中一個。

**3.3 ★★** *為什麼隨機搜尋在高維失敗。* 令 $u$ 為 $\mathbb{R}^n$ 中均勻隨機的單位向量，$g$ 為固定的單位向量。證明 $\mathbb E[(u^{\top}g)^2] = 1/n$。由此推得：隨機的一小步讓平滑損失下降的一階期望量為零，典型大小只有 $\|\nabla L\|/\sqrt n$——而梯度步能達到 $\|\nabla L\|$。

**3.4 ★** 對 $s = (0, 0, 0, 0)$、目標類別 3 的 softmax 交叉熵，計算 $p$、損失與 $\bar s$。把損失與單元 01 的均勻基準連結起來。

**3.5 ★★** 對 $H = \mathrm{diag}(0.5, 2, 8)$：求 $\eta$ 的穩定上限、最佳固定步長、對應的速率，以及把誤差縮小 $10^{4}$ 倍所需步數。再對調好的重球動量重做一次。

**3.6 ★** Adam（$\beta_1 = 0.9$、$\beta_2 = 0.999$）連續三步收到常數梯度 $g = 2$。計算 $k = 1,2,3$ 時的 $m_k, v_k, \hat m_k, \hat v_k$ 與更新量。

## 推導

**3.7 ★★ [不使用 AI]** 推導下列運算的向量–雅可比乘積：(a) 單獨的 $y = \mathrm{softmax}(x)$，證明 $\bar x = p\odot(\bar y - (p^{\top}\bar y)\mathbf 1)$；(b) 沒有增益與偏置的層正規化 $y = (x - \mu)/\sigma$，其中 $\mu, \sigma$ 為 $x$ 的平均與標準差。

**3.8 ★★** 以足標記號推導 $Y = XW$ 的批次梯度 $\bar W = X^{\top}\bar Y$ 與 $\bar X = \bar YW^{\top}$，並驗證形狀規則。

**3.9 ★★ [不使用 AI]** 對具 ReLU 隱藏層、softmax 交叉熵輸出、批次大小 $B$ 的 MLP，推導完整的反向傳播演算法，並以乘加次數說明反向傳遞相對於前向傳遞的成本。

**3.10 ★★** 證明 §3.2.1 的損失 Hessian 為常數，且以 $\eta = 1/L''$ 做梯度下降可以從任何起點一步到達 $w^*$。為什麼對 $H = \mathrm{diag}(1, 10)$ 沒有任何固定 $\eta$ 能做到這點？

**3.11 ★★** 證明從大小為 $N$ 的資料集*不放回*地抽取小批次，得到的梯度是不偏的，且其變異數比放回抽樣小 $\frac{N-B}{N-1}$ 倍。

## 證明

**3.12 ★★ [不使用 AI]** 證明引理 3.1（下降引理）及其關於梯度步的系理。

**3.13 ★★** 證明若 $L$ 二次可微且處處 $\|H(\theta)\|_2\le\beta$，則 $L$ 為 $\beta$-平滑。

**3.14 ★★** 證明 $\mu$-強凸函數滿足 Polyak–Łojasiewicz 不等式，並證明 $f(x) = x^2 + 3\sin^2x$ 雖不是凸函數，卻滿足 PL 不等式（以數值方式找出一個有效的常數）。

**3.15 ★★★** 完整推導 §3.5.7 的動量分析：證明在區間內兩根的模長為 $\sqrt\beta$，推導最佳的 $\eta, \beta$，並證明速率為 $(\sqrt\kappa-1)/(\sqrt\kappa+1)$。

**3.16 ★★★** 對遞減排程 $\eta_k = \eta_0/\sqrt{k+1}$ 證明 §3.5.6 的 SGD 上界，並證明 $\min_{k<K}\mathbb E\|\nabla L(\theta_k)\|^2 = O(\log K/\sqrt K)$。

**3.17 ★★（實驗室）** 在你的純量引擎中加入 `relu`、`sigmoid` 與 `log`，並用它在 XOR 問題上訓練兩層網路。報告損失曲線，以及初始化時的梯度檢查。

**3.18 ★★** 以*對偶數*（$a + b\varepsilon$，$\varepsilon^2 = 0$）實作前向模式微分，並在 §3.3.2 的神經元上驗證。為什麼這能給出精確的導數？

**3.19 ★★** 以 NumPy 為 64 層 MLP 實作檢查點重算：每 8 層儲存一次活化值，在反向時重算其餘部分。與全部儲存相比，量測峰值記憶體與時間。

**3.20 ★★★** 選一篇近期的最佳化器論文。指出它聲稱改善了 §3.8.7 中的哪一個量，在二次函數與主幹模型上設計一個能檢驗該主張的實驗，並說明什麼結果會推翻它。

## 部分解答

- **3.1** $L'(w) = 2(w-3)$，曲率 2，$\eta<1$ 時穩定。$\eta = 0.3$ 時誤差每步乘上 $0.4$：$w = 0, 1.8, 2.52, 2.808, 2.923, 2.969$。$\eta = 0.9$ 時因子為 $-0.8$：$w = 0, 5.4, 1.08, 4.536, 1.771, 3.983$——振盪中收斂。$\eta>1$ 時發散。
- **3.4** $p = (0.25, 0.25, 0.25, 0.25)$，損失 $\ln4 = 1.386$（均勻基準 $\ln V$），$\bar s = (0.25, 0.25, -0.75, 0.25)$。
- **3.5** 穩定條件 $\eta<0.25$；$\eta^* = 2/8.5 = 0.235$；$\kappa = 16$，速率 $15/17 = 0.882$；步數 $\ln10^4/(-\ln0.882) \approx 73.6$。動量：速率 $(4-1)/(4+1) = 0.6$，漸近約 18 步。
- **3.6** 對每個 $k$ 都有 $\hat m_k = 2$、$\hat v_k = 4$（對常數梯度，偏差校正是精確的），所以每次更新都是 $-\eta\cdot2/(2+\epsilon)\approx-\eta$。
