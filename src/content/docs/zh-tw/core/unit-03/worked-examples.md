## 詳解例題 3.1——直線擬合的梯度下降

**問題。** 以 §3.2.1 的資料，$L(w) = \tfrac13(14w^2 - 56.2w + 56.42)$。從 $w_0 = 0$ 出發、以 $\eta = 0.1$ 做五步梯度下降。計算前，先預測每步的誤差縮減因子。

**解答。** $L'(w) = \tfrac13(28w - 56.2)$，$L''(w) = 28/3 \approx 9.333$。在拋物線上，誤差每步乘上 $1-\eta L'' = 1 - 0.9333 = 0.0667$（§3.2.3），所以每一步應該消除剩餘誤差的約 93%。

| $k$ | $w_k$ | $L(w_k)$ | $L'(w_k)$ | $w_{k+1} = w_k - 0.1L'(w_k)$ |
|---|---|---|---|---|
| 0 | 0.000000 | 18.806667 | −18.733333 | 1.873333 |
| 1 | 1.873333 | 0.089985 | −1.248889 | 1.998222 |
| 2 | 1.998222 | 0.006800 | −0.083259 | 2.006548 |
| 3 | 2.006548 | 0.006430 | −0.005551 | 2.007103 |
| 4 | 2.007103 | 0.006429 | −0.000370 | 2.007140 |

誤差 $w^* - w_k$ 依序為 $2.00714 \to 0.13381 \to 0.00892 \to 0.00059 \to 0.00004$：每個比值都是 $0.0667$，與預測完全相同。最小損失 $0.006429$ 不為零，因為沒有一條通過原點的直線能穿過全部三點。

## 詳解例題 3.2——共用輸入處的累加

**問題。** 對 $f(a,b) = (a+b)\cdot a + \tanh a$，在 $a = 0.5$、$b = -1$ 時以反向模式計算 $\partial f/\partial a$ 與 $\partial f/\partial b$，列出 $\bar a$ 的每一份貢獻，並與解析導數比對。

**解答。** 軌跡：$v_1 = a + b = -0.5$；$v_2 = v_1\cdot a = -0.25$；$v_3 = \tanh a = 0.462117$；$f = v_2 + v_3 = 0.212117$。

輸入 $a$ 有**三個子節點**（$v_1$、$v_2$、$v_3$）。依相反順序反向計算：

| 步驟 | 規則 | 貢獻 | 累計 $\bar a$ |
|---|---|---|---|
| $\bar f = 1$ | 起始值 | | 0 |
| $f = v_2 + v_3$ | $\bar v_2 \mathrel{+}= 1$、$\bar v_3 \mathrel{+}= 1$ | | 0 |
| $v_3 = \tanh a$ | $\bar a \mathrel{+}= \bar v_3(1-v_3^2)$ | $+0.786448$ | 0.786448 |
| $v_2 = v_1\cdot a$ | $\bar v_1 \mathrel{+}= \bar v_2\,a$；$\ \bar a \mathrel{+}= \bar v_2\,v_1$ | $\bar v_1 = 0.5$；$-0.5$ | 0.286448 |
| $v_1 = a + b$ | $\bar a \mathrel{+}= \bar v_1$；$\ \bar b \mathrel{+}= \bar v_1$ | $+0.5$；$\bar b = 0.5$ | **0.786448** |

**檢查。** $f = a^2 + ab + \tanh a$，所以 $\partial f/\partial a = 2a + b + (1-\tanh^2a) = 1 - 1 + 0.786448 = 0.786448$ ✓，$\partial f/\partial b = a = 0.5$ ✓。若實作用*賦值*取代累加，$\bar a$ 會是 $0.5$（只有最後一份貢獻）——錯了 36%，實驗室的扇出測試也會失敗。

## 詳解例題 3.3——手算兩層網路

**問題。** 輸入 $x = (1, 2)$；隱藏層 $z_1 = W_1x + b_1$、$h_1 = \tanh z_1$，其中
$W_1 = \begin{pmatrix}0.5&-0.25\\0.3&0.1\end{pmatrix}$、$b_1 = (0.1, -0.2)$；輸出 $\hat y = w_2^{\top}h_1 + b_2$，$w_2 = (1, -2)$、$b_2 = 0.05$；損失 $L = \tfrac12(\hat y - 1)^2$。以 §3.3.6 的演算法計算所有梯度，並以中央差分驗證 $\partial L/\partial (W_1)_{12}$。

**前向。**
$z_1 = (0.5 - 0.5 + 0.1,\ 0.3 + 0.2 - 0.2) = (0.1,\ 0.3)$；
$h_1 = (\tanh 0.1,\ \tanh 0.3) = (0.099668,\ 0.291313)$；
$\hat y = 0.099668 - 2(0.291313) + 0.05 = -0.432957$；
$L = \tfrac12(-1.432957)^2 = 1.026683$。

**反向。**

| 量 | 規則 | 值 |
|---|---|---|
| $\bar{\hat y}$ | $\hat y - 1$ | −1.432957 |
| $\bar w_2$ | $\bar{\hat y}\,h_1$ | (−0.142820, −0.417439) |
| $\bar b_2$ | $\bar{\hat y}$ | −1.432957 |
| $\bar h_1$ | $w_2\,\bar{\hat y}$ | (−1.432957, 2.865914) |
| $1-h_1^2$ | | (0.990066, 0.915137) |
| $\bar z_1$ | $\bar h_1\odot(1-h_1^2)$ | (−1.418723, 2.622704) |
| $\bar W_1$ | $\bar z_1\,x^{\top}$ | $\begin{pmatrix}-1.418723&-2.837445\\2.622704&5.245409\end{pmatrix}$ |
| $\bar b_1$ | $\bar z_1$ | (−1.418723, 2.622704) |

**檢查。** 把 $(W_1)_{12}$ 擾動 $\pm10^{-6}$ 取中央差分，得 $-2.8374453$ ✓。

**解讀結果。** 第二個隱藏單元權重的梯度較大且符號相反：輸出權重 $-2$ 在誤差訊號往回傳時既放大又反轉了它——這就是 $\bar h_{\ell-1} = W_\ell^\top\bar z_\ell$ 中轉置權重矩陣的作用。

## 詳解例題 3.4——softmax 交叉熵

**問題。** 分數 $s = (2.0, 1.0, 0.1)$，目標為第 1 類。計算 $p$、損失與 $\bar s$。

**解答。** $e^{s} = (7.389, 2.718, 1.105)$，總和 $11.212$，所以 $p = (0.659, 0.242, 0.099)$（更精確為 $0.659001, 0.242433, 0.098566$）。損失 $= -\ln 0.659001 = 0.417030$。梯度 $\bar s = p - e_1 = (-0.341, 0.242, 0.099)$。

梯度提高正確類別的分數，並依其他類別拿走多少機率來壓低它們。各元素總和為零（所有分數加上同一常數時 softmax 不變，所以損失在全 1 方向上不可能改變）。

## 詳解例題 3.5——病態條件與動量

**問題。** $L(\theta) = \tfrac12(\theta_1^2 + 10\theta_2^2)$，從 $(1, 1)$ 出發。(a) 求梯度下降法的最佳固定步長及其收斂因子。(b) 誤差降為 $10^{-3}$ 倍需要幾步？(c) 以 §3.5.7 的最佳參數，對重球動量重做一次。

**解答。** (a) 曲率為 $\lambda_1 = 1$、$\lambda_2 = 10$；每個座標的誤差乘上 $1-\eta\lambda_i$。當 $|1-\eta\cdot1| = |1-\eta\cdot10|$ 時，最慢的因子最小，即 $\eta = 2/(1+10) = 2/11 \approx 0.182$，兩個座標的因子都是 $(10-1)/(10+1) = 0.818$（§3.5.4）。

(b) $0.818^k = 10^{-3} \Rightarrow k = \ln10^{-3}/\ln0.818 \approx 34.4$。模擬結果：35 步。

(c) 對 $\kappa = 10$：$\eta = 4/(\sqrt{10}+1)^2 = 0.231$、$\beta = \bigl((\sqrt{10}-1)/(\sqrt{10}+1)\bigr)^2 = 0.270$，漸近因子 $(\sqrt{10}-1)/(\sqrt{10}+1) = 0.519$，預測約 10.5 步達到 $10^3$ 倍。模擬結果：15 步（漸近速率需要幾步才會生效），量測到的漸近因子為 $0.52$。圖 3.2 畫出兩條路徑。

## 詳解例題 3.6——選擇有限差分的步長

**問題。** 在雙精度下以中央差分估計 $\sin x$ 在 $x = 1$ 的導數。哪個 $h$ 使誤差最小？誤差最小能到多少？

**解答。** 兩種誤差互相競爭。*截斷誤差（truncation error）：* 泰勒展開給出 $\frac{f(x+h)-f(x-h)}{2h} = f'(x) + \frac{h^2}{6}f'''(x) + O(h^4)$，誤差約 $\frac{h^2}{6}|f'''|$。*捨入誤差（rounding error）：* 每個計算出的 $f$ 值都帶有至多單位捨入誤差 $u = 2^{-53}\approx1.11\times10^{-16}$ 的相對誤差；兩個幾乎相等的數相減會保留這個絕對誤差，除以 $2h$ 又將它放大，得約 $u|f|/h$。令 $E'(h) = 0$ 來最小化 $E(h) = \frac{h^2}{6}|f'''| + \frac{u|f|}{h}$：

$$
h^* = \Bigl(\frac{3u|f|}{|f'''|}\Bigr)^{1/3} = \Bigl(\frac{3\cdot1.11\times10^{-16}\cdot0.8415}{0.5403}\Bigr)^{1/3}\approx 8.0\times10^{-6},\qquad E(h^*)\approx1.7\times10^{-11}.
$$

實測誤差：$h = 10^{-4}$ 時 $9.0\times10^{-10}$，$h = 10^{-5}$ 時 $1.1\times10^{-11}$，$h=10^{-6}$ 時 $2.8\times10^{-11}$，$h = 10^{-8}$ 時 $2.6\times10^{-9}$。步長更小反而*更差*。前向差分（截斷誤差為 $O(h)$）的最佳步長約在 $\sqrt u\approx10^{-8}$，最佳誤差只有約 $3\times10^{-9}$。圖 3.4（§3.7.5）畫出完整的 V 形曲線。

## 詳解例題 3.7——Adam 的第一步

**問題。** 一個模型有三個參數，第一次的梯度為 $g_1 = (0.001,\ -50,\ 3)$。取 $\beta_1 = 0.9$、$\beta_2 = 0.999$、$\epsilon = 10^{-8}$，計算 Adam 第一次更新的方向 $\hat m_1/(\sqrt{\hat v_1}+\epsilon)$。

**解答。** $m_1 = 0.1g_1$、$v_1 = 0.001g_1^2$；偏差校正後 $\hat m_1 = g_1$、$\hat v_1 = g_1^2$。所以方向為 $g_1/(|g_1| + \epsilon) = (0.99999,\ -1,\ 1)$。每個座標都（幾乎恰好）移動 $\eta$，儘管梯度大小相差五萬倍。若沒有偏差校正，第一步在每個座標上都會大 $\frac{0.1g}{\sqrt{0.001}|g|} \approx 3.16$ 倍——這就是省略它的實作在訓練初期行為怪異的原因。

## 詳解例題 3.8——前向還是反向？

**問題。** 計算得到完整導數所需的傳遞次數：(a) 損失 $L:\mathbb{R}^{1000}\to\mathbb{R}$；(b) 軌跡 $\gamma:\mathbb{R}\to\mathbb{R}^{1000}$；(c) 映射 $F:\mathbb{R}^{1000}\to\mathbb{R}^{1000}$。

**解答。** 前向模式每次給出雅可比矩陣的一*行*；反向模式給出一*列*。(a) 雅可比矩陣為 $1\times1000$：前向 1000 次，反向 **1** 次。(b) $1000\times1$：前向 **1** 次，反向 1000 次。(c) $1000\times1000$：兩者都要 1000 次——除非只需要乘積 $J^{\top}u$（一次反向）或 $Jv$（一次前向），而實務上這是常見情況。

## 詳解例題 3.9——以變異數決定初始化

**問題。** 一層計算 $z = \sum_{j=1}^{n}w_jx_j$，有 $n = 256$ 個平均為 0、變異數為 1 的獨立輸入，權重獨立、平均為 0、變異數為 $\sigma_w^2$。選擇 $\sigma_w$ 使 $\mathrm{Var}(z) = 1$。如果輸入是前一層單位變異數前活化經過 ReLU 的輸出，應該怎麼改？

**解答。** 對獨立且平均為零的因子，$\mathrm{Var}(w_jx_j) = \mathrm{Var}(w_j)\mathrm{Var}(x_j)$，獨立項的變異數相加：$\mathrm{Var}(z) = n\sigma_w^2$。所以 $\sigma_w^2 = 1/n$，$\sigma_w = 0.0625$。

若 $x_j = \mathrm{ReLU}(u_j)$，$u_j$ 對稱於零且 $\mathrm{Var}(u_j) = 1$，則 $x_j$ 平均不為零，改用二階動差：$\mathbb E[x_j^2] = \tfrac12\mathbb E[u_j^2] = \tfrac12$（一半的質量被歸零），$\mathrm{Var}(z) = n\sigma_w^2\,\mathbb E[x_j^2] = n\sigma_w^2/2$。要維持 $\mathrm{Var}(z) = 1$，需 $\sigma_w^2 = 2/n$，$\sigma_w = 0.0884$——即 [He et al.（2015）](/zh-tw/references/#he-2015) 的規則。§3.8.1 推導反向傳遞的版本，圖 3.3 顯示違反這條規則時會發生什麼。
