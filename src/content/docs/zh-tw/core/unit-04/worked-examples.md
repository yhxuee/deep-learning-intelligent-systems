## 詳解例題 4.1——逐步的軟查找

**問題。** 以 §4.2.1 的編碼與 §4.2.7 的投影，對 $\beta = 4$ 計算查詢 $?b$ 對鍵值對 $(a,3), (b,7), (c,1)$ 的分數、權重與輸出。

**解答。** 查詢為 $q = W_Qx_{?b} = 4\,(0,1,0)$。鍵讀取鍵欄：$k_{(a,3)} = (1,0,0)$、$k_{(b,7)} = (0,1,0)$、$k_{(c,1)} = (0,0,1)$，而查詢詞元自己的鍵欄是空的，$k_{?b} = (0,0,0)$。值為：$3, 7, 1, 0$。

| 位置 | 分數 $q^{\top}k$ | $e^{\text{分數}}$ | 權重 | 權重 × 值 |
|---|---|---|---|---|
| $(a,3)$ | 0 | 1 | 0.0174 | 0.052 |
| $(b,7)$ | 4 | 54.598 | 0.9479 | 6.635 |
| $(c,1)$ | 0 | 1 | 0.0174 | 0.017 |
| $?b$ | 0 | 1 | 0.0174 | 0 |
| **總和** | | 57.598 | 1.0000 | **6.705** |

在 $\beta=8$ 時，匹配權重為 $e^8/(e^8+3)=0.9990$，輸出為 6.994。這很接近 7，卻不等於 7：有限尺度的 softmax 仍會替每個未遮罩位置留下正權重。

空的鍵欄也解釋了查詢為何不會選到自己。$W_Q$ 讀取查詢欄，$W_K$ 則讀取分開的鍵欄。若改把查詢與鍵的身分編在同一組座標，並直接用原始內積比較，查詢的自我分數就可能和匹配鍵值對並列。分開投影，能讓「我在問什麼」與「別人如何找到我」使用不同特徵。

## 詳解例題 4.2——四個見證序列上的最佳仿射擬合

**問題。** 對定理 4.1 證明中的四個序列 $A, B, C, D$（目標為 3、7、7、3），求使總平方誤差最小的仿射函數的輸出。

**解答。** 每個仿射 $F$ 都滿足 $F_A + F_D = F_B + F_C$。在此限制下最小化 $(F_A-3)^2 + (F_B-7)^2 + (F_C-7)^2 + (F_D-3)^2$。對 $F_A + F_D - F_B - F_C = 0$ 引入拉格朗日乘數 $\lambda$，駐點條件給出殘差 $F_A - 3 = F_D - 3 = -\lambda/2$ 與 $F_B - 7 = F_C - 7 = \lambda/2$。代入限制式，$(3 - \lambda/2)\cdot2 = (7 + \lambda/2)\cdot2$，所以 $\lambda = -4$，且

$$
F_A = F_B = F_C = F_D = 5 .
$$

對這四個見證序列，最佳仿射擬合都輸出**兩個候選值的平均**；每次殘差大小為 2，總平方誤差為 $4\cdot2^2=16$。常數仿射函數 $F(X)=5$ 可以實現這些輸出，所以受限最小值確實可達。這個結果針對仿射混合，並沒有排除每一種使用固定位置連接的非線性架構。

## 詳解例題 4.3——因果注意力的前向計算

**問題。** 三個位置，$d_k = d_v = 2$：

$$
Q = \begin{pmatrix}1&0\\0&1\\1&1\end{pmatrix},\quad
K = \begin{pmatrix}1&0\\1&1\\0&1\end{pmatrix},\quad
V = \begin{pmatrix}1&2\\0&1\\3&0\end{pmatrix}.
$$

計算 $S$、因果權重 $A$ 與 $Y$。

**解答。** $QK^{\top}$ 的元素為 $q_i^{\top}k_j$；除以 $\sqrt2$：

$$
S = \frac{1}{\sqrt2}\begin{pmatrix}1&1&0\\0&1&1\\1&2&1\end{pmatrix}
= \begin{pmatrix}0.7071&0.7071&0\\0&0.7071&0.7071\\0.7071&1.4142&0.7071\end{pmatrix}.
$$

套用因果遮罩（對角線以上的元素變成 $-\infty$）與逐列 softmax。請記住：每一列是一個接收者，在獲准看見的來源位置中做選擇：

- 第 1 列只有一個可見元素：$A_{1\cdot} = (1, 0, 0)$。
- 第 2 列：$\mathrm{softmax}(0, 0.7071) = (0.3302, 0.6698)$，因為 $1/(1+e^{0.7071}) = 0.3302$。
- 第 3 列：$\mathrm{softmax}(0.7071, 1.4142, 0.7071) = (0.2483, 0.5035, 0.2483)$。

$$
A = \begin{pmatrix}1&0&0\\0.3302&0.6698&0\\0.2483&0.5035&0.2483\end{pmatrix},\qquad
Y = AV = \begin{pmatrix}1&2\\0.3302&1.3302\\0.9930&1.0000\end{pmatrix}.
$$

例如接收者 3 的輸出為 $0.2483(1,2) + 0.5035(0,1) + 0.2483(3,0) = (0.9930, 1.0000)$。圖 4.3 畫出 $A$。

![詳解例題 4.3 的 3×3 因果注意力矩陣熱圖：接收者 1 的權重為 (1, 遮罩, 遮罩)；接收者 2 為 (0.330, 0.670, 遮罩)；接收者 3 為 (0.248, 0.503, 0.248)。](/figures/u04-attention-heatmap.svg)

*圖 4.3——因果注意力權重：每個接收者在可見位置上的權重總和為 1。*

## 詳解例題 4.4——因果注意力的反向計算

**問題。** 延續詳解例題 4.3，上游梯度為 $\bar Y = \begin{pmatrix}1&0\\0&1\\1&-1\end{pmatrix}$。以 §4.3.6 的公式計算 $\bar V$、$\bar A$、$\bar S$、$\bar Q$ 與 $\bar K$，並以有限差分檢查 $\bar Q_{31}$。

**解答。** 先讓相依鏈保持清楚：$Y\to(A,V)$，再由 $A\to S$，最後由 $S\to(Q,K)$。下面每個帶上橫線的矩陣，都和不帶線的對應矩陣形狀相同。

$\bar V = A^{\top}\bar Y = \begin{pmatrix}1.2483&0.0820\\0.5035&0.1663\\0.2483&-0.2483\end{pmatrix}$，且 $\bar A = \bar YV^{\top} = \begin{pmatrix}1&0&3\\2&1&0\\-1&-1&3\end{pmatrix}$。

逐列做 softmax 的反向，$\bar S_{i\cdot} = a_i\odot(\bar A_{i\cdot} - a_i^{\top}\bar A_{i\cdot})$，只用可見元素：

- 第 1 列：唯一的可見權重為 1，所以 $a^{\top}\bar A = 1$，$\bar S_{1\cdot} = 1\cdot(1-1) = 0$。*一個只能看到自己的查詢，對於「該看哪裡」沒有什麼可學的。*
- 第 2 列：$a^{\top}\bar A = 0.3302\cdot2 + 0.6698\cdot1 = 1.3302$；$\bar S_{2\cdot} = (0.3302(2-1.3302),\ 0.6698(1-1.3302),\ 0) = (0.2212, -0.2212, 0)$。
- 第 3 列：$a^{\top}\bar A = -0.2483 - 0.5035 + 0.7448 = -0.0070$；$\bar S_{3\cdot} = (-0.2465, -0.5000, 0.7465)$。

$\bar S$ 的每一列總和都為零——這是 softmax 對「同一列加上常數」不變的結果。接著

$$
\bar Q = \frac{\bar SK}{\sqrt2} = \begin{pmatrix}0&0\\0&-0.1564\\-0.5279&0.1743\end{pmatrix},\qquad
\bar K = \frac{\bar S^{\top}Q}{\sqrt2} = \begin{pmatrix}-0.1743&-0.0179\\-0.3535&-0.5099\\0.5279&0.5279\end{pmatrix}.
$$

**檢查。** 把 $Q_{31}$ 擾動 $\pm10^{-6}$，對 $L = \sum_{ij}Y_{ij}\bar Y_{ij}$ 取差分，得 $-0.52785$ ✓。

## 詳解例題 4.5——RoPE 只依賴相對位置

**問題。** 一個旋轉對，$\theta = 0.5$、$q = (1, 0)$、$k = (0.6, 0.8)$。對 $(m,n) = (3,1), (5,3), (10,8)$ 與 $(1,3)$ 計算分數 $\bigl(R(m\theta)q\bigr)^{\top}\bigl(R(n\theta)k\bigr)$。

**解答。** 由 §4.3.4，分數為 $q^{\top}R((n-m)\theta)k$。前三對都有 $n - m = -2$，角度為 $-1$ 弧度：$R(-1)k = (0.6\cos1 + 0.8\sin1,\ \dots)$，分數是它的第一分量，$0.6(0.5403) + 0.8(0.8415) = 0.9974$——**三者完全相同**，雖然絕對位置不同。對 $(1,3)$，$n - m = +2$：$0.6(0.5403) - 0.8(0.8415) = -0.3490$。以明確的旋轉直接計算也得到同樣四個值（誤差在 $10^{-15}$ 內）。旋轉相對位移會改變分數；兩個位置一起平移則不會。

## 詳解例題 4.6——總寬度固定時，頭數不改變參數量

**問題。** 固定總寬度 $d=768$，比較 $H=1$ 個寬度 768 的頭，以及 $H=12$ 個寬度 64 的頭，其注意力參數量。

**解答。** 12 個頭時，每個頭有 $W_Q^{(h)},W_K^{(h)},W_V^{(h)}\in\mathbb{R}^{768\times64}$：$3\cdot12\cdot768\cdot64=3\cdot768^2=1\,769\,472$ 個參數，加上 $W_O$ 的 $768^2=589\,824$；總計 $4d^2=2\,359\,296$（另加 $4d=3\,072$ 個偏置）。一個寬度 768 的頭，參數量完全相同，因為固定了 $Hd_h=d$。

分數矩陣乘法的首要算術量也相同：$12\cdot T^2\cdot64=T^2\cdot768$。改變的是路由結構與中間儲存：從一個逐列正規化的 $T\times T$ 矩陣，變成十二個。若增加 $H$ 時也增加總寬度，當然就會增加參數。

## 詳解例題 4.7——計算 GPT-2 small 的參數量

**問題。** GPT-2 small 有 $d = 768$、$L = 12$ 個區塊、詞彙量 $V = 50\,257$、最大長度 $T_{\max} = 1\,024$、學習的位置嵌入，以及綁定的反嵌入。精確計算它的參數量。

**解答。** 每個區塊：

| 部分 | 公式 | 數量 |
|---|---|---|
| 注意力 $W_{QKV}$ 與偏置 | $3d^2 + 3d$ | 1 771 776 |
| 注意力輸出 $W_O$ 與偏置 | $d^2 + d$ | 590 592 |
| MLP $W_1$（$4d\times d$）與偏置 | $4d^2 + 4d$ | 2 362 368 |
| MLP $W_2$（$d\times4d$）與偏置 | $4d^2 + d$ | 2 360 064 |
| 兩個層正規化（各有增益與偏置） | $4d$ | 3 072 |
| **區塊合計** | $12d^2 + 13d$ | **7 087 872** |

十二個區塊：85,054,464。詞元嵌入 $Vd=38\,597\,376$；位置 $T_{\max}d=786\,432$；最後的層正規化 $2d=1\,536$；綁定的反嵌入 0。**總計：124,439,808。** 實驗室的 `test_gpt2_small_parameter_count` 會以這個數字檢查公式。其中約 31% 的參數在詞元嵌入表中。這個比例不是模型大小的定律；若一個模型家族大致固定詞彙量，卻增加深度與隱藏寬度，該比例便會下降。

## 詳解例題 4.8——長度 1,024 時的計算量與記憶體

**問題。** 對 GPT-2 small 的一個區塊、一條 $T = 1\,024$ 個詞元的序列，計算 (a) 投影與 MLP 的前向 FLOPs，對比注意力分數與混合的 FLOPs；(b) 兩者相等的長度；(c) 若以 16 位元浮點數直接儲存注意力權重矩陣所需的記憶體；(d) 整個模型的 KV 快取記憶體。

**解答。** 採用一次乘加算 2 FLOPs 的慣例，而且只計大型矩陣乘法。(a) 投影（$4d^2$ 個參數）與 MLP（$8d^2$）每個詞元每個參數約 2 FLOPs：$2\cdot12d^2\cdot T=24Td^2=1.45\times10^{10}$。分數 $QK^{\top}$ 與混合 $AV$ 各需 $2T^2d$：合計 $4T^2d=3.22\times10^{9}$。
(b) $24Td^2 = 4T^2d \iff T = 6d = 4\,608$。短於這個長度時，逐詞元的層佔主導；長於它時，注意力佔主導（圖 4.4）。
(c) 12 個頭 × $1024^2$ 個權重 × 2 位元組 $=25\,165\,824$ 位元組：按十進位計，每區塊每條序列為 25.2 MB；按二進位計則正好是 24 MiB。
(d) 對一般多頭注意力，$2\times L\times T\times d\times2$ 位元組 $=2\cdot12\cdot1024\cdot768\cdot2=37\,748\,736$ 位元組：按十進位計，每條序列為 37.7 MB；按二進位計則正好是 36 MiB（[KV 快取](/zh-tw/atlas/nodes/mech-kv-cache/)）。分組查詢注意力會改變快取的鍵和值寬度，因而改變這個數量。

![d = 768 時，一個 Transformer 區塊的前向 FLOPs 對序列長度的雙對數圖：投影與 MLP 隨 T 線性增長，注意力分數與混合隨 T 平方增長，兩者在 T = 6d = 4608 相交。](/figures/u04-flops-crossover.svg)

*圖 4.4——計算量花在哪裡：在 $T = 6d$ 之後，平方級的注意力超過線性層。*

## 詳解例題 4.9——分塊精確計算 softmax

**問題。** 對一個查詢，分數為 $(1, 3, 2)$、純量值為 $(10, 20, 30)$，計算注意力輸出——先直接計算，再把鍵分成兩塊 $\{1, 2\}$ 與 $\{3\}$ 處理，只保留執行中的最大值 $m$、正規化分母 $\ell$ 與未正規化的輸出 $o$。

**直接計算。** 權重 $e^{s}/\sum e^{s} = (0.0900, 0.6652, 0.2447)$；輸出 $0.900 + 13.305 + 7.342 = 21.547$。

**分塊計算。** 第 1 塊（分數 1、3）之後：$m = 3$，$\ell = e^{1-3} + e^{3-3} = 1.1353$，$o = 10e^{-2} + 20 = 21.3534$。
第 2 塊（分數 2）：新的最大值為 $m' = \max(3, 2) = 3$，所以舊的總和不需重新縮放（$e^{m - m'} = 1$）；加入新項：$\ell' = 1.1353 + e^{2-3} = 1.5032$，$o' = 21.3534 + 30e^{-1} = 32.3897$。輸出 $o'/\ell' = 21.547$ ✓。

如果之後某一塊有更大的分數，舊的 $\ell$ 與 $o$ 會先乘上 $e^{m-m'}<1$，再加上新項。這種**線上 softmax（online softmax）**（[Milakov & Gimelshein 2018](/zh-tw/references/#milakov-2018)）在實數算術中與直接 softmax 代數等價；浮點計算可能因捨入而略有不同。它能以串流方式運算，不必儲存完整的一列權重，也是考量 IO 的注意力核心之關鍵成分（§4.8.1）。
