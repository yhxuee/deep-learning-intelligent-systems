## Compact — one semester, 14 weeks

For departments with a single deep-learning course. Covers the minimum a graduate needs to verify AI-written deep-learning code.

| Weeks | Units | Output |
|---|---|---|
| 1–2 | [01](/core/unit-01/) Learning | Spine Stage 01; held-out evaluation |
| 3–5 | [03](/core/unit-03/) Optimization (+ [02](/core/unit-02/) essentials) | Hand-built autodiff passing all invariants; Stage 03 |
| 6–8 | [04](/core/unit-04/) Interaction | Attention from memory; bug hunt; Stage 04 |
| 9 | Consolidation | AI-off midterm + oral check |
| 10–11 | [07](/core/unit-07/) Self-supervision | Pretrain the spine model; contamination check |
| 12–13 | [10](/core/unit-10/) Failure | Evaluation harness; leakage diagnosis |
| 14 | Defense | Short project + oral defense |

## Full — two semesters, 28 weeks

| Weeks | Focus | Output |
|---|---|---|
| 1–6 | Units 01–03: learning, representation, optimization | Minimal network with independent gradient verification |
| 7–12 | Units 04–06: interaction, memory, compute | Comparative experiment on information-processing mechanisms |
| 13–14 | Consolidation | Independent and oral assessments |
| 15–20 | Units 07–09: self-supervision, generation, decision | Small end-to-end pipeline incl. post-training |
| 21–24 | Units 10–11: failure, interpretation | Diagnostic and adversarial evaluation report; induction head |
| 25–28 | Unit 12: capstone | Reproduce → challenge → extend → defend |
