The [Traditional Chinese edition](/zh-tw/) uses Taiwan academic terminology and gives the English term in parentheses at a term's first appearance on each page, e.g. 梯度下降法（gradient descent）. This glossary is the reference for both editions. Where mainland-China usage differs, the common variant is listed so that readers can connect the two literatures.
