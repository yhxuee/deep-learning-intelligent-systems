The [Traditional Chinese edition](/zh-tw/) uses Taiwan academic terminology and the [Simplified Chinese edition](/zh-cn/) uses mainland terminology; both give the English term in parentheses at a term's first appearance on each page, e.g. 梯度下降法（gradient descent）. This glossary is the reference for all three editions. The Simplified edition is generated from the Traditional one with the mainland terms listed here, so the two cannot drift apart. Note that Taiwan and mainland usage swap the words for matrix rows and columns (Taiwan 列 = row, 行 = column; mainland 行 = row, 列 = column).
