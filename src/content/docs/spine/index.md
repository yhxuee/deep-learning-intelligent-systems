Abstract questions need a concrete object to be asked about. The spine project is **one small language model that you build, extend and interrogate across the whole Core**. Stanford's CS336 shows that building a language model from scratch is a viable organizing thread for a course [CS336](/references/#cs336-2026); the spine applies the same idea at laptop scale, using a corpus of simple stories in the spirit of TinyStories [Eldan & Li 2023](/references/#eldan-2023).

Every stage has a **verification target** — a number or invariant that tells you, independently of any AI, whether the stage is correct. All targets run in CI (`spine/test_spine.py`, `spine/test_model.py`).

## One model, one corpus

- **`spine/model.py`** is a decoder-only Transformer in NumPy (pre-LayerNorm, tied embeddings, learned positions, KV cache) whose backward pass is written out by hand — the derivations of Units 03 and 04, executed. Every gradient is checked against central finite differences, and an instrumented matrix product counts FLOPs so that Unit 06's $6N + 12LTd$ rule is verified to the last operation. Hooks for ablating and patching attention heads serve Unit 11. You may write your own stages with a framework's autograd and compare against this reference.
- **`spine/data/tales.txt`** is generated by `make_tales.py`: 1 400 short stories, 50 distinct characters, the last 140 held out. It is synthetic so that it is licence-free and **instrumented**: 67 duplicate pairs, 6 held-out stories leaked into training, 30% wrong arithmetic, and made-up pet names that can only be predicted by copying are planted on purpose, and their locations are written to `tales_manifest.json`. Later stages must detect or cope with each.

## Stages

| Stage | Unit | You add | Verification target |
|---|---|---|---|
| 01 | [01](/core/unit-01/) | count-based bigram, add-α smoothing | held-out NLL < $\ln V$; α → ∞ gives $\ln V$ exactly |
| 02 | [02](/core/unit-02/) | factorized bigram with tied embeddings; neural 4-gram | init loss $= \ln V$; lookup gradient = one-hot gradient; interchangeable symbols merge; neural 4-gram beats counts on scarce data |
| 03 | [03](/core/unit-03/) | neural bigram trained with your derived gradient | init loss $=\ln V$; converges to the count optimum from above |
| 04 | [04](/core/unit-04/) | causal self-attention: the Transformer block | gradient check of every parameter; causality; beats the bigram |
| 05 | [05](/core/unit-05/) | KV-cache decoding | cached logits = full recompute; cache bytes = formula |
| 06 | [06](/core/unit-06/) | FLOP accounting; five model widths; scaling fit | counted FLOPs $= BT(6N + 12LTd)$ exactly; fit recovers known laws; prediction written before the sixth run |
| 07 | [07](/core/unit-07/) | MinHash dedup, contamination check, pretraining | every planted duplicate and leak found, nothing else removed |
| 08 | [08](/core/unit-08/) | samplers; 2-D flow matching | samplers reduce to each other in their limits; exact Gaussian field transports noise onto data |
| 09 | [09](/core/unit-09/) | REINFORCE with a KL anchor; DPO; reward-hacking audit | estimator unbiased; KL-regularized optimum = tilted reference; DPO gradient = finite differences |
| 10 | [10](/core/unit-10/) | evaluation harness | ECE of calibrated / miscalibrated predictors; 95% bootstrap coverage; pairing narrows intervals |
| 11 | [11](/core/unit-11/) | find, test and ablate copying circuits | hand-built induction circuit found by every method; ablation and patching invariants |
| 12 | [12](/core/unit-12/) | pre-registered ablation and replication | determinism; tamper-evident pre-registration; mechanical decision rule |

## Running it

```bash
cd spine
python -m pytest                         # every verification target, a few minutes on a laptop
python stage01_bigram.py                 # seconds
python stage04_attention.py              # a few minutes; writes checkpoints/stage04.npz
python stage07_pretrain.py               # about 15 minutes; writes checkpoints/stage07.npz
python stage09_post_training.py          # uses the Stage 07 checkpoint
```

Every stage needs only NumPy. Stages 05 and 08–11 load the Stage 07 checkpoint, which is committed so that they run without retraining. To use a real corpus, pass `--data path/to/text.txt` to stages 01–04.

## Design rules

- **Earned abstraction.** Every gradient in the reference is one you have derived (Units 03–04); frameworks are welcome once you can check them against it.
- **One change per stage**, with a prediction written before the run.
- **Laptop first.** Every stage runs on a laptop CPU in minutes; nothing needs a GPU.
- **Ground truth before claims.** Where a stage detects something (duplicates, contamination, circuits), the ground truth is planted or hand-built first, so the detector itself is tested.
